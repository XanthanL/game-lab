# 章节标题制度（2026-09-21 定稿）

作者要求：改得像《地球往事》那样。**照抄不行，取它的做法**。

## 《地球往事》标题的做法（拆出来的规则）

| 特征 | 例 | 说明 |
|---|---|---|
| 具象名词，不用抽象概念 | 「疯狂年代」「寂静的春天」「黑暗战役」 | 能看见、能摸到、能发生 |
| 并列式三项 | 「三体、周文王、长夜」「三体、墨子、烈焰」 | 两个实体 + 一个意象，用顿号连 |
| 自造制度名词 | 「面壁者」「破壁人」「执剑人」 | 世界自己的词，不是现成词 |
| 极短 | 「咒语」「塔」「地面」 | 1—3 字照样立得住 |
| 事件型 | 「大静默」「大移民」 | 发生过的一件事 |
| 编号序列 | 「红岸之一 / 之二 / 之三」 | 同题连续时用 |
| 冷 | 全篇没有一句抒情标题 | 不评价，只命名 |

## 旧标题的问题

旧版是「物理概念 + 社会学延伸」的论文腔：

- 测地线方程的非线性解 / 诺特定理的例外情况 / 卡西米尔效应的社会形态 /
  彭罗斯过程的底层实现 / 贝尓不等式的背叛 / 霍金辐射的逆向应用……

四个毛病：
1. **标题即剧透**——读者看到「彭罗斯过程的底层实现」就知道这章要讲什么原理，悬念没了。
2. **标题在替正文下结论**——「背叛」「例外情况」是判断，不是命名。
3. **学术腔**，和小说本身「零情绪形容词、设定从动作里长出来」的叙事纪律相反。
4. 有两处**撞名**：14「量子纠缠态的宏观显现」≈ 25「量子纠缠的宏观显现」。

## 新标题制度（四条）

1. **只命名，不评价。** 标题里不许出现判断词（背叛、例外、错误、代价、不可逆）。
2. **优先用本章的那个「物」。** 每章章末落在一个物上，标题就多半是那个物。
3. **2—5 字为主。** 超过 5 字要说明为什么。
4. **人名只有当人物本身是悬念时才用**（第 5 章瑟拉、第 7 章七四），且全书不超过 3 个。
