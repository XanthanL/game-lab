# 第一卷重写规划 · v2（2026-09-21）

## 一、为什么要重写

读一遍现有第 1-12 章，最大的问题不是设定，是**叙述方式**：

1. **解释代替呈现**。几乎每个物理概念后面都跟着一段"这意味着……""他明白了……"。
   读者被喂结论，没有被给出可以自己得出结论的材料。
2. **抒情式收尾**。每章结尾都是同一套："我们是被遗忘的测地线""即使弯曲也依然有方向"
   "那是希望的味道"。"我们是被遗忘的测地线"一句在现有文本里出现了 **5 次**，
   每次都当章末重锤用，第五次已经没有任何重量。
3. **众生缺席**。第一卷名义上是"世界观奠基篇"，但除了七四和艾拉，
   底层是一团模糊的背景。没有职业分工，没有作息，没有物价，没有气味，
   没有"一个搬运工三十一年走多少步"这种能让人信服的数字。
4. **主角过早站在舞台中央**。第 1 章七四就开始觉醒、追问、拿芯片、见哲伦，
   读者还没见过这个世界的样子，就被要求关心一个人的内心。

## 二、参照系：地球往事（三体 I）的叙事纪律

不是模仿刘慈欣的题材，是借他的**叙述姿势**：

| 纪律 | 做法 |
|---|---|
| 零情绪形容词 | 用名词和数字代替"压抑""绝望"。写"通道灯 30% 亮度"，不写"昏暗压抑的通道" |
| 设定从动作里长出来 | 度规畸变不解释，写队列自然走成弧线、水壶里的水面倾斜 0.4 度 |
| 每章至少一个可验证的物理量 | 频率、温度、长度、步数、余额 —— 精确到小数点后一位 |
| 对话短，有潜台词 | 三轮不换场景；人物说半句，另半句留给读者 |
| 结尾落在一个"物"上 | 计数器上的步数、一张纸条、一段无名振动记录。**禁止**结尾抒情总结 |
| 理论比重 ≤ 20% | 物理概念以"系统公告 / 工作手册 / 老工人的经验之谈"出现，不做科普 |
| 冷启动，慢收紧 | 开篇是日常琐事，章末才给一个不安的具体细节 |

### 第 23 章的实际落点

**章**「巡塔人」时间是纪元 1018 年 **3 月 31 日**（第 12 章是 3 月 22 日，**中间隔了九天**，
九天里他走了四个扇区、过了十一道闸、怀里多了两盘带子）。旧稿（米洛 / 艾琳 / 蕾娜 / 林小满 / 阿雅 / 陆明）
与新设定完全脱节，整章推倒，旧稿备份 `.workbuddy/ch23-old.md`。

**空间 = 塔底绕塔一圈的那条「线」**（本章主角）：
- ⭐ **线不是画的，是踩出来的。** 灰被踩到两边、中间露出一条底；线不宽，**一脚宽**；
  线的两边是两道堆起来的灰，**半个指头**高。
- ⭐ **巡塔的规矩 = 走一圈，脚落在线上才算一圈**；落不上不算，要再走一圈。
  一天三班（早中夜），班次靠**塔影**判断（影到某块砖上是一半）。
  **天阴没有影就不走，等影**——最长等过一天，那天少一格，上头没问过。
- ⭐ **读者能把自己放进去的场景**：七四踩到线上，翟说「你踩线上了」；章末翟让他**踩一下线头**留个印
  （「明天我还能找到它」「要是明天找不到呢」「那就再走一圈」）。
- ⭐ **用身体量不用仪表量**：灰厚的地方线会断（塔基北边，灰到脚踝）。断了就看不出来，
  脚不知道往哪儿落——他**把脚掌悬着往下落，硬的是线上，软的是灰**，软了就收回来往边上挪。
  后来他记的不是线在哪儿，是**哪一块踩下去硬**。

**引文落地**（两层，缺一层就不成立）：
- **第一层（塔上）**：塔底第一级台阶**侧面**刻着字，二十个位置（十八个字 + 两个点），
  地上**只剩十个口子**（靠里那一半）；靠外那一半被**从塔上下来的取水人脚尖刮平了**
  ——一天一趟，刮二十三年。（接第 12 章「比四百级那一片小，刻得浅，有一半被踩平了」。）
- **第二层（图上）**：九天前七四描图时，把靠外那十个空位**按「字该长什么样」补上了**。
  **那一行里有十个是他自己写的，他以为那是塔刻的。**
  翟用手指隔着门槛点出哪些是刻的、哪些不是（刻的槽两头深，划的槽中间深）；七四删掉自己补的那十个，
  屏上十个对地上十个。
- ⭐⭐ **他没走过这一圈，他就不知道。** ——这就是引文「不巡，你只有一张图」的落点。

**众生 = 巡塔人 翟（二十三年）**：
- 绕着塔基走，头低着看脚前面两步（抬头线就不在眼睛里，脚差半步一圈就不算；收着下巴走久了脖子后面有一块硬的）。
- 一天三圈；本子最后一页一格一个数（一圈一格）；**「我不记年，记格」**。
- ⭐ **前几页印的表格（日期 / 班次 / 结论）三栏从头到尾一个格子没填过**——「填了要人来看」；
  一次来看的人把最后一页折了个横折痕（「折了就不看了」）；第一本被上头收走了。
- ⭐ **格数 ≠ 天数**：病过两次，没走的那天**不画格**，所以数挨着数、中间没有空，
  **他自己也找不出来是哪一天**。「格子是数圈，不是数天。」
- 睡塔外的板铺（板搭在塔壁和一根斜杆中间，底下垫两块配给点拆墙的砖）；一天两趟取水，一趟一桶，
  碗是标准配给碗（碗底光的，跟塔上那三个一样）。
- ⭐ **两条路**：巡塔走线（留下印，叠了二十三年）；取水走直路（水晃出来落在灰上，
  印第二天就没了）——**那条路上一个印也没有**。
- ⭐ 七四反问他「你记这个给谁看」，他答不出；翟回敬一句「你放上去，就是有人看。上面有脚。」

**章末的「物」**：七四踩下线头的印，线头宽了一点；他顺着那条线走，线贴着塔基往前去，绕过去，看不见。
结尾「他站回原来的地方。／线又出来了。／他站在线上。」——**他自己绕塔时脚没落在线上**。

### 第 22 章的实际落点

**章**「漩涡」紧接第 21 章，时间是纪元 1018 年 3 月 29 日（在第 2 扇区过夜后往第 9 扇区走）。
旧稿（米洛 / 艾琳 / 蕾娜 / 林小满 / 阿雅 / K-09848 / 机器人助手 / 伪造档案诱饵）与新设定完全脱节，
整章推倒，旧稿备份 `.workbuddy/ch22-old.md`。

**空间 = 第 9 扇区的坡道**（身临其境主场）：
- ⭐ **坡道不是设计出来的，是绕出来的。** 第 9 扇区在结构上是一个接缝，缝年年开合，贴缝的墙年年裂；
  裂了就修，修的办法是把通道往里挪。挪到今天，这一段已经不是通道，是一圈一圈绕上去的坡。
  **转三圈半，斜度不匀。**
- ⭐ 五天前他从这儿过，那时候这一段是直的（接第 12 章他从第 12 扇区过闸去塔）。
  现在它弯了。他不知道是它弯了还是他记错了。
- ⭐ **读者能把自己放进去的场景**：他在墙上用指甲划一道，走一圈，三十步回到划痕；再划一道，
  这一次四十二步。同一圈路，数出两个数。**他没有尺。**
- ⭐ 坡道上的人都低头走（抬头看三秒就转），都靠里走（外侧没有栏，黑）。
  他靠在墙上，那一块墙的灰被手磨亮了，**是温的**——刚有人扶过，但他没有看见人。
- ⭐ 他数圈用了三种办法（数步子 / 数灯 / 数弯），三个数对不上。**同一圈路，同一个人，数不出一个数。**

**引文落地**：坡道转角墙上一行字（他描的**第六片**不认得的字）——
**上半句五个字「进去了就转」，下半句七个字「转到不是你为止」。**
- ⭐ 上半句笔画深、颜色老、摸得出坎；下半句浅、是平的。
- ⭐⭐ **上半句有两重保险**：它在高处（够不着）+ 它在沟里（灰填不满）。**两重都不是有人特意留的**
  ——一重是坡弯了，一重是灰的性子。**它自己留下来的。**
- ⭐⭐⭐ **够不着不是因为人矮，是因为他站在他站的地方。** 七四站到那个人的位置，抬头，够不着；
  往坡上走两步，缓了，够得着。**往前两步就够着了，可是往前两步就不是他那一段墙了。**

**众生 = 补墙工 桑（十七年）**：
- ⭐ 他的活是「把墙刷掉」。**一块墙刷七下**，刷完下巴点七下（他数数不用嘴，用下巴）。
- ⭐⭐ **七下就是那七个字。** 他不是刷掉它，他是**写**它。十七年，一天三遍（早班 / 中班 / 夜班），
  **字从来没有断过。**
- ⭐ **他从来没有见过另外两个班的人**：三个名字写在手册背面，他写在**中间**
  （"上头是老的，底下是新的，我在中间"）；底下那个名字比他新——有人在他后面来过。
- ⭐ **刷子是从上一个手里传下来的**：柄上握的地方磨出的坑，比他的手宽一点，他的手落进去严丝合缝。
- ⭐ **他等过一次**：早来半个时辰，看见湿的字，他等，**等到灰干了**，人没有来，他把字刷掉了。
  十七年，他只差一点看见过一回。
- ⭐⭐ **十七年也是别人告诉他的**：坡道里的灯不灭，他分不出白天黑夜，他唯一的时间刻度是灰
  （灰干要一顿饭的工夫）。"我来的头一天，上头说，你在这儿十七年。"
- ⭐ **"够不着的不用管"**——头一天上头说的第二件事（纸上没有，是上头说的）。
