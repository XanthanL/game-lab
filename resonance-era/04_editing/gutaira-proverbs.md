## 一、三条来源的配比

### 主干（七成）· 实践的唯物论

不是口号，是**看世界的方法**。谚语要长在这些判断上：

| 内核 | 说人话 | 落进本书 |
|------|--------|----------|
| **异化** | 人的产物反过来压住人 | 「它身上那一份不在它身上，这就是它」 |
| **量变引起质变** | 一分一分攒，攒到不是它 | 「一年两米九，走到不是它那天」 |
| **被拿走的那一截** | 拨的和发的对不上，差额谁的也不是 | 「中间那一截没有」 |
| **历史是干活的人造的** | 留下名字的没干活 | 「十四行，没有一个签名。活是他们干的」 |
| **没调查就没有发言权** | 你没爬，你就不知道上面有什么 | 「四百二十七级。你没爬，你就没有发言权」 |
| **做过才算数** | 耳朵听的不算，手上的才算 | 「写了八年，手上有的，嘴上没有」 |
| **集体拆不开** | 拆得开的归一个人，拆不开的谁也拿不走 | 「拆不开的，谁也拿不走」 |
| **上面不是一个人** | 管着你的东西不在哪间屋里 | 「中枢不在哪间屋里。它在每一间屋里」 |

### 底色（二成）· 不可知

知道的代价、说不出它是什么、尺度上量不了的东西。

- 看了要记一笔 → **知道是要付账的**
- 「我不知道」不是说懒，是说**它本来就说不出来** ← 全书重复最多的四个字，是这套哲学的顶点
- 用一个指甲盖量"走样" = 用人的尺度量不可理解的东西（这本身就是一个不可知的姿势）

### 腔调（一成）· 启示录

**决绝、不收尾、不安慰。** 句子押的是判断的硬，不押韵。
不许出现「只要……就……」「明天会更好」「希望」这类积极收束。

## 二、创作规则

1. **不指名**：不许出现任何人名 / 流派名 / 作品名 / 典故出处。
2. **不引成语**：鲁迅、论语、唐诗、俗语全部退役，只造新句。
3. **字数随缘**，但**正文里写了「X 个字」就必须正好 X 个字**（硬约束，见第四节）。
4. **句式**：两截最好——前半截陈述一个事实，后半截翻一刀。例：
   「拨的是一本，发的是一本。中间那一截，两本上都没有。」
5. **不解释**：只呈现判断或观察，不展开，不抒情。
6. **与章名形成同构或反讽**：章名是「物」，引文是「物」的注释。
7. **source 继续做世界观**：铭牌已拆 / 粉刷覆盖 / 漆掉大半 / 被磨平 / 踩平仅存一字。

## 五、风格走向（三次定调的叠加）

| 版本 | 调性 | 状态 |
|------|------|------|
| 初版（09-21 前） | 鲁迅 / 论语 / 唐诗 —— 文明、温情、和解 | ❌ 已废 |
| 二版（09-22 初） | 启示录腔 —— 决绝、不收尾、不安慰 | 保留为**腔调** |
| **三版（09-22 现行）** | **实践的唯物论为主干 + 不可知为底色 + 启示录为腔调** | ✅ 现行 |

每条新写引文应满足三选二以上：
- **A 唯物**：说一个看得见的事实（量、差额、手上的、爬没爬）
- **B 翻刀**：后半截把前半截推翻（"这跟你人在哪儿不相干"）
- **C 不可知**：落在"说不出来"上（"我不知道"是直接引用，不用在引文里）

不允许出现「只要……就……」「只要不……就……」「加油」「明天会更好」「希望」等积极收束。

### 借词表（in-world dictionary）

**只替名词，不动句式与标点** —— 换完之后标点计数必须与原来相等，
这一条由 `res-pv-probe3.cjs` 盯死。

| 那个时代的说法 | 这个世界 |
|----------------|----------|
| 资产阶级       | 上层     |
| 无产阶级       | 底层人   |
| 体制           | 中枢     |
| 主义           | 主张     |
| 统治秩序       | 上面的秩序 |
| **革命**       | **共振** |

「上层 / 底层 / 中枢 / 层级」是本书自己的词（六层级社会 + 文明管理中枢），
**不是同义词替换** —— 换完之后这句话属于这个世界，不只是把刺眼的词磨掉。

**共振是这本书的名字。** 作者 2026-10-13 定的这一个替换，把它同时变成了动词：
在这个宇宙里，推翻一个秩序的动作就叫**共振** —— 让足够多的部件先在同一频率上自己动起来。
它因此比其余五个替换都重：写正文时注意别让这个词滑回纯物理义，它已经是一个政治词了。

> ⚠️ **这张表只许出现在 `proverbs.js` 的注释和本文档里。**
> 页面上的说明文字（`intro.note`）**不许**把替换前的词列出来 ——
> 那等于把要藏的东西又印在拓片辑的抬头。

### 加新条目的规矩

1. **`tags` 取一个或两个单字**（云 / 兆 / 碑 / 黑 / 担 / 量），测绘仪读数的语言，不是分类学标签。
2. **`source` 必须做世界观** —— 哪面墙、什么时候被磨平、谁去擦的。
   补的新条目里，`source` 故意去蹭那一章原有引文里的同一面墙，让拓片之间互相看见（见第七节）。
3. **不许写 `origin`。** 就算写了也不会被渲染（`reader.js` 里已经没有读它的分支）。
4. **先查借词表。** 新句里出现那个时代的术语，先换再贴；换完回文件注释里把那一行补进表。
5. 加一条 = `items` 里加一个对象。`id` 就是编号，条数由代码读 `items.length`，别去别处写死数字。

## 七、补的 18 条：找来的名言 + 挂进章节（2026-10-12 建，10-13 挂满）

作者原话：「可以按此风格去找类似的语句和名言，然后作用于我们相应章节的前面。」

### 「作用于章节前面」是怎么落的

**不替换那一章原有的 epigraph，而是接在它后面**（`.ch-epigraph-2`，更小更淡）。

理由：原有 epigraph 的字数跟正文里的「X 个字」是绑死的 —— 换掉它，正文会静默脱节，
而 `res-probe.cjs` **不校验**这一条（见第四节）。所以那 7 章的引文谁也不许动。

双向链路挂在 `proverbs.js` 的 `chapter` 这一个字段上，不要在别处再配一份表：

- 谚语页：有 `chapter` 的条目底下出现「挂在 第 N 章 X 前面」→ 点进去
- 章节页：引文下面接一张「同页拓片 · 第 M 号」→ 回拓片辑
