# 古泰拉谚语体系 · 战锤40K 启示录腔

> **作者 2026-09-22 拍板**：原版用的是读者耳熟能详的中文谚语/诗句（"世上本没有路""铁打的营盘流水的兵"），
> 调子偏中庸、温情、和解。整部小说的底色其实是被压到底、靠勇气也走不出去的极权，
> 引文的调性应该**反过来** —— 像战锤40K 那种「帝国黑暗启示录」腔：
>
> - 句式决绝，不留余地；
> - 自指「知道而无用」「看见而不说」「记录而无存」；
> - 站在末日一侧的观察者，不站在救赎一侧；
> - 古泰拉 = 我们的时代，所以**仍然用中文**，但语感学战锤那种**直陈的、不安慰的、不收尾的**句子。

**参考示例（作者原话）**：

> 「就像幸运会显现三次一样，灾难也会兆示三次，不想看而不看，发现了也不说，说了也不听，之后便只能是灭亡。」

这条的三段式「三次兆示 → 不想看 / 发现了也不说 / 说了也不听 → 灭亡」就是新谚语的标准句式骨架。

## 创作规则

1. **字数随缘**：2—14 字都行。**唯一硬约束**：如果该章正文里有「X 个字」的字数描述，quote 必须正好 X 个字。
2. **不解释**：quote 本身只呈现判断或观察，不展开，不抒情。
3. **与章名形成反讽或同构**：章名是「物」，引文是「物」的注释或背书。
4. **source 仍然做世界观**：铭牌已拆 / 粉刷覆盖 / 漆掉一半 / 被磨平 / 踩平仅存一字。
5. **不复用中文成语典故**：旧版那批（鲁迅/韩非/荀子/杜甫/古泰拉烂大街的）全部退役，换成**新造**的谚语气。
6. **不强押韵**：战锤40K 的格言也不押韵，押的是**判断的硬**。

## 风格走向

旧版调性：**鲁迅 / 论语 / 唐诗** → 文明、教师、温情、反讽。
新版调性：**启示录 / 战争祷词 / 末世观察** → 黑色、决绝、不安慰、留缝。

每条引文应满足三选一以上：
- **A** 自指观察：「画圈的人，站在圈外」「知道而无用」
- **B** 反讽倒置：「罪不问人」「疤忘了，痛也还在」
- **C** 末日陈述：「三日之后，是死寂」「未雨绸缪：先编好那一处死」

不允许出现「只要……就……」「只要不……就……」「加油」「明天会更好」「希望」等积极收束。
