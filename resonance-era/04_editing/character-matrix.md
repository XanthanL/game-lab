## 一、边界：搬什么，不搬什么

| | 处理 | 理由 |
|---|---|---|
| 九维坐标结构 | **照搬结构，换说法** | 见第二节。维度本身是通用的，说法必须换成这个世界的词 |
| 四件套（core/quote/light/shadow） | **照搬** | 见第三节 |
| shadow 的写法 | **照搬，且并入拓片规则** | 见第四节 —— 它和我们的「两截翻刀」是同一门手艺 |

| 单条 core / quote 的句子 | **可压成拓片，但要过借词表和拓片规则** | 见第五节样本 |

⚠️ 40ktest 已完成去 IP 化（全部设定与名称为原创），所以**不存在侵权问题**；

## 二、九维（泰拉说法）

40ktest 的刻度是 −3 ~ +3，用余弦相似度匹配，**只问方向不问强度**。
给本书的角色定坐标时照用这个刻度，但维度说法换成这个世界的：

| 维度 | 40ktest 原说法 | **本书说法** | 它在问什么 |
|:--:|---|:--:|---|
| D1 | 秩序 ↔ 崩坏 | **秩序 ↔ 崩坏**（沿用） | 你如何对待结构与不确定性 |
| D2 | 忠诚 ↔ 反叛 | **认下 ↔ 反问** | 你与中枢、与承诺的关系（**不是善恶**） |
| D3 | 智谋 ↔ 武力 | **布局 ↔ 上手** | 冲突当前，你是先算还是先动 |
| D4 | 共情 ↔ 冷酷 | **共情 ↔ 冷酷**（沿用，**双倍权重**） | 别人的处境在你决策里的权重 |
| D5 | 纵欲 ↔ 禁欲 | **浓度 ↔ 省着** | 配给世界里，你是把这一份用尽还是留着 |
| D6 | 显扬 ↔ 隐秘 | **留名 ↔ 不落款** | 要不要被认出来（墙上的字 vs 不出声） |
| D7 | 求知 ↔ 信仰 | **查 ↔ 认** | 面对说不清的那部分，你是追问还是交付 |
| D8 | 怨恨 ↔ 释然 | **记账 ↔ 过账** ⭐ | 过去那笔不公，你记着还是销掉 |
| D9 | 体系 ↔ 独行 | **在册 ↔ 不在册** ⭐ | 你在名册上，还是你自己走 |

⭐ **D8 / D9 是这套坐标落进本书之后变好的地方** —— 40ktest 那边的说法是通用心理维度，
换成「记账 ↔ 过账」「在册 ↔ 不在册」之后，它直接就是第 2 章「名册」和第 4 章「过账」的语言，
量的是同一样东西，但读起来是这个世界在问。

> D4 双倍权重这条也照搬：多条路径在其余八维上高度重叠，只有共情能把它们分开。
> **两个角色其余八维差不多时，用 D4 分。**

## 三、四件套模板

给任何一个人（哪怕只出场两场）定这四句，按顺序写：

```
core    —— 一句话内核。陈述句，不许评价，不许用判断词。
           例：「你把该扛的扛下来了，然后一个字都不解释。」
quote   —— 他自己的一句话。第一人称，口语，短。
           例：「我不需要被理解，我需要事情被做成。」
light   —— 这个内核为什么成立（三四句，落在具体能力上，不许夸）。
shadow  —— 这个内核累积下去会变成什么代价（见第四节）。
```

纪律（与 `immersion-discipline.md` 一致）：

1. **core 只陈述，不评价。** 写「你把该扛的扛下来了」，不写「你是个负责任的人」。
2. **quote 必须是他能说出口的话**，不是作者的旁白。第一人称，不超过两句。
3. **light 不许写成赞美诗** —— 写它能办成什么事，不写它多好。
4. **shadow 是必需项，不是可选项。** 只有 light 没有 shadow 的角色是纸片。
5. **不许出现人名 / 流派名 / 作品名**（第二节硬约束，同样适用于角色设定）。

## 四、shadow 怎么写（⚠️ 这就是我们的翻刀）

40ktest 里 shadow 最狠的几句：

| 原型 | shadow |
|---|---|
| 负山者 | 沉默是会累积利息的。……被误解不是命运，是你选择了不澄清。 |
| 柱石 | 最硬的东西断起来最彻底。……可你也是会累的，而且你不给自己留退路。 |
| 影护者 | 为了做成事而跨过自己底线的人，事后清算的是自己。……唯独算不清「我变成了什么」这一项。 |
| 阵线督者 | 「不能退」久了会变成「不会退」。……而有些时候，正确的事恰恰是承认这条线守不住了。 |
| 齿轮匠师 | 有些最重要的东西恰恰不在流程里：一句话该不该说，一个人该不该等。这些没有条目。 |
| 集群意志 | 当自我完全让给整体，你就失去了说「这个我不干」的能力。 |

**它的固定动作是：把优点本身当成原因，推出代价。**
不是"他有个缺点"，是"正因为这个优点一直生效，所以它变成了这个"。

这与 `gutaira-proverbs.md` 第二节的**「翻刀」（后半截把前半截推翻）完全同构**：

| | 拓片（刻在墙上） | shadow（说给人听） |
|---|---|---|
| 前半 | 陈述一个事实 | 陈述这个内核 |
| 后半 | 推翻前半 | 推出它累积成的代价 |
| 主语 | 无人称 | 第二人称「你」 |
| 长度 | 两句，各 ≤ 15 字 | 三四句 |

所以：**写 shadow 的方法 = 拓片翻刀的方法**。往后写角色到 shadow 卡住时，
去拓片辑找同内核的那一条，把它从无人称改成「你」。

| 拓片 | 原型出处 | 压完的句子 |

| 27 息 | 负山者 shadow | 不说话是会生息的。<br>久了以后，本来该知道你在想什么的人，也不知道。 |
| 28 表 | 齿轮匠师 shadow | 该说的那一句不在表上。<br>该等的那一个也不在。 |
| 29 不 | 集群意志 shadow | 把自己交出去以后，就没有说不的那一项了。<br>剩下的活，是别人挑剩下的。 |

3. **砍到两句** —— 原句三四行的推理只留两截，剩下的留给墙上那块空白。

## 六、捷径：先配型，再改人称

2026-10-14 三十六厥初入册之后，**它们就是现成的人物内核库**。
给一个新角色定四件套时不用从零想：

1. 先估他的九维向量，在厥初里找最接近的那一型；
2. 拿那型的 `core` / `light` / `shadow` 当底稿；
3. 改人称（厥初是第二人称「你」，角色要换成具体的人）、换名词、砍到这个人的口气；
4. `quote` 改成他能说出口的短句 —— **优先从正文里取现成的，比新编强**（见第七节）。

⚠️ 配型只当底稿，**不要照抄** —— 两个角色同型会立刻露馅。
同型的两个人要用 `vec` 里差得最开的那一轴把他们分开（优先 D4 共情，双倍权重）。

**配完要写的不是「他像哪一型」，是「他在哪一轴上跟那一型分开了」。**
那一轴是这个人的定义，也是 shadow 的落点。格式见第七节的 `gap`。

### 四件套

```
core   你在暗处，是因为要留下来的是他们，不是你。
quote  因为它在。
light  你的沉默是有方向的：你站在被划掉的那一栏那一边。一千二百零四段，
       没有一段是给自己录的。你不声张，但该按下去的那一次你按实了 ——
       松开两颗螺栓，不是八颗，够塞进去就够。
shadow 你把代价算得很清楚：拔接口数到二，走三个配给点掉三格半，申诉要多一笔。
       你把人量成了数，量到最后自己也是十二点七 —— 三个字符，划在带子外壳上。
       那一盘你听了四年的带子里有三个字，你一个字都没听出来：你量得出所有人，
       读不出一句话。而最后这一栏不是你填的 —— 介质编号 D-07943，容量一千二百零五，
       同一个号两页，人的那一页空着，介质的那一页满了。
```

**quote 是正文里现成的一句**，不是新编的。第 7 章艾拉问「这个数字有什么意义」，
他答「我不知道」；她说「你不知道你还录」；他说「因为它在」。
四个字，是他全书唯一一次自述动机 —— **这就是他的台词，编不出更好的。**

### shadow 是怎么推出来的

柯拉的原句是「你可以把代价算得很清楚，唯独算不清『我变成了什么』这一项」。
落到七四身上，这句要更狠一层，因为**那一栏不是他自己填的**：

- 他把代价算得极准 —— 拔接口数到二、电量三格半、申诉多一笔，全是算过的；
- 他把人量成了数 —— 一千二百零四段基频；
- **量到最后自己也是十二点七**，三个字符划在带子外壳上；
- 而他听了四年、一个字都没听出来的那句话，恰恰是**一个人说的三个字**；
- 最后系统是这么写的：同一个号两页，人的那一页空着，介质的那一页满了。

**「你量得出所有人，读不出一句话。」** —— 优点（把世界量化）直接推出代价（读不出人话）。
这就是第四节的翻刀，也是柯拉那句「算不清我变成了什么」在本书里的实解。

### ⚠️ gap：他与柯拉唯一真正分开的一轴

| | 柯拉 | 七四 |
|---|:---:|:---:|
| **D8 记账 ↔ 过账** | **+2 记账** | **−2 过账** |

这是全部 10 点距离里的 4 点，占四成。

**柯拉的沉默里有恨；七四的没有。** 柯拉的 light 写着「你反的是压迫本身」——
柯拉知道自己在反什么。七四从来不问「凭什么」：被空编那天，他把四行字看了四遍、
怕自己输错又输了一次号，然后走了。他不算这笔账，他算的是「申诉会多一笔」。

**他不是放下了，是没拿起 —— 他把自己的遭遇当成数据处理。**
这是全书最冷的一处，也是七四区别于所有同型者的地方。

另外两处小分歧一并记着：他比柯拉更依赖程序（D1 +2 / 0），也追问得更多（D7 +3 / 1）。
**他被清出去的原因，正是他去查了那一栏** —— 求知这一维既是他的引擎，也是他的灾因。

### 为什么先是这一个，后来是这两个

七四是第一张，因为第 7 章以他为名、素材最密。格里、艾拉原先被我判成「素材撑不起九轴逐条依据」（格里只在记忆里出现、艾拉只有一场半）—— 那是**误判**：通读 `03_manuscript/` 后确认，格里在第 1 章是实打实的主角（走 B-4 三百四十一个月、记每年两米九、被剔除、把计数器交给七四），并在第 2/7/8/13/14 章持续回响；艾拉在第 2/5/7/8/9/10/11/12/17 章都有在场戏（喂清运工、按胸口判十二点七、讲缝、讲父亲的闭环）。**两人的 basis 每一条都能指到具体段落，不是拍脑袋填的。** 所以 2026-10-15 把两张卡一并补上了。

### 加一个新角色的流程

1. 在 `cast.js` 的 `items` 里加一个对象：`id` / `name` / `hao`（没号写 `null`）/ `jc` / `vec`；
2. 先估他的九维向量 `vec`，在厥初里找最近的一型填进 `jc`（见第六节算法）；
3. 四件套 `core / quote / light / shadow`：**为这个人写**，以配型为底稿但不照抄；
   `quote` 优先从正文里取现成的，`quoteSrc` 记出处；
4. `gap` 写他与配型分得最开的那一轴（优先 D4 共情），这是他区别于同型者的地方；
5. `basis` 九条逐轴填——**每一轴都要能指出书里哪一段**，否则就是拍脑袋填的。

字段语义见 `cast.js` 头注释。探针 `res-cast-probe.cjs` 守：渲染 3 张卡（七四 / 格里 / 艾拉）、
每张配型回查对得上、九轴读数 9 格、依据 9 条、无 console error。
