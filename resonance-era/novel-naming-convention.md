# 《共振纪元》小说命名与标题规范

## 一、小说名称确认

**正式书名**: **《共振纪元》**

### 命名理由

1. **通俗易懂**: "纪元"指一个时代，"共振"通过剧情会自然理解其含义（集体意识觉醒的临界点现象）
2. **主题精准**: 直接指向全书核心——当足够多的人在同一频率上振动时会产生质变效应
3. **长度适中**: 四个字朗朗上口便于传播记忆
4. **系列延展**: 可自然分卷命名如《共振纪元 I: 测地线方程的非线性解》

### 物理概念解释

**"共振"在本书中的含义**:
- 物理学本义：当外力频率接近系统固有频率时振幅急剧增大的现象
- 社会隐喻：当足够多的人在相似的频率上振动时（12.7Hz±0.5Hz），会产生宏观效应
- 剧情体现：集体意识觉醒→共鸣网络建立→系统崩溃的三阶段过程

## 二、章节标题混合式策略

### 总体原则

| 类型 | 占比 | 使用场景 | 示例 |
|------|------|---------|------|
| **定律型标题** | 约 30% | - 虚构宇宙中真实存在的物理法则<br>- 本章情节恰好对应某个物理概念的巧妙应用<br>- 需要强化理论深度或学术氛围的时刻 | 「测地线方程的非线性解」「诺特定理的例外情况」 |
| **事件/话语型标题** | 约 70% | - 重大剧情转折时刻<br>- 关键人物登场或揭露身份<br>- 对话中的金句或宣言<br>- 情感高潮或心理挣扎时刻 | 「仓库里的第三次午夜灯光」「她说：自由意志是否存在？」 |

### 分类标准详解

#### A. 定律型标题（保留条件）

仅用于以下两种情况之一：

1. **虚构宇宙的基础物理法则**:
   - 这些法则是故事世界观的一部分，而非现实世界的科学延伸
   - 例如："空间度规畸变""12.7Hz 共振频率""量子记忆残留效应"
   
2. **核心主题的集中体现**:
   - 本章主要围绕某个物理概念展开深入探讨
   - 该概念对理解后续剧情至关重要
   - 例如："贝尓不等式的背叛"（暗示信任危机）

#### B. 事件型标题特征

- **时空限定 + 具体事件**: 「D-9981 审讯室里的三十七分钟」「凌晨两点废弃仓库的第一盏灯」
- **数字强调突出戏剧性**: 「七个节点形成的六边形」「被删除的第三十七秒」
- **意象画面感强烈**: 「蓝色海面上的白色岛屿」「锈迹斑斑的无线电塔」

#### C. 话语型标题特征

- **直接引语制造悬念**: 「他说：真正的勇气是什么？」「她问：我们是被遗忘的测地线」
- **金句提炼升华主题**: 「黎明前的最后一道曙光」「不是给岁月以文明而是给文明以岁月」
- **内心独白揭示矛盾**: 「如果自由意志不存在那我们还有什么意义」

## 五、特殊情况处理指南

### A. 何时可以突破 30%/70% 的比例限制？

1. **开篇铺垫期**（第 1-5 章）:
   - 可以适当提高定律型比例至 40-50%
   - 原因：帮助读者快速建立世界观认知框架

2. **结局收束期**（最后 3 章）:
   - 可以回归较多定律型标题用于哲学升华
   - 原因：强化主题深度并提供开放思考空间

3. **特殊卷式结构**:
   - 某卷专门探讨某一物理概念时可以临时调整为 60% 定律型
   - 必须在下卷恢复混合比例平衡

### B. 定律型标题的简化技巧

如果一个定律过于复杂难以直接用作标题，可以采用以下方式简化：

| 原定律 | 简化后标题 | 优化理由 |
|--------|-----------|---------|
| "量子退相干导致的集体意识稳定性下降" | 「量子退相干的集体意识」 | 去除冗余修饰词保留核心 |
| "冯·诺依曼架构在社会组织中的类比应用" | 「冯·诺依曼架构的社会学延伸」 | 用"延伸"替代"类比应用"更简洁 |
| "海森堡不确定性原理在人际信任关系中的映射" | 「海森堡不确定性原理的社会应用」 | 聚焦"社会应用"而非具体映射关系 |

### C. 避免标题雷同的检查清单

1. **数字不重复**: 检查是否有多处使用相同的"第 X 次""XX 分钟"等时间限定
2. **动词多样化**: 避免连续使用"XXX 的 XX 模式/形态/机制"这类固定句式
3. **主语轮换**: 确保不同类型的人物（七四/艾琳/蕾娜/K-09848 等）都有机会成为标题焦点
4. **情感梯度**: 保持冷静客观→紧张悬疑→激情澎湃的情绪递进曲线

## 六、附录：标题创作辅助工具

### A. 定律型标题生成公式

```
[虚构宇宙中的物理概念] + [比喻动词] + [社会现象]
例：量子芝诺效应 → 观测者的迟钝 → 量子芝诺效应的迟钝
```

### B. 事件型标题生成公式

```
[具体地点] + [时间点] + [关键动作/物品]
例：废弃仓库 → 第三次午夜灯光 → 仓库里的第三次午夜灯光
```

### C. 话语型标题生成公式

```
[人物称谓] + [引用完整语句] + [省略号或直接结束]
例：阿雅说 → "自由意志是否存在？" → 她说：自由意志是否存在？
```
