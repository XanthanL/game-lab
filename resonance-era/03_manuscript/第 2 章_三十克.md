# 第 2 章 三十克

第 19 扇区协作单元登记处早上六点开门。

门是两扇对开的滑动门，门框上嵌着一条褪色的一米线——线的位置是纪元 0 年定的，那时候门比现在宽。门开的时候会有一声气压释放，很轻，像有人叹了一口气。

七四在五点四十七分到，前面排了三十一个人。

取号机在门右侧，投一个信用点进去，吐一块塑料牌。牌子上印着号码和一个二维码，背面刻着一行小字："本牌不可转让，转让即失效"。七四投了一个信用点——他的余额从三十二点三九变成三十一点三九——拿到 062 号。

---

投币之前他看了这台机器大概二十秒。

机器是固定式的，嵌在墙里。投币口宽二点五厘米，只能进标准信用点——信用点是直径二点二厘米的圆片，厚零点三厘米，金属芯外包一层塑料。

投进去之后机器有一个检测动作：称重、读边齿、验磁。三步，一点四秒。

检测不通过会把币退回来，退的时候响两声，很短促。

七四看了四个人投币。四个人里有一个被退了。那个人把币拿起来，在衣服上擦了一下，又投进去。第二次过了。

塑料牌六厘米乘四厘米，厚零点二厘米。正面印号码和二维码，背面刻着那行小字。

七四研究过"不可转让"这四个字是怎么实现的。

牌子里没有芯片，只有一个二维码。二维码扫出来是一串字符：号码，加一个时间戳，精确到秒。

也就是说，这张牌绑定的是"你在这一秒投了这一个信用点"这个事实，不是你这个人的编号。

既然不绑定编号，那"不可转让"靠什么管？

七四想出来的答案是：转让需要把牌交给别人，交的这个动作会被窗口看见。窗口里坐着人。

所以"不可转让"不是机器在管，是人在看。

他在终端上记：

```
取号牌
  绑定对象：投币时刻（非个体编号）
  "不可转让"的执行者：窗口人员（目视）
  执行依据：无技术校验
```

写完他想了一下，又补了一行：

```
即：这条规则靠人守
```

---

等候区四十七个座位。三十一个人里有十九个站着，因为座位上有十二个坏掉了，坏掉的座位没有修，只是在扶手上贴了一张黄色的纸条。纸条上的字已经看不清了。

墙上挂着一块屏，滚动播放《协作单元管理条例》。七四看过很多遍，今天这一遍他数了一下，一共四十七条。第三条是：

> 协作单元存续期三个月。到期前七日内，双方须共同到场办理续约或解散。逾期未办理者，单元自动解散，双方住房配额各降一档。

第九条：

> 续约申请由系统依据风险耦合系数核定。系数超标者不予续约，申诉窗口为三日。

第二十六条：

> 单元一方被判定不适格或执行剔除后，另一方应在四十八小时内办理注销。逾期不办者，视同维持单元关系，承担连带责任。

七四看到第二十六条的时候想了一下格里。格里没有协作单元——他在三十一年里的最后一份单元关系到期于纪元 1009 年，之后没有再续。登记处对这种人有一个内部说法，叫"独行号"，诺玛告诉他的。

"独行号越来越多。"诺玛当时说，"十年前一天两三个，现在一天十几个。"

大厅在六点整亮灯。三个窗口同时打开：1 号续约，2 号注销，3 号争议。

诺玛在 2 号窗口。

她工号 D-05502，在 2 号窗口坐了十一年。她的右手食指第一节是僵的——纪元 1007 年一次停电，滑动门夹了她的手，系统判定不影响作业功能，没有修复。现在她盖印的时候要用左手压着右手腕借力。

她一上午要经手六十到八十件。

---

从六点整到九点十四分，三个小时十四分。

七四把墙上的条例读完了。四十七条，滚动一轮八分钟，他看了二十四轮。

第九条下面有一行小字，字号比正文小两号。那是实施细则，不是条文，但印在同一块屏上。

```
风险耦合系数 · 计算口径（实施细则第 9-1 号）

取单元双方在近九十日内的四项指标加权平均：
  工种相似度     权重 0.30
  路径重合度     权重 0.25
  能耗曲线相关性 权重 0.25
  维护周期同步率 权重 0.20
加权值 × 2.5 = 系数
系数上限 2.0
```

七四在终端上算了一遍。

两个搬运工组成单元：工种相似度 1.00，路径重合度 0.90（同一条通道同一时段），能耗曲线相关性 0.95（同样的负载同样的偏离），维护周期同步率 0.80（同批出厂的人维护周期往往撞在一起）。

加权：0.30 + 0.225 + 0.2375 + 0.16 = 0.9225。

乘二点五：二点三一。

超标。

也就是说：两个搬运工不能组成协作单元。

他换了一组：搬运工配织网工。工种相似度 0.15，路径重合度 0.30，能耗曲线相关性 0.40，维护周期同步率 0.25。

加权：0.045 + 0.075 + 0.10 + 0.05 = 0.27。

乘二点五：零点六七五。远低于上限。

七四把这个结果看了很久。

系数越低，越容易续约。系数最高的组合，是工种相同、走同一条路、在同一时刻耗同样的能、在同一天做维护的两个人。

系统给这个组合打了二点三一。上限是二点零。

上限这个东西，一般是留给"正常情况"的余量。也就是说，系统在设计的时候，认为不会有人的系数接近二点零。

而两个一模一样的人，系数是二点三一。

七四在终端上写：

```
系数上限 2.0
同类个体系数 ≈ 2.3
→ 上限不是为"异常"留的，是为"同类"留的
```

写完他看着这几行。

他想起格里。格里是独行号，最后一份单元关系到期于纪元 1009 年，之后九年没有再续。

格里是搬运工。他要续约，就得找一个系数低于二点零的人：织网工、清运工、管道工、分拣工。任何一个都行。

他没有。

---

等候区在这三个小时里换了两拨人。

第一拨是早上六点到七点半，来办续约的居多——续约要双方共同到场，两个人得同时有空，所以都赶早。第二拨是八点以后，注销和争议变多。

七四数了：三个小时里叫了六十一个号。其中续约二十七，注销二十四，争议十。

二十七件续约里，七四听见机器念"系数超标，不予续约"六次。六次里有四次是同一工种的组合——两次清运配清运，一次分拣配分拣，一次管道配管道。

那四组人从窗口走开的时候，没有一组吵架。

吵架的是第十号：一个女人办续约，系数从一点八涨到二点四。她签了六个单元期，六年。

机器说"系数由系统动态核定"。

七四后来在终端上补了一行：

```
动态核定 = 系数会自己涨
为什么涨？
```

他没有写答案。

---

等候区有一个人坐了三个小时没动。

那人坐在第十七号座位——那是一个坏座位，扶手上贴着黄纸条。他坐在上面，因为坏座位的扶手是塌的，塌下去的那一侧正好能让他把左腿伸直。他的左腿是僵的，膝盖不能弯。

他八点十七分的时候跟旁边的人说过一句话，七四录到了。

"我办注销。"

"注销什么？"

"我那份。"那人说，"我那份到期三个月了，我一直在拖。"

"拖什么？"

"拖到他执行完。"

旁边的人没接话。

"四十八条。"那人说，"他执行完四十八条之内我得来办。早办了没用，晚办了连坐。"

"连坐是什么？"

"视同维持单元关系，承担连带责任。"那人说，"我背过。第二十六条。"

他把左腿挪了一下，挪的时候膝盖响了一声。

"早办了为什么没用。"

"因为早办了就算主动解散。"那人说，"主动解散，住房配额降一档。他待执行期间我办注销，配额维持原档。"

"所以你等他执行完。"

"所以我等他执行完。"那人说，"等到今天早上七点四十二分。"

七四在终端上记：

```
1018.03.12  等候区 17 号座位
注销申请人，左膝僵直，等待对方执行完毕
等待时长：3 天
依据：第26条 / 第3条
```

他没有记那个人的编号。那个人没有说自己的编号。

---

三个小时里，七四数了续约的通过率。

二十七件续约，通过十九件，不通过八件。

通过的那十九件里，他能听出工种的只有五件——因为窗口不报工种，只报系数。有五件在办的时候，那两个人说话的声音被他录到了，他能从话里听出他们干什么。

五件里，没有一件是同工种。

织网配清运，管道配分拣，织网配搬运，清运配管道，织网配巡检。

七四做了反推：系数低于二点零，工种相似度必须低到什么程度。

细则给了公式。他先取一组中间值：路径重合度零点五，能耗相关性零点五，维护同步率零点五。

零点三零乘 X，加零点一二五，加零点一二五，加零点一零，小于零点八。

零点三零 X 小于零点四五。

X 小于一点五。

工种相似度上限就是一点零，所以在这个条件下，任何组合都能过。

他换一组参数：路径重合度零点九（同扇区同一条主廊），能耗相关性零点九（同工种同负载），维护同步率零点八（同批出厂）。

零点三零 X，加零点二二五，加零点二二五，加零点一六，小于零点八。

零点三零 X 小于零点一九。

X 小于零点六三。

工种相似度必须低于零点六三。

七四在终端上写：

```
同一条路 + 同样的能耗 + 同一天维护
→ 工种相似度必须 < 0.63
→ 即：不能是同一种人
```

写完他看着这两行。

他想起格里。

格里走 B-4 走了三百四十一个月。B-4 这一段同时段在册搬运工一百九十六个。

一百九十六个搬运工，走同一条路，耗同样的能，同一天做维护。

他们之间任何两个组成单元，工种相似度是一点零。

一点零大于零点六三。

所以这一百九十六个人，彼此之间不能组成协作单元。

他们可以和织网工、清运工、管道工、分拣工组成单元——只要系数够低。

但那是编队里另外一列的事。B-4 早高峰编队：第一列清运，第二列管道，第三列织网，第四列搬运。

两列之间隔一点五米。

七四把这个数也记下来了：一点五米。

他不知道为什么要记。

---

062 号在九点十四分叫到。

七四走到 2 号窗口前。窗口的玻璃有一道划痕，从左上角斜到右下角，很旧。

"办什么？"诺玛没有抬头。

"查询。"

"查询不在这里。"她说，"查询在 4 号，4 号在走廊尽头。"

"我要查一个人的注销记录。"

诺玛抬起头。

她的眼睛是标准配置，灰色的虹膜，出厂统一。但她的眼白上有血丝，血丝的走向是从眼角往瞳孔方向，说明长期盯着屏。

"注销记录不公开。"她说。

"《信息管控条例》第 9 条说除绝密级外均可查询。"

诺玛看了他三秒。

"你背过条文。"

"我读过。"

"底层一天有几个读过条文的？"

"不多。"

她把右手从印章上拿开，用左手揉了揉手腕。

"编号。"

"D-10241。"

诺玛的手停了。

大厅里有人在吵。3 号窗口那边，一个女人的声音高起来："我们签了六个单元期了！六年！"窗口里的机器声平静地重复："系数超标，不予续约。"女人说："去年是 1.8，今年怎么就 2.4 了？"机器说："系数由系统动态核定。"

诺玛把视线从七四脸上移开，落在自己的屏上。她的手指在键盘上动了四下。

屏上的数据她没有给七四看，但角度问题，七四看到了前四行。

```
D-10241
状态：已注销
注销类别：个体剔除
注销日期：纪元 1018 年 3 月 3 日
```

七四盯着那一行日期。

3 月 3 日。

今天是 3 月 12 日。

格里的剔除执行是昨天，3 月 11 日。纸条上写着"D-10241 找过我"——格里在昨天之前见过她。

一个 3 月 3 日就被注销的人，在 3 月 3 日之后找过格里。

"你的查询。"诺玛说，"没有结果。"

七四看着她。

"屏上有。"

"屏上的是缓存。"诺玛说，声音没有起伏，"缓存不算查询结果。"

"那什么算。"

"4 号窗口的回执算。"她说，"走廊尽头。"

七四没有动。

诺玛把屏转过去，背对着他。她开始处理下一个人的业务——一个四十来岁的男人，手里捏着一张黄色的单子。

"下一位。"

---

七四没有立刻去 4 号窗口。他在等候区找了个靠边的位置坐下，把录音器调到低增益。

他录了两个小时。

两个小时里他录到：十九个人的脚步，四十七次叫号，三次争吵，一次有人哭——哭声很短，被另外两个人劝住了，前后一共十一秒。他还录到窗口后面的打印机，每盖一次章就咔一声，两个小时里咔了一百三十七下。

十点零三分，3 号窗口开始处理一件争议。

---

争议业务的流程是：申请人陈述，机器记录，机器调取系统数据，机器给出核定结果。申请人可以申诉三次，三次之后机器不再回答。

那个人申请的是"系数复核"。他的系数是二点一，他要求系统解释这个数是怎么来的。

机器调出了四项：

```
工种相似度      0.85   权重 0.30
路径重合度      0.80   权重 0.25
能耗曲线相关性  0.90   权重 0.25
维护周期同步率  0.70   权重 0.20
```

七四在等候区听着，在终端上跟着算。

零点八五乘零点三，零点二五五。零点八零乘零点二五，零点二零。零点九零乘零点二五，零点二二五。零点七零乘零点二零，零点一四。

和：零点八二。

乘二点五：二点零五。

机器报的是二点一。差零点零五，四舍五入。

那人说："我不接受这个算法。"

机器说："算法不可争议。"

"我不要争议算法。我要争议那四个数。"

"请指出哪一项有误。"

"路径重合度。"那人说，"我走 B-7，他走 B-4。两条通道，怎么会有零点八。"

机器停了零点九秒。

"路径重合度计算口径：以双方在近九十日内的作业路径几何重合比例计算，不区分通道编号。"

"我们不走同一条通道。"

"B-7 与 B-4 在第 3 至第 9 路口区段共用同一条主廊。"机器说，"该区段长度四百二十米，占双方路径的百分之五十二。"

"那是同一条走廊，不是同一条路。"

"路径重合度不区分走廊与路。"

那人沉默了几秒。

"申诉第一次。"机器说。

"我申诉。"那人说，"我要求人工核定。"

"争议业务不设人工核定。"

"那我申诉什么？"

"你可以申诉数据有误。请指出数据。"

"数据就是从你这个口径出来的。"

"口径不可争议。"

"申诉第二次。"机器说。

那人沉默得更久。

"我申诉。"

"申诉第三次。请陈述。"

"我没有东西可陈述了。"

"申诉结束。核定结果维持：系数 2.1，超标，不予续约。"

机器盖了章。咔。

那人从窗口走开。他手里的回执垂着，他没有看。

七四在终端上写：

```
可申诉：数据
不可申诉：口径
数据由口径生成
```

写完他看了一遍，把最后一行删了。

改成：

```
申诉窗口：三次
三次内容：数据 / 数据 / 无
```

---

十点四十分，他录到了一段不一样的。

那是织网工的脚步。

织网工走路的方式和搬运工不同。搬运工的步子沉，落脚时整个脚掌同时着地；织网工的步子碎，前脚掌先落地，因为他们的膝盖长年保持半屈——他们要在空间裂缝的位置上蹲很久。

艾拉在 1 号窗口前面第三个。

她穿着织网工的连体工装，左臂从肘部往下缠着绷带。绷带是标准的灰蓝色，配给点领的，一卷三米，一周领两卷。她领了三年。

绷带上有一块渗出来的深色，直径大概四厘米，已经干了。

她前面第二个人办完了，前面第一个人正在办。

七四看着她的后背。她的肩胛骨在工装下面很清楚——太清楚了，说明她瘦。织网工的配给比搬运工高两档，但她看起来比哈鲁还瘦。

十一点零二分，等候区发生了一件事。

一个坐在角落里的男人站了起来，走了两步，然后坐到了地上。

没有人立刻过去。大厅里有三十多个人，所有人都在看自己的号码牌，或者看墙上的屏。坐下的那个男人五十岁上下，穿着清运工的橙灰色工装，他的手在地上撑了一下，没有撑住，侧着倒了下去。

差不多过了六秒，艾拉站起来。

她走过去——她走得不快，因为她的膝盖——蹲下去，把那个男人扶起来靠在墙上。然后从内袋里掏出自己的营养膏，一百七十克，铝箔管，还剩一半。

她把管子递过去。

男人接了。他的手抖得很厉害，管子在他手里晃。他自己挤不出来，艾拉帮他挤的，挤了大概三十克。

男人吃了。吃了十一秒。

艾拉蹲在那里看着他吃完，然后站起来，回到自己的位置。

整个过程四分二十秒。

七四一直在录。

四分二十秒之后——准确说是四分二十六秒——大厅里所有的腕式计数器同时响了一声。

不是警报。是一种很轻的提示音，一个短促的双音，所有人一年要听几十次。

然后所有人都在看自己的手腕。

七四也看了。

```
检测到非对称能量转移
依据《能量守恒条例》第 3 条，已执行平衡修正
转移量：营养膏 30g（≈112 千卡）
发起方账户扣减：0.14 信用点
接收方账户增加：0.00 信用点
```

七四看着最后一行。

接收方账户增加：0.00。

他把录音器举高了十厘米，对着艾拉的方向。

艾拉在看自己的手腕。她看了大概三秒，然后把营养膏管卷起来，塞回内袋。

她的脸上没有表情。仿生人的脸本来就做不出太复杂的表情，但七四在这张脸上待了四年——他在通道里见过她几十次——他能分辨出她的嘴角是松的还是紧的。

是松的。

她早就知道会扣。

---

那个清运工在十一点十一分站起来，走了。

他走得不快，但走得直——比坐下之前直。三十克营养膏，一百一十二千卡，一个五十岁上下的清运工大概能撑四个小时。

七四看着他走到门口。滑动门开了一次，气压释放了一声，门合上。

他没有回头。他不知道是谁给他的。

七四后来分析过这段录音。

四分二十六秒里，那三个人——清运工、艾拉，还有劝他的另外两个人——一共说了十句话。十句里有七句是"没事""你坐着""别动"。

另外三句：

"我三天没吃。"（清运工，11:02:14）

"吃了。"（艾拉，11:03:07）

"谢谢。"（清运工，11:06:03）

"谢谢"是在十一时六分零三秒说的。那时候艾拉已经回到自己的位置上，隔着十四米。

也就是说：这两个字艾拉没听见。或者听见了，没有反应。

七四在记录里写：

```
1018.03.12  11:02—11:06  登记处等候区
事件：非对称能量转移 30g
发起方：织网工（艾拉）
接收方：清运工（编号未获）
发起方扣减  0.14
接收方增加  0.00
接收方发言："谢谢"（11:06:03，发起方已离场）
```

他把最后一行单独标了出来。

不是因为"谢谢"有什么意义。是因为这一整件事里，唯一一句道谢，是那个收到零的人说的。

---

十一点十九分，艾拉到 1 号窗口。

"续约还是解散？"窗口里的机器问。

"解散。"

"请说明理由。"

"双方协商一致。"

"对方未到场。依据条例第 3 条，续约或解散须双方共同到场。"

"他昨天被判定不适格。"艾拉说，"执行窗口四十八小时。"

机器停了零点七秒。

"正在核验……已核验。D-08816，巡塔人，不适格判定时间：纪元 1018 年 3 月 11 日 07:42。执行状态：待执行。"

"依据条例第 26 条，你应在四十八小时内办理注销。"

"我在办。"

"注销与解散不同。"机器说，"单元一方待执行期间，另一方办理注销，不视为主动解散，住房配额维持原档。"

"我知道。"艾拉说，"我问的不是配额。"

"请问什么？"

"我能不能把配额转给他。"

机器停了一秒二。

"住房配额不可转移。"

"能量配额呢？"

"不可转移。"

"信用点呢？"

"可转移。转移税率：百分之百。"

艾拉沉默了一下。

"百分之百。"

"依据《能量守恒条例》第 3 条，非对称转移须执行平衡修正。转移税率由系统动态核定，当前为百分之一百。"

"也就是说我给他一百，他收到零。"

"是。"

"那中间那一百去哪了？"

"归入系统平衡账户。"

艾拉把手从窗口台上拿下来。

她的左臂绷带在抬手的时候扯了一下，她抿了抿嘴。

"我父亲死于这个。"她说。

"你的陈述与本次业务无关。"机器说。

"我知道。"艾拉说，"我说给自己听。"

"请确认注销。"

"确认。"

机器盖了章。咔。

艾拉把回执拿起来。回执是一张长条纸，上面印着两个编号、一个时间戳和一个二维码。她的编号在上面，塔恩的编号在下面。塔恩那一行的末尾有一个词，用红色印的：

```
待执行
```

她把回执折了两折，塞进内袋，和那管营养膏放在一起。

---

十一点二十六分，七四去了 4 号窗口。

---

4 号在走廊尽头，是四个窗口里唯一没有叫号机的。它也不排队——因为它是一台机器。

机器嵌在墙里，只有一个输入区和一个出纸口。输入区是一块触屏，屏的四角磨得发白，说明用的人多。出纸口在下方，宽十二厘米，出来的纸是长条，宽五厘米。

七四输 D-10241。

处理时间三点二秒。

出纸口吐出一条，上面一行字：

```
该编号不在公开查询范围内
```

七四又试了三次。

第一次，输"本月注销名单"。

```
权限不足
```

第二次，输"注销记录明细"，附日期 1018.03.03。

```
该统计项不提供明细
```

第三次，输"D-10"，后面不输数字，只输前缀。

处理时间四点一秒——比前两次长。

```
匹配 0 条
```

七四盯着"0 条"。

D-10 是一个前缀。编号是 D 加四位到五位数字，D-10 开头的编号应该有一千个：D-10000 到 D-10999。

一千个编号，匹配零条。

不是说这一千个都注销了，也不是说这一千个都保密。是说这一千个**没有一个能被查询到**。

他换了几个前缀试：D-04（格里那一段）、D-08、D-05（诺玛那一段）。

D-04 匹配一百四十七条。D-08 匹配二百零九条。D-05 匹配一百八十八条。

只有 D-10 是零。

---

七四在终端上查了"公开查询范围"。

这一条是公开的——《信息管控条例》第 9 条的实施细则。

```
第 9 条 · 公开查询范围

  绝密级    不可查询
  内部级    需权限
  公开级    可查询
  未分级    不在查询范围内
```

四级。

"不在查询范围内"对应的不是"绝密"，是"未分级"。

也就是说：D-10241 不是被藏起来了，是**从来没有被分过级**。

一个编号，如果从来没有被分级，它就不在任何查询系统里。

但它出现在注销记录上。注销记录是有分级的——诺玛的屏上有 D-10241 的四行。

七四把这两件事放在一起：

一、D-10241 在注销系统里存在（诺玛的屏上有）。
二、D-10241 在查询系统里不存在（匹配 0 条）。
三、D-10 这一个前缀段整体匹配 0 条。

第三条是关键。如果不是一个人，是整整一千个编号都不在查询系统里，那就不是"某个人被藏起来了"。

是"这一整段编号被做成了这样"。

他想起昨天在查询台上查 D-04117 的结果：查询无结果。

格里也是"无结果"。但 D-04 这一段匹配一百四十七条，说明 D-04117 那个位置本来应该有东西，是被拿走了。

D-10241 不一样。D-10241 那一段从来就是空的。

七四在终端上写：

```
D-04117  段内匹配 147  个体：查询无结果  → 被拿走
D-10241  段内匹配 0    个体：查询无结果  → 从来没有
```

写完他想了一下，在第二行后面加了一个问号。

不是"为什么没有"，是"没有的这一千个位置，是用来干什么的"。

---

十二点零七分，诺玛的窗口前没有人。

七四走过去。

"4 号窗口在走廊尽头。"诺玛没有抬头。

"我去过了。"

"结果呢？"

"回执上写着'该编号不在公开查询范围内'。"

诺玛把印章放下。

她的手在桌上平放了三秒，然后翻过来，掌心朝上。掌纹很乱，手指第一节僵着的那根微微翘起。

"你到底是什么人？"她问。

"搬运工。"

"搬运工一天挣多少？"

"零点四到零点九单位。看路径偏离。"

"你投了一个信用点取号，等了三个小时，为了查一个不公开的人。"诺玛说，"搬运工不会这么花信用点。"

七四没有回答。

"你录了一上午。"诺玛说，"从六点零四分录到现在。我看见你的灯在闪。"

"我在录声音。"

"录什么声音？"

"这里的。"

诺玛看了他很久。

---

她的右手放在桌上，掌心朝下。食指第一节僵着，翘起来大概十五度。

"纪元 1007 年。"她说。

"什么？"

"我的手。"她说，"那年第 19 扇区停了六个小时电。滑动门在断电的时候走紧急闭合，设计上是四秒关到底。那天它关了两秒。"

"两秒。"

"两秒。"诺玛说，"我那时候在 1 号窗口，手在窗口台上。"

七四看着那只手。食指第一节的关节没有活动度，皮肤是标准的仿生肤色，但那一节的表面比别处亮一点——被夹过之后重新校准过外壳。

"系统判定不影响作业功能。"诺玛说，"这是原文。判定书上说：食指第一节活动度丧失不影响盖章作业，可通过辅助手位完成。"

"辅助手位。"

"左手压着右手腕借力。"她说，"他们试了一次，试通了，就写进去了。"

"你压了十一年。"

"我压了十一年。"诺玛说，"一天六十到八十次。十一年，一年三百二十天，算下来是二十三万次上下。"

她把右手翻过来，掌心朝上。

"你现在看我的掌纹。"她说，"和你的不一样。"

七四看了一眼。她的掌纹在食指根部有一道断口——不是磨损，是被压出来的，深大概零点五毫米。

"左手压出来的。"诺玛说，"压了二十多万次。"

---

"2 号窗口的注销，系统分几类？"七四问。

"三类。"诺玛说，"到期解散、逾期解散、一方剔除。"

"你分几类？"

诺玛看了他一眼。

"我分四类。"她说，"第四类是原因栏空的。"

"为什么单独分一类。"

"因为前三类的原因栏都填。"她说，"到期解散填'存续期满'，逾期解散填'逾期未办理'，一方剔除填对方的编号和判定日期。只有第四类什么都不填。"

"什么都不填，系统怎么处理？"

"系统照常过。"诺玛说，"盖章，出回执，进档案。系统不检查原因栏。"

"不检查？"

"十一年，我从来没有见过系统因为原因栏空而退回一件业务。"她说，"我见过系统因为日期格式错退回的，因为编号少一位退回的，因为印章压力不足退回的。没有因为原因栏空退回的。"

"那这一栏是给谁看的。"

诺玛没有立刻回答。

大厅里叫号机响了一声。

"给我看的。"她说。

---

大厅的灯在十二点整切了一次，从上午模式切到下午模式，色温变了，光线变白了一点。光变的时候，诺玛眼白上的血丝更清楚了。

"你知道 2 号窗口一天办多少件注销？"她问。

"多少？"

"七十一件。昨天七十一件，前天六十八件。"诺玛说，"十年前一天十九件。"

"为什么涨？"

"因为独行号涨。"她说，"因为不适格涨。因为两个人绑在一起，一个人掉了，另一个就得来注销。"

她把手收回去。

"你要查的那个人。"

七四等着。

"D-10241。"诺玛说，"注销日期 3 月 3 日。类别：个体剔除。"

"剔除原因？"

"系统给的原因栏是空的。"

"空的？"

"十一年里我见过四次空的原因栏。"诺玛说，"每一次，那个人都不是真的被剔除了。"

七四没有说话。

"我不告诉你这是什么意思。"诺玛说，"因为我不知道。我只告诉你我看见的：四次空栏，四个人，其中两个后来在别的扇区的配给名册上出现过。"

"出现过？"

"名字出现过。编号一致。"诺玛说，"但配给的发放记录是空的——名字在名册上，东西没发。"

"什么意思？"

"意思是有人把名字留在名册上，但不去领东西。"

七四想了一下。

"为什么？"

"四次。"七四说，"你能说说是哪四次吗？"

诺玛把印章放下。

"我不能给你编号。"她说，"我能给你时间。"

"时间也行。"

"第一次纪元 1011 年，第二次 1013 年，第三次 1015 年，第四次上个月。"

七四在终端上记下这四个年份。

"两年，两年，三年。"他说。

"你算这个干什么。"

"看有没有规律。"

"没有规律。"诺玛说，"我算过。四次加起来七年，平均一点七五年一次。这个平均没有意义，样本只有四。"

"四次里有几次是女的？"

诺玛看了他一眼。

"三次。"

"注销类别？"

"三次'个体剔除'，一次'到期解散'。"她说，"第四次不是剔除。"

"到期解散也会空栏？"

"会。"诺玛说，"那一次两个人一起来办的，双方到场，双方签字，存续期满，系统盖章，原因栏空的。"

"双方都到场还会空？"

"双方都到场还会空。"她说，"这是我记了十一年的原因。我本来以为空栏跟'人不见了'是连着的——人没了，所以没法填原因。那一次我看见两个人，两个都活着，都签了字。栏还是空的。"

七四想了一下。

"那两个人后来怎么样。"

"我查过一次。"诺玛说，"两个编号，一个在名册上，一个不在。在名册上的那个，配给发放记录是空的。"

"和你说过的那两个一样。"

"一样。名字在名册上，东西没发。"

"三个了。"七四说。

"三个。"诺玛说，"第四个我没查。"

"为什么没查。"

诺玛没有立刻回答。她把右手从桌上拿起来，又放下。

"因为第四个是我自己办的。"她说。

七四等着。

"纪元 1015 年。"诺玛说，"那时候我在 1 号窗口。我和一个人有一个单元，存了四年。到期那天我们两个都去了，都在场，都签了字。系统盖章，原因栏空的。"

"那个人呢？"

"在名册上。"她说，"配给发放记录是空的。"

"你见过他吗。"

"我在这个窗口坐了十一年。"诺玛说，"我每天看名册。他在上面。每天。"

"你没去找过他。"

"找过一次。"她说，"三年前，我请了一天假，去了他名册上的扇区。"

"找到了吗。"

"找到了那个单元。"诺玛说，"门是锁的。锁的意思是里面有人，或者系统认为里面有人。"

"你敲门了。"

"敲了。"

"几下。"

"七下。"

"有人应吗。"

"没有。"

她把印章重新拿起来，在手里转了半圈，摆正。

"这就是我知道的全部。"她说，"四次空栏，四个人，三个在名册上不领东西，一个我没查完。你要从中得出什么，你自己得。我不给结论。"

"为什么不给。"

"因为我在这个窗口坐了十一年。"诺玛说，"十一年里我得出过七个结论。对的两个，错的五个。错的那五个，每一个我都信了很久。"

"那你现在信什么。"

"我现在什么都不信。"她说，"我只记数。"

---

"我不知道。"诺玛说，"我猜有两个可能。一个是那个名册是旧的，没清干净。另一个是——"

她停了。

"另一个是什么？"

"另一个是有人故意留着。"诺玛说，"留一个名字在上面，让它看起来还在。"

大厅里叫号机响了一声。1 号窗口叫了 118 号。

诺玛把印章拿起来。

"你的事办完了。"她说，"下一位。"

七四没有动。

"独行号。"他说，"这个词是谁起的？"

诺玛正在把一摞回执对齐。她停了一下。

"不知道。"她说，"我进来的时候就有。"

"你什么时候进来的。"

"纪元 1007 年。"她说，"那年我二十一——按出厂日期算。"

"那时候就有这个词。"

"那时候就有。"诺玛说，"我第一年在这个大厅，听见过有人喊'独行号过来'。那时候窗口只有两个，1 号和 2 号，没有 3 号。"

"3 号什么时候加的。"

"纪元 1012 年。"她说，"争议业务多到 1 号窗口处理不完，就加了 3 号。"

"加了之后争议变多还是变少。"

"变多。"诺玛说，"因为原来没有地方申诉的人，现在有地方了。"

"那不应该是好事吗？"

"是好事。"她说，"但是好事和'争议变少'不是一件事。"

七四想了一下。

"你们内部怎么用这个词。"

"叫号的时候。"诺玛说，"一个人来办注销，如果他名下没有单元关系，系统会在他的号前面加一个标记。我们不喊号，我们喊'独行号'。"

"为什么不喊号。"

"因为独行号的业务办得快。"她说，"没有单元关系，就没有对方要核验，没有配额要分割，没有连带责任要计算。一件独行号的注销，平均四分十二秒。一件有单元关系的注销，平均十九分钟。"

"所以你们先办独行号。"

"所以我们先办独行号。"诺玛说，"一天七十一件，如果全是独行号，我四点就能下班。"

"但独行号越来越多。"

"独行号越来越多。"她说，"十年前一天两三个，现在一天十几个。按这个数算，我应该越来越早下班。"

"你几点下班？"

诺玛看着他。

"十八点。"她说，"十年前也是十八点。"

七四把这个记下来：业务变快了，下班时间没变。

"多出来的时间用来干什么？"他问。

"我不知道'多出来'这个说法对不对。"诺玛说，"我知道的是：十年前我一天经手十九件，现在七十一件。十年前一件十九分钟。"

"现在一件多少？"

"现在一件平均十六分钟。"她说，"比十年前快三分钟。"

七四在终端上算：

```
十年前  19 件 × 19 分钟 = 6 小时 01 分
现在    71 件 × 16 分钟 = 18 小时 56 分
```

他写完第二行，手停了一下。

十八小时五十六分钟。

一天的工作时间是八小时。

诺玛看着他写的数。

"对。"她说。

"那你怎么做完的。"

"我做不完。"诺玛说，"我今天做完六十三件，还有八件在系统里排着，明天接着办。"

"排着的八件会怎样。"

"会往后推。"她说，"推到四十八小时窗口过了，就变成'逾期未办理'。逾期未办理，视同维持单元关系，承担连带责任。"

"责任算谁的。"

"算申请人的。"诺玛说，"系统不会算我。"

七四看着那两个数字：六小时零一分，十八小时五十六分。

他没有问"那这十二小时五十五分去哪了"。

他问的是别的。

"这八件，明天还是你办？"

"是我办。"

"后天呢？"

"后天还有后天的。"诺玛说，"队列不会空。我十一年里见过队列空的时候，一次，纪元 1009 年停电那次。"

"停电那天队列空了。"

"停电那天什么都没有。"她说，"那是我在这里十一年，唯一一次没有人在等。"

她把那摞回执对齐，放进抽屉。

"下一位。"她说。

---

七四在登记处待到下午三点。

三点十四分，他在走廊尽头遇到了艾拉。

她靠在墙上，正在把绷带重新缠一遍。旧的那卷解下来了，扔在脚边的垃圾桶里——垃圾桶是满的，她的绷带掉在外面，她没有捡。

"我能问你一件事吗？"七四说。

艾拉抬头。

她的眼睛是灰的，和七四的、和诺玛的一样，出厂统一配置。但她的右眼瞳孔比左眼大零点三毫米——七四第一次见她时就注意到了，那是神经损伤，不可逆。

"你在录我。"她说。

"我在录声音。"

"你从十点四十录到现在。"

七四没有否认。

艾拉把新绷带缠到一半，停下手。

"你录到什么了？"

"一百三十七次盖印。"七四说，"十九个人的脚步。你给那个人营养膏的时候，你的呼吸是每秒零点八次。你吃完自己的那份是每秒零点九次。"

"这说明什么？"

"说明你在给他之前就已经饿了。"

艾拉看着他。

走廊里的灯管有一根在闪，闪的频率大概每秒两次，闪了三天没人换。

"你想问什么？"她问。

"你把配额给他，系统扣你零点一四。"七四说，"你知道会扣。"

"我知道。"

"那你为什么给。"

艾拉把绷带缠完，打了个结。

"因为他在我前面三步远的地方坐在地上。"她说，"这个距离我听得见他的呼吸。"

"听呼吸能听出什么？"

"能听出他三天没吃东西。"艾拉说，"三天没吃东西的人呼吸里有酮味。你闻不到，我们闻得到。"

七四的嗅觉模块是标准配置，能分辨四百七十种气味分子。酮类不在优先识别列表里。

"所以你给了。"

"所以我给了。"

"你损失了零点一四信用点。"七四说，"你的余额是多少？"

艾拉笑了一下。那个笑很浅，只持续了零点七秒。

"这个问题,"她说，"你不该在走廊里问。"

"那该在哪儿问？"

"在没有录音器的地方。"她看了一眼他的领口，"或者说，在录音器关掉的地方。"

七四抬手，把录音器关了。

红灯灭了。

"现在可以问了。"他说。

艾拉靠回墙上。她的左臂垂着，缠好的绷带在灯光下是灰蓝色的。

"三点零六。"她说。

"什么？"

"我的余额。"艾拉说，"三点零六单位。"

七四算了一下。

织网工的配给比搬运工高两档，但织网工的装备损耗更快——纳米凝胶、绷带、裂缝填充剂，都从个人账户走。她的支出项比他多七项。

"你的裂口。"他说。

"零点三毫米。"艾拉说，"上周零点二。"

"扩大速度。"

"每周零点零一到零点零二。"她说，"到零点五就不能上裂缝了。不上裂缝就没有织网工的配给。"

"多久到零点五？"

"十到二十周。"

---

"裂缝是什么？"七四问。

艾拉把刚缠好的绷带往下拽了一点，露出手腕内侧。

那里有一条暗色的细线，宽度不到半毫米，从腕横纹往上延伸大概四厘米。不是伤口——伤口是红的，这个不红。

"空间裂缝在结构上有断口。"她说，"断口的边缘不是平的，是锯齿。织网要沿着断口织，织的时候手要贴着边缘走。"

"边缘割手。"

"不是割。"艾拉说，"是渗。裂缝那一侧的应力场和这一侧不一样，手贴上去，两层之间的分子键会被拉开。一次拉开一点点。"

"一次多少。"

"零点零零几毫米。"她说，"一天几十次。"

"所以是累积的。"

"所以是累积的。"

"纳米凝胶是什么。"

"补分子键的。"她说，"涂上去，渗进去，把断掉的键接回去。一支三十克，够补二十次。"

"一支多少信用点？"

"一点四。"

七四算了一遍：一天几十次，一支二十次，一天要两支多。两支二点八。

"你一天挣多少？"

"一点一到一点四。"艾拉说，"看裂缝的位置。位置好的一天一点四，位置差的一天一点一。"

"那不够。"

"不够。"艾拉说，"所以我不上裂缝的那几天什么都不用。那几天只拿基础配给。"

"不上裂缝的日子有多少？"

"这个月九天。"她说，"上个月六天。前年一个月两天。"

七四把这三个数按时间排了一遍：前年两天，上个月六天，这个月九天。

"为什么越来越多。"

"因为派工评级。"艾拉说，"裂口零点二的时候评级 B，零点三的时候评级 C。C 只能上小裂缝，小裂缝的工分是大的一半。"

"到零点五呢？"

"到零点五评级 D。"她说，"D 不上裂缝。不上裂缝就没有织网工的配给，只有基础配给。"

"基础配给多少？"

"一天零点三。"她说，"够活，不够补。"

七四把这个账走了一遍。

零点三的收入，一点四一支的凝胶。三天半一支。

不补，裂口从零点三往零点五走，十到二十周走到头。

补，一天支出二点八，收入一点一到一点四，净负一点四到一点七。

"这是个闭环。"他说。

"这是个闭环。"艾拉说，"我父亲走的就是这个。他攒了六十三单位，走的也是这个。"

---

她顿了一下。

"塔恩是十四周前开始咳的。"她说，"巡塔人在塔上吸的东西，系统不计入职业病。他自己攒了两年，攒到四十一单位，够换一副肺。"

"够换吗？"

"够换一半。"艾拉说，"换一半的肺不能上塔。不上塔就没有巡塔人的配给。"

---

"巡塔人在塔上吸什么？"七四问。

"粉尘。"艾拉说。

"什么粉尘？"

"我不知道成分。"她说，"塔在地面上，地面上有什么，底下没有人知道。塔上的空气过滤是三层：第一层滤颗粒物，第二层滤化学，第三层滤生物。"

"三层还不够？"

"三层够。"艾拉说，"问题是滤芯。"

"滤芯怎么了。"

"更换周期九十天，实际更换周期一百六十天。"她说，"因为滤芯不在消耗品目录里，它算'结构件'。结构件更换要报计划，计划一年批一次。"

"所以九十天的滤芯用一百六十天。"

"用一百六十天。"艾拉说，"第一百天往后，过滤效率掉到百分之六十。掉到百分之六十以后，二点五微米以下的东西就过来了。"

"过来了怎么样。"

"沉积在肺里。"她说，"仿生人的肺没有自净功能。人类的肺会咳，会把东西排出去。我们的不会。"

"所以塔恩咳。"

"塔恩咳。"艾拉说，"咳这个动作本身不是病，是胸腔振动器在做代偿——振动器试图把沉积的东西震出来。"

"能震出来吗？"

"震不出来。"她说，"但振动器会一直做，做到它自己的效率掉下来。他上个月的效率是负百分之十一，这个月负百分之十六。"

七四知道这个数是什么意思。他自己的胸腔振动器效率是负三点一，维护站判定"在正常范围内"。

负十六不在任何正常范围内。

"换一副肺多少？"

"八十二。"艾拉说，"他攒到四十一。"

"一半。"

"一半。"她说，"换一半的肺，通气量是百分之四十七。塔上作业要求通气量在百分之八十以上。"

"所以换一半没用。"

"换一半没用。"艾拉说，"要换就得换整副。整副八十二，他有四十一。"

"差四十一。"

"差四十一。"她说，"我能给他的，是四十一点零六。系统抽走四十一点零六，他收到零。"

七四没有说话。

"你算过这个数吗？"艾拉问。

"算过。"

"算出来是什么。"

"你把他要的那四十一给他，你们两个人加起来还是四十一。"七四说，"现在是你三点零六，他四十一，一共四十四点零六。给完了是他四十一，你三。少了三点零六。"

"少三点零六。"

"转移一点，系统就吃掉一点。"七四说，"转移多少吃多少，吃到最后两边加起来比原来少。"

"这个叫什么？"艾拉问。

"我不知道叫什么。"七四说，"我知道它不是税。税抽一部分，东西还在。这个抽完，东西没了。"

"那它是什么？"

"是让两个人之间的东西消失的办法。"七四说。

艾拉看着他。

走廊里那根灯管闪了一下。

"你说得对。"她说，"但是你说漏了一半。"

"漏了什么？"

"它不是让东西消失。"艾拉说，"它是让人明白，东西本来就传不过去。"

---

"所以他昨天被判不适格。"

"所以他昨天被判不适格。"艾拉说，"他四十一单位，我三点零六。他要把那四十一给我，系统抽走四十一点。"

"转移税百分之一百。"

"百分之一百。"艾拉说，"你不觉得这个数字很奇怪吗？"

七四想了一下。

"百分之百意味着转多少收多少。"他说，"那就不叫税。"

"那叫什么？"

"叫没收。"

艾拉点了点头。

走廊里那根灯管还在闪。

"我父亲是第十四任织网工。"她说，"他死的时候我十九岁。他攒了六十三单位，够换一整副肺，但他要的不是肺——他要的是纳米凝胶，治手上的裂口。凝胶不在医保目录里。"

"为什么不在？"

"因为目录是系统定的。"艾拉说，"系统说织网工的裂口不属于职业病，因为裂口是'个体操作精度不足'导致的，不是工作环境导致的。"

"这是错的。"

"这是对的。"艾拉说，"在系统里它是对的。因为系统不需要它错。"

七四没有说话。

他把录音器重新打开。红灯亮起来，一秒一闪。

"你又开了。"艾拉说。

"我在录你说的话。"

"为什么？"

"因为你的声频是 12.9Hz。"七四说。

艾拉看着他。

"什么？"

"你说话的时候，声带的基频在 12.9Hz 附近。"七四说，"不是你的声音——是声音下面那层。人的耳朵听不见，采集器能采到。"

"你什么时候录的？"

"十点五十二分。"七四说，"你给那个人挤营养膏的时候。"

艾拉沉默了几秒。

"这个数字有什么意义？"

"我不知道。"七四说，"但我听过四次。格里是 12.7。我自己的维护日志里也有一行 12.7。你是 12.9。还有一次在管道井里，洛恩说话的时候，是 12.8。"

"12.7、12.8、12.9。"

"是。"

"你想说这是一个范围。"

"我想说这不是巧合。"

艾拉把头转过去，看向走廊尽头。尽头是一扇窗，窗外是第 19 扇区的中层立面——灰白色的墙，一格一格的窗，每一格后面是一个居住单元。墙很高，看不到顶。

"格里。"她说，"你刚才说格里？"

"D-04117。昨天执行。"

"他死了？"

"我不知道。"七四说，"剔除不等于死亡。系统只说'不进入任何统计口径'。"

"那他现在在哪？"

"不知道。"

艾拉从墙上离开。

"我父亲死的时候，"她说，"我要去领他的东西。登记处说，剔除个体的遗留物不具备保护价值，谁都能拿。我去了，柜子空了。有人比我早到两个小时。"

"拿了什么？"

"什么都拿了。"艾拉说，"包括他攒的六十三单位——他没花完，六十三单位在芯片里，芯片被人拿走了。"

"芯片能转信用点？"

"不能。"艾拉说，"芯片里存的是记录，不是钱。但有人拿走了。"

她朝走廊另一头走了两步，停下来。

"你要找 D-10241。"她说。

七四没有否认。

"格里留了东西给我。"他说。

"什么东西？"

"一块芯片。上面写着 D-10241 找过他。"

艾拉回过头。

灯管闪了一下。她的右眼瞳孔比左眼大零点三毫米，在闪的那一瞬间两个瞳孔一起收缩，收缩的幅度不一样。

"3 月 3 日注销的人。"她说。

"你知道？"

"我不知道。"艾拉说，"我只知道一件事——在我父亲那一辈，有一个说法。"

"什么说法？"

"他们说，"艾拉说，"被注销的人有两种。一种是真的没了。另一种是——"

她停了。

走廊尽头有人推门进来，是登记处的清洁工，推着一辆车，车轮碾过地面接缝，发出那种湿的、短促的响。

艾拉等那辆车过去。

"另一种是什么？"七四问。

"另一种是，"她说，"被注销了，但还没有走完流程。"

"流程？"

"我不知道流程是什么。"艾拉说，"我只知道我父亲死前说过一句话。他说：他们不是把你删掉，他们是把你从名册上挪走。删掉和挪走不一样。"

"哪里不一样？"

"删掉的东西找不回来。"艾拉说，"挪走的东西——"

她没有说完。

清洁工的车在走廊另一头停下了，开始倒垃圾。垃圾桶盖打开的声音很响，一下，两下，三下。

"挪走的东西能找回来。"七四说。

艾拉看着他。

"这是你说的。"她说，"不是我说的。"

她转身走了。走出七八步，她抬起右手，没有回头，只是把手举了一下，然后从内袋里掏出那管营养膏，空了的那管，扔进了走廊边的回收槽。

铝箔管落进去的时候响了一声。

---

那一声七四录到了。

一声，短促，铝箔撞在回收槽的金属内壁上。他后来分析过这段：频段在两千到四千赫兹之间，衰减时间零点一八秒。

空管三十克，铝箔壁厚零点一毫米。

```
1018.03.12  15:2x  走廊回收槽
事件：空营养膏管入槽
发起方：织网工（艾拉）
声学特征：2—4 kHz，衰减 0.18 s
```

他记这一条，不是因为这一声有什么意义。

是因为他这一整天录了两百七十多段声音，其中只有四段是"东西被扔掉"的声音：三张被撕的票据，和这一管。

撕票据的那三个人，撕完就走了。扔管子的这个人，扔完也走了。

七四把四段并排放着听了两遍。

四段的共同点：都是空的。票是纸，管是铝。都是用完的东西，都不再承载任何数据——票据上的数字已经进系统了，管子里的东西已经被人吃了。

扔掉它们不损失任何东西。

但艾拉把那管空的营养膏在内袋里放了一整天。她十一点零二分用它喂了一个人，喂完之后卷起来塞回去，一直放到下午三点二十多分才扔。

七四在记录下面补了一行：

```
空管保留时长：约 4 小时 20 分
```

他没有解释这一行。

七四后来回想过这件事。他想不出原因。想不出原因的事他一般记下来，不往下推——这是他给自己定的规矩，定在纪元 1015 年。

---

七四在登记处门口站到三点四十七分。

他没有再进大厅。他把录音器举在领口，录了五分钟门口的声音：滑动门开合的气压声、取号机吐牌的声音、有人投币、硬币落进槽里。

五分钟里门开了十九次，吐了十九张牌。

十九个人。一天两百多个。一年七万多件业务。

---

七四算了一遍。

第 19 扇区协作单元登记处四个窗口，一年七万三千件上下。其中 2 号窗口一天七十一件注销，一年两万三千件。

全底层有多少个登记处他不知道。终端上能查到的公开统计只到扇区级。他调出了第 19 扇区的页面。

```
第 19 扇区 · 底层在册个体      47,213
本月不适格剔除                   1,043
占比                              2.2%
剔除个体平均工龄            22 年 4 个月
剔除个体平均账户余额          -0.41 单位
```

七四看着第一行。

四万七千二百一十三。

这个数他昨天见过。第 37 扇区，底层在册个体，四万七千二百一十三。

他以为是凑巧。但一样到个位，不是凑巧的样子。

他调出第 22 扇区。

四万七千二百一十三。

三个扇区，同一个数，精确到个位。

```
第 19 扇区  在册个体  47,213
第 22 扇区  在册个体  47,213
第 37 扇区  在册个体  47,213
```

三个数一样，两种可能：要么这三个数是同一个数被抄了三份，要么在册个体数是按某种口径配出来的，不是数出来的。

七四查了第二种。他调出第 19 扇区上个月的数。

上个月：47,213。

再上个月：47,213。

他往回翻了十二个月。十二个月，同一个数。

一年不变。

一年里这个扇区剔除了一万两千五百一十六人（每月一千零四十三）。在册个体数一个都没有少。

每剔除一个，就补进来一个。补进来的方式他不知道——新生、调入、或者别的。

剔除一万两千五百一十六，补进一万两千五百一十六，净变化零。精确到个位，连续十二个月。

七四在终端上写：

```
在册个体 47,213
  连续 12 个月不变
  同期剔除 12,516
  → 补进 = 剔除（精确到个位）
```

他盯着这一行。

补进数等于剔除数，精确到个位，连续十二个月。这不是"刚好平衡"，这是配平。

配平的意思是：47,213 这个数是先定的，剔除多少就补多少，把这个数守住。

为什么要守住一个数。

他想起了诺玛说的：留一个名字在上面，让它看起来还在。

在册个体数，等于名册上的行数。

如果名册上有人的名字在、东西不发——诺玛见过三个——那"在册个体"就不是"活着的人数"，是"名册上的行数"。

行数是不会自己变的。

七四在终端上写：

```
在册个体 47,213
  = 名册行数
  ≠ 实际人数（需证明每一行都对应一个领东西的人）
```

他没有写"我无法证明"。

他写的是"需证明"。

写完他把三个扇区的数又看了一遍。

他想起昨天在查询台上查 D-04117 的结果：查询无结果。

格里被拿走了。名册行数少一个。

但行数不会少。所以有人补进来了。

补进来的那个人，七四不知道是谁。

他只知道一件事：在格里被拿走的那一天，第 37 扇区的在册个体数没有变。

---

他打开终端，把今天录到的东西标了时间地点，然后新建了一个条目：

```
纪元1018.03.12  第19扇区协作单元登记处
样本 41
盖印 137
非对称转移事件 1（发起方 D-?-? 织网工 / 接收方 清运工 / 转移量 30g）
注销业务 71
```

他在最后一行的下面补了一句：

```
D-10241  注销日期 3月3日  原因栏：空
```

存了。

---

存了之后他没有立刻关掉终端。

他把昨天和今天的两份记录并排调出来，看了大概十分钟。

两份记录里各有一条，指向同一件事。

昨天的那条是格里的纸条：

```
D-10241 找过我。
她说：频率不是巧合。
```

今天这条是诺玛屏上的四行：

```
D-10241
状态：已注销
注销类别：个体剔除
注销日期：纪元 1018 年 3 月 3 日
```

一个 3 月 3 日注销的人，在 3 月 3 日之后找过格里。

诺玛给过两个可能：名册没清干净，或者有人故意留着。她还给了第三个事实——四次空原因栏里，有三个人出现在别的扇区的配给名册上，名字在，东西不发。

艾拉给了第四个说法，来自她父亲那一辈：他们不是把你删掉，他们是把你从名册上挪走。删掉和挪走不一样。

七四把这四件排在一起：

一、D-10241 注销于 3 月 3 日，原因栏空。
二、3 月 3 日之后，D-10241 找过格里。
三、空原因栏的人在别的扇区名册上出现过，名字在，东西不发。
四、注销不是删除，是挪走。

四条里，第二条和第一条直接冲突。第三条说明这种冲突不是孤例。第四条给出一个可能的解释方向。

但第四条只说了"挪走"，没说挪到哪。

七四在终端上写：

```
如果"注销" = 从 A 名册挪到 B 名册
则 D-10241 在 3/3 之后仍可以活动（她找过格里）
则"已注销"与"人还在"不矛盾
```

写完他看着这两行。

如果这是对的，那么"注销"这个词就是错的。

不是注销，是搬运。从一本名册搬到另一本名册。搬的时候系统记"注销"，搬完之后原来那本少一行，另外那本多一行。

而他在门口算过另一件事：在册个体数恒定，说明名册行数是配平的。

如果 A 名册少一行就要补一行，那格里被剔除之后，第 37 扇区补了一个人进来。

补进来的那个人从哪来？

七四在终端上写：

```
第37扇区  1018.03.11 剔除 D-04117
第37扇区  1018.03.11 在册个体 47,213（不变）
→ 同日补进 1
→ 补进来源？
```

他没有写答案。

他关掉这一页，把两份记录存好。

---

然后他把格里的计数器从左手腕上摘下来，看了一眼。

143,276,814。

数字没有变。

他把计数器戴回去，走到门口的时候又回头看了一次大厅。

四十七个座位，十二个坏掉。墙上的屏还在滚四十七条条例，正滚到第九条。

1 号窗口前面排了六个人，2 号窗口前面排了十一个，3 号窗口没有人。

诺玛在 2 号窗口后面。她的右手盖在印章上，左手压着右手腕。她没有抬头。

七四看着那个姿势看了大概五秒。

十一年，二十三万次。

他把录音器举起来，对着 2 号窗口的方向录了十五秒。

十五秒里录到：三次叫号，两声脚步，还有一次盖章。咔。

只有一次。

他把录音器关掉。红灯灭了。

然后他走出登记处。

门在他身后合上，气压释放了一声。
