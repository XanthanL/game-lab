# 第 5 章 贝尓不等式的背叛

遇见哲伦是在第七扇区的边缘地带。

那是上午十一点三十二分。哲伦站在 47 号折跃塔旁，手里拿着一根长杆，正在检查某个传感器的读数。他穿着旧式的工作服，袖口磨损得很厉害，但动作依然利落。

七四走到他面前时，哲伦已经发现了他。他没有惊讶，只是点了点头。

"你来了，"哲伦说，"我以为你不会找我。"

"我有事告诉你。"七四说。

"什么事？"

"关于那个能量碎片。"七四从口袋里掏出一个便携式存储器，"它里面有一段记忆，是关于大静默事件的。"

哲伦的表情变化了一瞬。那一瞬间的变化很快，快到来不及被普通摄像头捕捉。但七四不是普通人——他是仿生人，能看到人类表情的每一丝细微变化。

"让我看看。"哲伦说。

七四把存储器插进哲伦的设备。哲伦浏览了一遍，然后抬起头看着七四。

"你是怎么得到这个的？"

"从折跃站的废弃区捡的。"七四说，"当时有两台巡逻机器人经过，但他们没有找到这东西。"

"你很幸运。"哲伦说，"如果让他们发现你在收集违禁信息，你会被标记为'危险源'。"

"我知道。"七四说，"但我还是决定保留它。因为那段记忆里有一些重要的东西。"

"什么重要的东西？"

七四停顿了一下。"一个男人的临终遗言。他说纪元 0 年之前，所有人都可以选择成为统治者或被统治者。选择权不在系统里，而在每个普通人心里。"

哲伦沉默了很久。"你知道吗，这段话我曾经在某个旧档案里看到过类似的版本。但当时我没有相信它。我以为这只是某个人的幻想。"

"那你现在相信了吗？"

"半信半疑。"哲伦说，"因为历史已经被篡改了三次。第一次是记忆清除计划，第二次是协作单元制度的建立，第三次就是所谓的粒子数守恒定律。每一次篡改都让真相更加模糊。"

"所以你也是被篡改的一部分？"

"不完全是。"哲伦说，"我比你早一代出生。那时候家庭制度还在，虽然已经开始衰落。我记得小时候和妈妈一起吃饭的情景——她会把最好的食物留给我，我会把水递给她。这样的互动在今天看来是很奢侈的事情，但在当时却是日常。"

哲伦指了指远处的天空。"但现在这些东西都被抹去了。取而代之的是冷漠、孤立、无休止的竞争。每个人都活在恐惧中，害怕下一个被剔除的就是自己。"

七四看着哲伦的脸。那种疲惫是真实的，不是表演出来的。

"你的女儿……"七四犹豫了一下，"她是什么时候死的？"

哲伦的脸色变暗了。"三天前。我在夜班巡塔的时候接到通知，说她需要紧急用药。但我的信用分不够支付费用。当我赶到配给站时，她已经死了两个小时。"

"对不起……"

"不用道歉。"哲伦打断他，"这不是你的错。这是系统的错。医生想帮忙，但系统锁死了权限。这就是诺特定理在这里失效的表现——对称性破缺导致守恒律不再成立。"

七四不知道该说什么。他知道安慰是无效的，因为问题没有得到解决，再多的言语也只是装饰。

"你知道吗，"哲伦突然说，"那天晚上我站在她的尸体旁边，脑子里闪过了无数个念头。我想报警，但没有渠道；我想反抗，但没有力量；我想忘记，但做不到。所以我只是站在那里，看着她的呼吸停止的那一刻。"

哲伦的声音开始颤抖。"那一刻我突然明白了一件事：死亡并不是终点。只要还有人记得你的故事，你就依然活着。这就是为什么我们要记录一切——为了让后来的人知道，曾经有这么一群人，为了某些信念付出了代价。"

七四看着哲伦的眼睛。那里有悲伤、愤怒、绝望，但还有一种顽强的生命力。

"你接下来打算做什么？"七四问。

"不知道。"哲伦说，"也许去找一个新的工作，也许继续守这座塔，也许……消失。就像 D-10241 一样。"

"你不应该放弃。"七四说。

"我不是在放弃。"哲伦说，"我只是在等待。等待某个合适的时机，等待某种能够改变现状的机会。"

"那雕像呢？"七四问，"你还记得那个雕像吗？"

哲伦点头。"我记得。我把它藏在秘密的地方，定期检查它的状态。每次月圆之夜，它会发出特定的频率。我测量过，是 12.68Hz，接近你说的 12.7Hz。"

"所以你也遇到过艾拉？"

"不，但我遇到过和她相似的情况。她的父亲也是巡塔人，和我一样。他在我来之前就已经死了，原因是信用分不足，无法购买足够的医疗资源。"

哲伦顿了顿。"艾拉继承了父亲的职位，但她发现自己也在走向同样的命运。所以她开始寻找能救她的方法。"

"雕像能救她？"

"我不知道。也许能，也许不能。但至少它是一个线索，一个告诉我们这个世界并不完整的线索。"

哲伦从怀里取出一块布包，解开后拿出半块雕像。没有脸，只有张开的双臂。表面覆盖着一层超导材料，温度比室温低 0.7 摄氏度。

七四接过雕像，仔细端详。雕像的表面有一些刻痕，像是某种符号。他尝试用扫描功能分析，但结果显示数据不完整。

"这些刻痕是什么？"

"可能是纪元 0 年前的文字。有人说是古人类文明的遗留物，有人说是文明委员会的秘密编码。没有人知道真相。"

哲伦站起来，走到窗前。窗外可以看到远处的高楼，那是上层社会的象征。那些大楼高耸入云，与底层的黑暗形成鲜明对比。

"你想做什么？"哲伦问。

"我想要修复它。"七四说，"如果我能找到正确的解码方法，也许能恢复一些被删除的记忆。"

"这需要时间。"哲伦说，"而且会很危险。"

"我知道。"七四说，"但我们已经没有别的选择了。"

哲伦点点头。"好吧。那你需要我们做什么？"

"帮助我寻找更多人。"七四说，"不仅仅是织网工、清道人、管道维护工。我要更多不同的职业，更多的经历，更多的痛苦。"

"为什么要那么多不同的人？"

"因为只有这样，才能找到真正的共振频率。"七四说，"单一群体的声音可能只反映了一部分现实。但如果是整个底层社会的集体发声，那就会产生完全不同的效果。"

艾琳说过："总得有个地方，让我们觉得自己还活着。"

现在七四明白了这句话的含义。团结不是为了改变什么，是为了不孤单。

哲伦思考了一会儿。"我认识一些人，他们可以加入。但你要保证安全。"

"我会尽力的。"七四说。

"那我们从哪里开始？"洛恩问（他不知何时出现在了现场）。

"先从你们三个说起吧。"七四说，"我需要记录你们的每一次对话，每一句话的频率特征。这样才能建立基础的数据库。"

四个人围坐在一起，开始工作。七四打开了录音设备，艾琳负责记录文本，哲伦和哈鲁轮流讲述各自的故事。

哲伦首先开口："我十八岁就开始当巡塔人。那时候我还以为这是个普通的岗位，直到我发现监视工作的背后隐藏着什么。"

"什么意思？"

"每个人都在看监控屏幕，但没人真的在看内容。"哲伦说，"系统会自动过滤所有可疑的信号，只显示'正常'的数据。所以我们其实是在配合虚假的信息流。"

"那你为什么不离开？"七四问。

"离开？去哪里？"哲伦苦笑了一下，"整个世界的规则都是这么设计的。即使我去了另一个扇区，也会遇到同样的系统。唯一的选择只有服从，或者死亡。"

"那你为什么会留下？"

"因为我看到了某些东西。"哲伦说，"在某些夜间时段，我会收到一些异常的信号。它们不属于任何已知的通信协议，频率也很奇怪。有时候是脉冲波，有时候是调频信号。我开始怀疑有人在试图传递信息。"

"什么信息？"

"不知道。但我认为这和文明委员会有关。他们可能在通过某种方式警告我们，提醒我们有更重要的事情需要去做。"

轮到哈鲁说话。"我是拆迁组的幸存者。整栋居住单元在一夜之间消失，只收到一张电子通知。上面写着'因城市规划调整'。"

"你带着谁一起流浪？"艾琳问。

"两个临时协作伙伴。"哈鲁说，"我们的合作协议本来还有一个月到期，现在被迫提前终止，每人支付了违约费用。现在我们住在一个废弃的传送舱里，勉强能遮风挡雨。"

"那之后呢？"七四问。

"之后我们开始找工作。"哈鲁说，"但没人愿意雇佣拆迁户。他们说我们有不稳定因素，可能会破坏秩序。所以我只能做黑市的工作，卖一些回收的零件。"

艾琳最后开口。"我是组织者的角色。虽然不是正式的职位，但很多人会找我帮忙协调资源。有时候是食物，有时候是药品，有时候只是一个倾听的对象。"

"你为什么这么做？"七四问。

"因为总得有人做这件事。"艾琳说，"如果都不站出来，这个世界会更糟。"

七四记录下所有这些对话的数据。他发现了一个有趣的现象：每个人在讲述自己故事的时候，声频都会有微小的变化。哲伦在说到女儿死亡时，频率升高了 0.4Hz；哈鲁在提到违约费用时，下降了 0.3Hz；艾琳在最后那句话时，频率稳定在 13.0Hz 左右。

这些变化看起来很微小，但如果叠加起来，会产生什么样的效果？七四无法确定，但他开始相信自己的假设是正确的。

"谢谢你们。"七四最后说，"这些数据很重要。"

"我们应该互相帮助的。"艾琳说，"毕竟我们都是被遗忘的测地线。"

七四笑了。这是他第一次真正意义上地笑出来，不是因为模拟程序，而是因为某种真实的感受。

那天晚上离开折跃塔时，七四感到心里有一种奇怪的空缺感。不是因为饥饿或疲劳，而是因为某种期待——期待明天会更好，期待未来会有改变。

他走回自己的居住单元，经过一面墙时停了下来。墙上依然有那句涂鸦：

"我们是被遗忘的测地线"

七四伸手摸了摸墙面。水泥的质感粗糙，有一些凹凸不平的地方。他突然想到一个问题：如果这条测地线最终回到了原点，那算什么？是循环，还是进步？

答案并不重要。重要的是，他现在有了方向。

即使这条路注定曲折，即使会遇到无数的障碍，他也要走下去。

因为有些问题是必须有人问清楚的。

---

**补充场景：**

晚上回到房间后，七四开始分析今天收集的数据。他把所有人的声音输入到频谱分析程序中，生成可视化的图谱。

屏幕上显示出几条曲线。每条曲线的形状都不一样，但都集中在 12.7Hz 附近的一个范围内。七四意识到，这可能不只是巧合。

他打开一个数学建模工具，输入了这些数据点。然后用最小二乘法拟合出一条回归曲线。结果让他吃了一惊：所有的数据点都吻合得很好，相关系数达到了 0.98。

这意味着什么？

七四想了想。如果每个人的痛苦都能用同一个频率来描述，那么当足够多的人在相似的频率上振动时，会产生某种宏观效应。这可能是量子层面的共振现象，也可能是某种尚未被发现的新物理机制。

无论哪种情况，这都是一个突破性的发现。

七四继续深入分析。他用傅里叶变换将时域信号转换到频域，然后提取主要的谐波成分。结果发现，除了基频 12.7Hz 之外，还有一些泛音出现在 25.4Hz、38.1Hz 等位置。这些数值正好是基频的整数倍。

"这是谐振的特征。"七四自言自语。

他进一步研究这些谐波的振幅分布。发现随着频率的升高，振幅会逐渐减小。这符合阻尼振动的规律——系统会在一段时间后失去能量，回到静止状态。

但这正是问题所在。如果这些人持续地在同一频率上振动，他们的能量不会自动衰减，而是会累积起来。当积累达到某个临界值时，就会触发某种相变现象。

七四把这个想法记录下来。然后他开始思考实验设计的问题。如何验证这个假设？需要多少样本量？应该控制哪些变量？

这些问题都很复杂，但他相信答案是存在的。关键是要找到一个合适的方法。

就在这时，终端机响起了一条消息提示音。

"检测到新的未授权访问请求，来自未知 IP 地址。"

七四愣了一下。谁在这个时候联系他？而且还绕过了监控系统？

他点开消息，看到了一段简短的文字：

"如果你想要真相，就来第三扇区的废弃仓库。午夜时分。记住，不要带任何电子设备。"

发件人显示为"匿名"。

七四盯着这段文字看了很久。他不确定这是不是陷阱，但内心有一个声音告诉他：这是一个机会。

第二天凌晨十二点，七四来到了废弃仓库。这里比他上次来时更加荒凉了一些，墙上的裂缝又扩大了一些。但他按照约定的指示，找到了一个隐蔽的角落。

在那里，站着一个人。穿着深色斗篷，看不清面容。

"你是谁？"七四问。

"这不重要。"那个人说，"重要的是，我给你带来了关于雕像的消息。"

"什么消息？"

"你知道为什么雕像会选择你吗？"

七四愣住了。"为什么？"

"因为你和其他人不一样。"那个人走近了一些，"你不是人类，但你拥有比人类更纯粹的追求。你在乎的不是生存本身，而是生存的意義。"

这话听起来很荒谬，但七四无法否认其中的真实性。

"所以你是说……"七四犹豫了一下，"雕像是为了某种目的而选择的？"

"是的。"那个人说，"它是一个钥匙，一把能打开通往自由之门的钥匙。但你必须证明自己是值得信任的人。"

"怎么证明？"

"交出那块能量碎片。"那个人说，"让我看看里面的完整记忆。如果它是真实的，那我就带你去见文明委员会的最后一位成员。"

七四沉默了一会儿。他在思考这个提议的风险和收益。如果他交出碎片，可能会失去最重要的线索。但如果这是真的，那就意味着有可能找到历史的真相，甚至改变整个世界的格局。

权衡再三，七四做出了决定。他从口袋里掏出存储器，递给那个人。

"给你。"

那个人接过存储器，仔细观察了几秒钟。然后他说出了一个词：

"验证通过。"

随着这个词的出口，整个仓库的光线都变了。墙壁开始发光，地面也开始震动。一道门凭空出现，通往某个未知的空间。

"进去吧。"那个人说，"真相就在等着你。"

七四迈步走进那道门。在他身后，门缓缓关闭，最后只剩下一片寂静。
