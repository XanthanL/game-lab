# 植物大战僵尸 · 重制版（纯前端复刻）

用原生 JavaScript + Canvas 2D 实现的塔防游戏《植物大战僵尸》核心玩法。**零依赖、零构建**，所有美术由代码矢量绘制（原创风格，规避原版素材版权），音效由 Web Audio 合成。

## 运行方式

- 直接双击 `index.html` 打开即可游玩
- 或启动任意静态服务器：`python -m http.server` / `npx serve` 后访问

## 本次重制内容

### 1. PC / 手机横竖屏自适应显示（修复窗口比例问题）
- 画布内部坐标由 `config.js` 按渲染模式分支：横屏基准 `1020×600`、竖屏基准 `720×1280`，两套均为内部逻辑分辨率，由 `main.js` 按视口**等比缩放**并叠加 `devicePixelRatio` 保证清晰。
- 桌面端以原始比例铺满窗口；手机端自动按朝向选择布局，横屏竖屏均**原生可玩**（不再锁定横屏），并保留 `?mode=portrait|landscape` 供桌面调试。
- `touch-action: none` + `user-scalable=no` 禁止误触缩放与页面滚动；触屏设备一律使用底部卡片 dock。
- 所有布局字段（草坪偏移、格子宽高、房屋/栅栏、顶栏、种子栏宽度）均为按 `_mode` 分支的 getter，因此 `game.js` / `draw.js` / 实体类里的 `c.xxx` 引用无需改动即自动适配两套布局，无回归风险。

### 2. 移动端触控重设计
- 触屏设备自动启用**底部卡片 dock**（大尺寸触控目标），画布内卡片栏自动隐藏。
- dock 内每张卡片含植物图标 + 名称 + 阳光消耗，并实时显示冷却遮罩；另含**铲子**（移除植物）与**暂停**按钮。
- 交互逻辑：点卡片选中 → 点草坪种植；点阳光收集；点铲子后点植物移除。

### 3. UI 与图标重制
- 全部植物 / 僵尸 / 阳光 / 道具改用**带渐变高光与描边的矢量绘制**，更精致。
- 关卡选择按“世界”分组（白天草地 / 黑夜 / 屋顶 / 终局），通关显示 ★。
- 顶栏新增阳光计数、波次进度、铲子与暂停按钮；Boss 关显示独立血条。

### 4. 内容扩展
- **23 个关卡 / 6 个世界**递进：白天草地 → 黑夜 → 泳池（昼夜）→ 浓雾 → 屋顶 → 终局。黑夜有月光与偏冷草坪，泳池含水面行，迷雾有渐隐视野，屋顶为瓦片地。
- **26 种植物**：向日葵/阳光菇、豌豆/寒冰/双发/三线射手、坚果/高坚果、樱桃炸弹、土豆雷、窝瓜、火爆辣椒、地刺/地刺王、火炬树桩、大嘴花、小喷菇/大喷菇、催眠菇、灯笼草、磁力菇、南瓜头、西瓜/玉米投手、玉米加农炮、咖啡豆。
- **17 种僵尸**：普通/路障/铁桶/撑杆跳/读报，新增 门板、橄榄球（重甲）、舞王（召唤）、气球（空中）、潜水（水下）、小丑、投石车、蹦极、矿工、雪人，以及两大 **Boss**：伽刚特尔（巨型木棍、砸碎植物、高血量）、僵尸博士机甲（终局 Boss，周期召唤小僵尸）。

## 美术与动画资源评估

本项目的美术策略经过评估与权衡，目标是**画质提升与流畅度平衡**：

### 现有资源评估
| 来源 | 授权 | 评价 | 结论 |
|---|---|---|---|
| **内置程序化矢量绘制**（本项目 `draw.js`） | 原创 / 无版权风险 | 零依赖、可无限缩放清晰、与现有风格完全协调、离线可用、内存占用极低 | **默认采用**，并持续打磨 |
| **Kenney.nl**（Plant & Food / Monsters / Animals 等） | **CC0 公共领域**（可商用、可修改） | 精致位图、风格统一、体积小；但需联网下载、位图缩放不如矢量清晰、需调色以协调 | 作为**可选接入**层（见下） |
| **OpenGameArt** | CC0 / CC-BY 混合 | 资源多但质量参差、授权需逐条核对（CC-BY 须署名） | 仅作备用，优先 Kenney CC0 |

> 原版《植物大战僵尸》素材受版权保护，不在此项目的可用资源范围内，故采用原创矢量风格替代。

### 已落地的画质提升（轻量、零额外 draw call）
- **软投影**：角色/物体下方单次半透明椭圆填充，立刻获得落地层次感。
- **渐变高光 + 描边**：植物头部、僵尸躯体、阳光、子弹均带径向渐变立体感。
- **动画系统**（`js/anim.js`）：缓动函数（`outBack`/`outElastic`/`outBounce` 等）+ 对象池化的瞬时动画管理器。
  - 植物入场**弹性缩放**（从地面"啵"地长出）；
  - 爆炸**全屏闪光**（暖色叠加，由动画管理器衰减，单次填充开销）；
  - 阳光脉冲光晕、子弹拖尾、割草机轮子旋转 + 排气。
- **静态背景离屏缓存**（`buildBgCache`）：草坪/房屋只在尺寸变化时重绘一次，之后整帧 `drawImage`，显著降低每帧绘制量。

### 性能与画质平衡策略
- **对象池**：粒子（`Particle`）、瞬时动画（`anim.run` 句柄）复用，避免 GC 抖动。
- **渐变 LRU 缓存**（`draw.js` 的 `A._gc`）：按坐标+颜色缓存 `CanvasGradient`，植物在固定格内坐标恒定 → 高命中率，避免每帧重建数百个渐变。
- **LOD / 合批**：Boss 与大型单位用 `ctx.scale` 统一放大而非额外 draw call；全屏闪光、软投影均为单次填充。
- **draw call 控制**：特效（爆炸/飘字/粒子）数量受关卡配置约束，必要时可在此层做上限裁剪。

### 如何接入真实素材（可选）
`js/art/sprites.js` 提供 CC0 图集接入层，默认关闭。加载一张 Kenney 等 CC0 图集后即可自动替换程序化绘制：

```js
// 在 main.js 启动后调用（示例）
PVZ.sprites.load({
  url: 'assets/sprites.png',
  atlas: {
    'plant:peashooter': { sx: 0,  sy: 0,  sw: 64, sh: 80 },
    'zombie:normal':    { sx: 64, sy: 0,  sw: 64, sh: 96 }
    /* …其余植物/僵尸帧… */
  }
}).then(() => console.log('CC0 精灵已启用'));
```

未调用 `load()` 时，游戏始终使用内置矢量绘制，**不影响任何默认表现与性能**。

## 目录结构

```
index.html              # 入口页面（含 viewport / 横屏提示）
css/style.css           # 响应式布局与移动端 dock
js/
├── main.js             # 入口：响应式缩放、主循环、输入
├── config.js           # 全局配置与数值表（植物/僵尸/关卡/世界）
├── game.js             # 游戏场景：波次、胜负、Boss、HUD、特效、割草机
├── ui.js               # DOM 界面：菜单/选关/暂停/结算/触控 dock
├── anim.js             # 轻量动画系统（缓动 + 对象池化动画管理器）
├── art/draw.js         # 程序化矢量绘制（全部角色与图标 + 渐变缓存）
├── art/sprites.js      # 可选 CC0 精灵图集接入层
├── entities/           # 植物 / 僵尸 / 子弹 / 特效实体
└── systems/            # 阳光 / 选卡 / 碰撞 / 音效 / 存档
test/smoke.js           # 无头逻辑测试
```

## 数值平衡
所有数值集中在 `js/config.js` 的 `PLANTS` / `ZOMBIES` / `LEVEL_LIST` / `SUN` 表中，调整即时生效；新增植物 = 配置条目 + `draw.js` 绘制函数 + 可选专属逻辑。
