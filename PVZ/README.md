# 植物大战僵尸（纯前端复刻）

用原生 JavaScript + Canvas 2D 实现的塔防游戏《植物大战僵尸》核心玩法，**零依赖、零构建**，所有美术由代码矢量绘制，音效由 Web Audio 合成。

## 运行方式

- 直接双击 `index.html` 打开即可游玩
- 或启动任意静态服务器：`python -m http.server` / `npx serve` 后访问

## 操作说明

| 操作 | 说明 |
|---|---|
| 鼠标 / 触控 | 点击或按住卡片拖拽到草坪种植；点击阳光收集 |
| 右键 | 取消当前选中的卡片 |
| P / Esc | 暂停 / 继续 |
| 暂停面板 | 1x / 2x / 4x / 8x 倍速循环切换、音量调节、重新开始、返回菜单 |

## 游戏内容

- **5 个关卡**（1-1 ~ 1-5），通关解锁下一关，进度存于 localStorage
- **9 种植物**：向日葵、豌豆射手、寒冰射手、双发射手、坚果墙、高坚果、樱桃炸弹、土豆雷、窝瓜
- **4 种僵尸**：普通、路障、铁桶、撑杆跳（可跳过第一株植物）
- **系统**：阳光经济、卡片冷却、波次刷怪、减速 / 爆炸 / 断头特效、粒子、屏幕震动、程序化音效与 BGM

## 目录结构

```
index.html              # 入口页面
css/style.css           # 页面布局与 UI
js/
├── main.js             # 入口：主循环、场景切换、输入
├── config.js           # 全局配置与数值表（植物/僵尸/关卡/阳光）
├── game.js             # 游戏场景：波次、胜负、HUD、特效
├── ui.js               # DOM 界面：菜单/选关/暂停/结算
├── art/draw.js         # 程序化矢量绘制
├── entities/           # 植物 / 僵尸 / 子弹 / 特效实体
└── systems/            # 阳光 / 选卡 / 碰撞 / 音效 / 存档
test/smoke.js           # 无头逻辑测试
PLAN.md                 # 开发规划文档
```

## 数值平衡

所有数值集中在 `js/config.js` 的 `PLANTS` / `ZOMBIES` / `LEVEL_LIST` / `SUN` 表中，调整即时生效；新增植物 = 配置条目 + `draw.js` 绘制函数 + 可选专属逻辑。

## 技术要点

- 静态背景（草坪/顶栏/栅栏）离屏缓存，每帧仅一次 `drawImage`
- 粒子使用对象池复用，避免 GC 抖动
- Pointer Events 统一鼠标与触控输入
