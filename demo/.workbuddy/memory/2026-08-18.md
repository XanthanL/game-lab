## 新项目立项：Hexa Sort × 国际象棋 微信小游戏
- 用户需求：结合 Hexa Sort（六边形拖拽排序消除）与国际象棋的微信小游戏；用户无微信小程序/小游戏开发与上架经验。
- 关键结论（已写入分析报告 hexachess-wechat-minigame-analysis.html）：
  - 必须走「微信小游戏」通道（非普通小程序），类目选「游戏/休闲益智」。
  - 上架最稳路线：个体工商户主体 + 纯广告变现(IAA) + 单机 + 休闲益智 ⇒ 免版号。
  - 版号铁律：是否要版号唯一判定=是否开内购；个人/个体无法自申版号；棋牌/联机对战必触发版号。MVP 锁死免内购。
  - 技术栈推荐：原生 微信小游戏(Canvas2D+TS) 或 Cocos Creator（二选一待用户拍板）。玩法量级的 2D 解谜，技术高可行。
  - MVP 概念：方案A（Hexa Sort 内核换皮为六色棋子）+ 轻量棋味包装（集齐同色触发将杀特效）。方案B（走法约束排序）留作后续迭代。
  - 里程碑：M0 注册个体户+账号 → M1 技术验证(demo) → M2 关卡内容 → M3 云开发排行榜/广告 → M4 软著+备案+上线，约 2–3 个月。
- 待用户拍板：① 主体=个体工商户(推荐) or 个人；② 框架=原生 Canvas2D or Cocos Creator。
- 下一步可接：搭一个可运行的 Hexa Sort 核心 demo（六边形网格+拖拽吸附+同色消除）验证手感。

## 用户补充三问：GSAP 技能 / 版权 / 益智定位
- GSAP 技能评估：对本项目（原生 Canvas2D 小游戏，无 DOM）基本无用——GSAP 面向 DOM/SVG/CSS 动画，会增包体+浏览器全局依赖；所需动效用自研 easing 更轻更可控。仅后续做推广落地页/H5/官网时 GSAP 才有价值。
