## 排除清单（≥3 条，含被谁排除）

- 排除 **editorial-hero / catalog-grid / split-narrative** 布局，因为「视觉资产质量=无」（intake 约束表第 1 条：依赖图的布局）
- 排除 **editorial-print / warm-hospitality / expressive-artistic** 风格，因为「视觉资产质量=无」（低质/无图毁掉或变廉价滤镜）
- 排除 **contemplative 全族**（quiet-luxury / japanese-ma），因为前置硬条件「必须有高质量素材」不成立
- 排除 **craft 全族**（warm-hospitality 等），因为「卖空间体验 + 有专业环境摄影」两条均不成立——本站卖的是信息检索
- 排除 **commerce 全族**，因为转化目标是「查询→到店」而非线上购买；SKU 目录网格依赖缩略图
- 排除 **minimal-state** 布局，因为内容量 40 条 >> 单屏单动作的适用范围
- 排除 **conversion IA**，因为核心动作是「查」不是「买/留资」
- 排除 **expressive / vernacular 族**，因为中文数据台账需要稳定字宽与等宽数字，风格化字形破坏扫读
- 排除一切需命令行/CMS 的维护方式与栈，因为「维护者=非技术」（D3）

## 剩余空间

- 技术栈：只剩 `plain-html`（D3 排除其余 6 个，见 tech-stack.md）
- IA：只剩 `directory`（高频单源清单）
- 风格：族=grid → 锚点=**swiss-utility**（when 四条全命中：视觉资产弱/快速扫读/非技术维护/实用高频）
- 布局：`utility-board`（锚点绑定）｜中轴：`left-rail`（锚点声明）
- 字体搭配（fonts.json 该锚点条目）：display=**Archivo** × body=**Inter** × mono=**IBM Plex Mono** × cjk=系统中文黑体栈；自托管 latin 子集 woff2
- 排版签名：r=1.2 / base=15px / lh=1.5 / measure 960px / 行长 74ch / 字重 400,600 / 直角 rad=0 / light 主题 / 动效 snap / 色相 264 低彩度（OKLCH 由 emit_tokens.py 确定性展开 + WCAG 校验）
