# 辰光修表铺 · Chenguang Watch Atelier — 网站运维手册

给唯一会碰这个网站的人（店主家属）看的一页纸手册。
网站是**纯静态**的：没有任何程序、数据库、构建步骤，改完用 FTP 传上去就生效。

---

## 一、FTP 上传什么

把下面 6 项传到虚拟主机的网站根目录（和 `index.html` 平级）：

```
index.html        ← 页面本身
css/              ← 样式（含 tokens.css）
js/               ← 脚本（含新到名表清单）
fonts/            ← 两个西文字体文件（共 65KB）
images/           ← 照片（目录里另有说明 README.txt）
```

> 传完打开网站，如仍是旧样子：按 Ctrl+F5 强制刷新（手机浏览器清一次缓存）。

## 二、每年改一次：营业时间

营业时间**全站只出现一处**。用记事本/VS Code 打开 `index.html`，
搜索「周二至周日」，只改这一行的中文（下面一行英文顺带核对）：

```html
<dd><strong>周二至周日 10:00 – 18:30（周一休息）</strong>…
```

改完只传 `index.html` 一个文件即可。

## 三、上线前要做（一次性）

- **电话**：现在页面上两处显示红色虚线框的 `028-XXXX-XXXX〔待填〕`
  （页首联系行 + 「到店信息」区）。把两处的文字换成真实号码，
  同时把两处 `href="tel:028-XXXX-XXXX"` 里的号码一起改掉，然后传 `index.html`。
- **照片**：按 `images/README.txt` 的文件名清单上传门头照和微距照。
  照片到位后，网页自动显示；在此之前显示的是带金色细框的占位框。
- **图注**：微距照下方写着「〔图注待填〕」，可顺手改成真图注
  （搜「图注待填」共 6 处）。

## 四、每月（可选）：新到名表

1. 照片传到 `images/new-arrivals/`（文件名随意，如 `2026-10-01.jpg`）
2. 打开 `js/new-arrivals.js`，照抄注释里的示例行、去掉行首 `//`、改成自己的信息：

```js
{ photo: "images/new-arrivals/2026-10-01.jpg", name: "欧米茄 蝶飞",
  nameEn: "Omega De Ville", detail: "1970 年代 · 手动上链", price: "到店询价" },
```

3. 传 `js/new-arrivals.js` 和照片，完成。
   不上架的月份什么都不用做——页面会显示「本期上新整理中」。

## 五、本地预览

双击 `index.html` 就能在浏览器里看（不联网也行）。

## 六、别动的东西

`css/tokens.css` 是全站的颜色/字号来源（设计系统），改错一处全站变形。
想换颜色/字号时先问一句，或对照 `design-system/MASTER.md` 里每个值的意义再改。
