# intent-summary · 意图汇总

## 源与形态
- 源：用户提供的完整文字需求文档 + 人物设定（见 source-map.md）。
- 形态：standalone 独立单页官网 · 中文单语 · 无参考站（references.md 不适用）。

## 成功定义（验收，源 S2 §7）
1. 手机 3 秒内加载首页（无栅格图、自托管字体 ≤2 族、无运行时 → 首屏 <300KB 有余量）。
2. 预约表单可成功提交并通知莉芙 → 静态站落地为「讯号板留言」模式：校验 + 蜜罐防垃圾 + 生成结构化留言 + 一键复制；后端 endpoint [待接]。
3. 价目表、地址、营业时间准确无误 → 5 条价格逐字来自源；地址/时间/上门范围原文；未定价项标柜台牌价。
4. 世界观一致、无现实品牌 → 全站设定词汇；地图为内联 SVG 手绘。
5. 安全警告和保修条款清晰可见 → 危险品清单用黑底黄字警示框（不折叠）+ 页脚保修政策。
6. 2 次点击内到「预约维修」和「租赁氧气囊」→ sticky board-bar 常驻两枚 CTA，1 次点击即达锚点。

## 转化目标
预约维修 / 滤芯询价 / 氧气囊租赁 / 到店-上门-寄修三种履约方式引流。

## 图文策略
- `image: optional`：无照片素材 → 排版承重 + 2 处内联 SVG（首屏呼吸器线稿、手绘通风井路线图）。
- `icon: none`：不用图标库；状态用文字标签（「营业中」「可寄修」），符合 utility-board 签名 3。

## 语言策略
中文单语；祖安黑话点缀（「到店付银轮」「讯号板」）但保证可读；金额/编号/时间用等宽西文字体渲染。

## 技术栈
`plain-html`（详见 tech-stack.md）。

## 族与锚点
industrial 族 → `concrete-brutalist`（详见 content-profile.md §三）。

## 中轴 / 区块 / 尺寸
- `--axis: left-rail`；`--measure: 1080px`；`--prose-width: 62ch`；`--gutter: 16px`；间距栅格 8px。
- 区块：顶栏状态戳 → 首屏（字标+CTA+信任条）→ 服务 S-01…06 → 价目表（筛选+双币+离线 txt）→ 预约流程+表单 → 关于莉芙（含危险品警示框）→ 客户评价 → FAQ 6 → 到店与地图 → 页脚。**Contact 不单设区块**（合并进「到店与地图」，按 layouts.md 区块默认）。

## 硬约束
低带宽 / 手机优先 / 老旧终端 / 无现实品牌 / 价目准确 / 安全条款可见 / 双币切换 / 表单防垃圾。

## 部署建议（源 S2 §6，未在代码内体现）
静态托管 + 低延迟节点；CDN 缓存 index.html 与 woff2；prices.txt 可被讯号板爬虫直接抓取（世界观内笑话，亦是离线方案）。
