# 拾花 2.0 · 手作花店网站 · 维护手册

给店主的一页说明。网站只有一个网页（`index.html`），全部内容用记事本就能改。
（1.0 旧版在隔壁 `shihua/` 文件夹，保留未动；以后用这个 2.0 就行。）

## 先看一眼

双击 `index.html`，浏览器里就是你的网站。手机效果：按 F12 → 点左上角手机图标。

## 要做的事：把 [待填] 填掉

页面上所有**红虚线框**里的 `[待填]` 都是留给你的，一共 4 类：

| 在哪 | 填什么 |
|---|---|
| 门牌下面 | 电话号码 |
| 「在售花目」表格 | 3 行占位，每行填：品名 / 花材 / 规格 / 价格（不够用就整行复制再加） |
| 「来店里坐坐」 | 门店地址、营业时间 |
| 「订花」 | 微信号、电话号码 |

**步骤**：`index.html` 右键 → 打开方式 → 记事本 → Ctrl+F 搜「待填」→ 逐个换成真实内容 → 保存 → 刷新浏览器。
表格行填完后，把该行的 ` class="todo-row"` 删掉，红框就消失了。

## 换成真实照片

照片直接**覆盖同名文件**即可，代码一个字都不用改：

```
assets/storefront.jpg        ← 店门口
assets/hand-tied.jpg         ← 包花的手
assets/tools.jpg             ← 麻绳花剪
assets/bouquet-kraft.jpg     ← 牛皮纸花束
assets/bouquet-champagne.jpg ← 香槟色花束
assets/shop-interior.jpg     ← 店内
assets/plants-window.jpg     ← 窗边绿植
assets/vase-home.jpg         ← 带回家的花
```

手机拍的话导出时选「原图」；图片越清楚网站越好看。

## 日常改价格 / 加花

只动表格里的文字。颜色、字号在 `design-system/tokens.css`，不懂不要动。

## 两个小提示

1. 现在网站里的照片是 AI 生成的示意图（你提供的），街坊会当真实店看；拿到实拍后建议尽早替换。
2. 大标题用的楷体字体按现在的文字做过瘦身（加载快）。以后标题里加了全新的字，那个字会自动退回系统楷体，观感接近，不用处理。

## 发布到网上

整个 `2.0` 文件夹上传到任意免费静态托管（GitHub Pages / Vercel / Cloudflare Pages）即可，无需构建。微信里发链接，打开就是手机排版。

## 文件结构

```
2.0/
├─ index.html            ← 网站本体，改内容只动这个
├─ styles.css            ← 排版样式（一般不动）
├─ assets/
│  ├─ *.jpg              ← 8 张照片，换图就覆盖同名文件
│  ├─ favicon.svg        ← 标签页小图标
│  └─ fonts/             ← 自托管字体（Marcellus/Karla/等宽/楷体子集，别动）
├─ design-system/
│  ├─ tokens.css         ← 颜色/字号/间距总开关（不懂别动）
│  └─ MASTER.md          ← 设计系统说明
├─ docs/                 ← 建站过程记录（可忽略）
├─ extraction/           ← 原图提取存档（可忽略）
└─ source-images/        ← 你发的 8 张原图存档
```
