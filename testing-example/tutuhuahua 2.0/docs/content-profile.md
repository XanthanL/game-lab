## 剩余空间

- IA:只剩 **portfolio(轻转化)** —— 条目并列 + 留资,其余被挤出
- 布局:只剩 **split-narrative** —— 锚点绑定 + 排除 catalog-grid 后的唯一解
- 风格:取 **quiet-luxury** —— 因为它是 contemplative 族内既满足「图为主角 + 不解释的静奢 + 慢节奏」、
  又未被批次账本与自身 never 排除的唯一锚点;40+ 件作品以「慢流大图」而非「密集网格」呈现,
  恰是奢侈品官网的观看方式(对比 v1 的「美术馆展签网格」)
