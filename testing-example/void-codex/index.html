虚空典籍藏在探险家协会公寓的十二层。我们卖文学和艺术书——小说、诗、画册、艺术理论，以及装帧好看的一切。选书标准只有一条：值得在深夜读下去。

偶尔办小型朗读会。规模不大，十几个人，一杯热饮，轮流读出声。活动信息就列在上面，加场或改期会第一时间更新。
