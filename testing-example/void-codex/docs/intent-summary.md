# Intent Summary — 意图摘要

- 源材料：用户口述（定位/目标）+ 参考站 URL（风格）+ 用户提供的设定型实体信息 → 见 `source-map.md`
- 交付形态：`standalone` 独立站（`E:\Code\mine-skills\testing-example\void-codex\`，用户指定新开子目录）
- 成功定义：路过的客人 10 秒内知道「这是一家深夜开的文学艺术书店」，3 次点击内知道「地址在哪、最近有什么朗读会」
- 转化目标：**到店**（次：记住活动节奏常回访）
- 图文策略：图片=**不要**（暂无素材，排版/光效/粒子承担视觉，留可插图位）；图标=**functional**（少量，服务状态与导航识别）
- 语言策略：**纯中文**，默认 zh，无切换器；眉标允许少量西文/数字作图形装饰（不算双语）
- 参考站：XanthanL Music（学 3 条/不学 2 条见 `references.md`）
- 技术栈：`plain-html`（D1–D8 见 `tech-stack.md`）
- 中轴：`center-axis`（hero/店名/主张居中；**正文、列表、地址一律左对齐**）
- 区块与尺寸：
  - 顶栏（玻璃拟态，品牌 + 3 锚点 + 营业状态点）= 要
  - Hero（超大渐变衬线店名 + 一句主张 + 主 CTA 看活动 / 次 CTA 找到我们 + SCROLL）= 要
  - 最近活动（编号台账列表，`data/events.js` 驱动）= 要（核心区块）
  - 书店（两三段短文 + 竖排引文 + 3 张玻璃特色卡）= 要
  - 到店（地址/营业/联络三卡，信息不可折叠）= 要
  - 独立 Contact 表单区 = **不做**（默认不做；联络信息并入到店区）
  - 主视觉三档宽度：店名 display ≈ `clamp(44px→96px)`；玻璃卡片 320–400px；列表/正文列 68ch（容器 1120px）
- 硬约束：
  1. 用户点名的调调：黑底 + 霓虹光晕 + 星尘粒子 + 渐变标题（2026-09-12 答复「保留暗夜霓虹」）
  2. 标题字体要有文学气质，去掉科幻感（同上答复的推荐项描述）
  3. 实体信息用用户提供的设定值，逐字呈现，不替换不改写
  4. 活动示例数据必须带可见「示例」标记，不得冒充真实活动
  5. 无图：不使用任何假图/氛围图充当店景
