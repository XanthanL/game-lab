### 学它的什么（3 条）

1. **氛围层**：纯黑沉浸底 + 缓慢漂移的星尘粒子 + 局部霓虹发光——"深夜"的物理感，直接承接用户点名的调调。
2. **字阶语法**：超大渐变标题压首屏 + 字距拉宽的小号大写眉标（`letter-spacing 0.08em+`）+ 编号等宽数字当视觉锚——一套"远看有气势、近看有刻度"的排版对比。
3. **台账组件**：编号行列表（等宽数字 + 当前行高亮 + 左侧霓虹描边 + 右侧对齐的数值列）——从"曲目列表"转译为"活动列表"的骨架。

### 不学它的什么（2 条）

1. **不学 Orbitron 科幻字形与全大写英文主张**：书店要文学气质，display 换有衬线中文（宋体系）+ 几何无衬线西文（Sora），中文正文绝不加正字距。
2. **不学它的音乐产品心智与信息结构**：不做播放器、不做逐字方块 logo、不做外链作品墙；书店的信息主轴是「最近有什么活动 + 怎么找到我们」，密度与组件都围绕它重组。

### 调性转译

参考站是「深夜电子音乐现场」；本站是「魔法都市里 24 小时亮灯的文学书店」。同一个深夜，不同的光源：音乐现场的光来自舞台，书店的光来自阅读——所以发光收在标题、描边与粒子上，正文区保持大面积极暗的安静。
