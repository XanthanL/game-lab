## 未采用的源内容

| 内容 | 理由 |
|---|---|
| 参考站的音乐播放器 / 专辑 / 曲目列表 | 书店无音频内容；只借其「编号列表 + 高亮当前行」的台账语法转译为活动列表 |
| 参考站的逐字迷宫 logo（X-A-N-T-H-A-N-L 方块字设计） | 属于该站品牌图形，照抄=劣质复制品；书店用衬线渐变字标替代 |
| 参考站的 More Works 外链区 / 语言切换器 | 书店单语言纯中文；无外链需求 |

## 提取告警

| 告警 | 影响 | 处置 |
|---|---|---|
| 参考站为 React SPA，HTML 无静态内容 | 无法从 HTML 直接读版面 | 已用浏览器渲染后 DOM snapshot + 3 张截图补齐 |
| 用户未提供活动信息与店拍照片 | 活动列表、图片位无真实数据 | 活动用 3 场**可见标记为「示例」**的条目占位；图片位不放假图，用排版/光效承担；均在「待补」表登记 |
| 实体信息为虚构设定（瓦罗兰大陆） | 地址不可导航、联络不可达 | 用户明确提供且为创作设定，**逐字呈现不做替换**；交付说明中再次提示 |
