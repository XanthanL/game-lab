# Intent Summary — 老陈家面馆

## 意图摘要（intent-summary）

- **源材料**：扫描 PDF 菜单 2 页（`T07-menu.pdf`）→ 页图目视转写（无 OCR，非伪装），溯源表见 `source-map.md`
- **交付形态**：`standalone`（推断：用户仅说「做个网站」，无宿主站迹象）→ **G2 确认**
- **成功定义**：街坊/路人打开页面后，10 秒内知道招牌是什么、菜单有什么、几点开、店在哪，并能一键拨号预订
- **转化目标**：**到店**（p2 给了地址/营业时间/电话「可预订，到店自取不排队」——强证据）
- **图文策略**：图片=**要**（用户提供 8 张元宝 AI 生成示意图：裁水印 + PNG→JPEG 归一化后上站，页脚标注「AI 生成示意图」；菜单纯排版不上图，保台账扫读节奏）；图标=**none**
- **语言策略**：纯中文；默认 zh；无切换器（街坊客群，源内容纯中文）
- **参考站**：无
- **技术栈**：`plain-html`（判定与排除见 `tech-stack.md`）
- **族与锚点**：`nostalgic` 复古怀旧族 → 锚点 **`retro-nostalgic`**（做旧纸张、有限色板、时代特征字体；`imagePolicy: optional` 容忍零摄影）→ **G2 确认**
- **中轴**：`left-rail`（锚点声明；全站左对齐，菜单 flush-left 扫读，正文左对齐）
- **布局**：`editorial-hero`（锚点绑定）：全宽 hero（店名超大字 + 招牌面价格块充当主张 + 主 CTA）→ 菜单三区（面食/凉菜/饮料）→ 「一碗红烧牛肉面，街上吃了三代人」pull quote → 到店信息（不可折叠）→ 页脚
- **底色档**：`paper`（锚点签名默认 surface；纸白暖底）｜ **变体轴**：`a` 原值（批次首用）｜ **字体对**：锚点默认（display = DM Serif Display × 中文宋体系 zh-song；body = DM Sans × PingFang SC；mono = fragment）→ **G2 确认**
- **视觉签名（≥3，editorial-hero 签名菜单选取，渲染结果中可指认）**：
  1. 超大标题压过首屏 —— hero「老陈家面馆」72px + 招牌面价格数字 40px 为全站最大字号
  2. 章节编号超大字号当装饰 —— 菜单三区 01/02/03 衬线大字
  3. 引用块跨栏出血 —— 「一碗红烧牛肉面，街上吃了三代人。」pull quote 撑出版心右缘
  4. 首字下沉 —— 店史段首字「牛」下沉两行
- **区块与尺寸**：区块 = Hero（要）／菜单（要，p1 全量）／店的故事（要，p2 两句，不扩写）／到店信息（要，p2 全量，不可折叠）／Contact·邮箱·社交（**不做**，默认规则）；无图站，容器 = `--wrap` 1040px，正文列 62ch，菜单列 ≈ 42ch（无主图三档宽度问题，以容器三档代替）
- **硬约束**：食品红线 —— 不得出现极限词（最/第一/顶级）、不得编造评价/销量/荣誉；「三十年」「老卤十年不换」仅按源原文表述；价格必须与菜单一致；菜品**不得增删**（用户明说「别的就照菜单来」）
