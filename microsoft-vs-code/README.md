# 微软大战代码 · Microsoft vs. Code

梗图改编的恶搞塔防，内核致敬《植物大战僵尸》：你的电脑是一块代码编辑器草坪，
微软全家桶大军从右侧走来，要给你强制安装；你用代码单位守住编辑器。
零依赖、零构建，美术全部矢量绘制，音效由 Web Audio 合成。

## 运行方式

双击 `index.html` 即可，或任意静态服务器（`python -m http.server`）。

## 五个关卡

| 关 | 名称 | 设定 |
|---|---|---|
| 01 | 白天防守 `main.js` | 教学关：4 张卡，认识咖啡与 log |
| 02 | 通宵冲刺 `night-mode.ts` | 全夜无天空咖啡，经济全靠咖啡机 |
| 03 | 冲突水道 `merge --abort` | 中间两行是 merge 冲突水道，先铺「分支莲叶」才能种植；遥测隐身、弹窗会飞 |
| 04 | 机房防守 `prod.config.json` | 生产环境：Teams 通知不断弹小红点，.NET 框架 4.0 倒了还会再起 |
| 05 | 决战红盟 `REDMOND.key` | 夜 + 水道 + 两个「强制更新.exe」，全卡池 |

通关进度存 localStorage，选关页自动解锁下一关。

## 玩法

- 货币是**咖啡**：白天关卡天空会掉咖啡，点击收集；进入加班（或夜关）后天空停掉，只能靠咖啡机。
- 铲子是 **git revert**：移除自己的单位并**返还一半咖啡**。
- 撑过本关全部波次即胜利；任何敌人碰到左侧的主机即失败（主机蓝屏）。

## 操作

点卡片（或数字键 1-0）→ 点格子种植；点咖啡收集；`X` 或点铲子后点单位移除；
`ESC` 暂停。触屏可直接点按。

## 实现

`js/config.js`（布局/阵营数据/关卡表）、`js/art.js`（全矢量美术）、
`js/main.js`（引擎：状态机、关卡驱动、战斗、HUD、选关与存档）。
内部逻辑分辨率 1280×720，按视口等比缩放并叠加 devicePixelRatio。
`window.__mvc` 暴露调试钩子（`give` / `spawn` / `tap` / `to` / `start` / `unlockAll`），便于测试。
