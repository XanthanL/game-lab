# 微软大战代码 · Microsoft vs. Code

梗图改编的恶搞塔防，内核致敬《植物大战僵尸》：你的电脑是一块代码编辑器草坪，
微软全家桶大军从右侧走来，要给你强制安装；你用代码单位守住编辑器。
零依赖、零构建，美术全部矢量绘制，音效由 Web Audio 合成。

## 运行方式

双击 `index.html` 即可，或任意静态服务器（`python -m http.server`）。

## 玩法

- 货币是**咖啡**：上午会从天空掉落，点击收集；**加班时间到（约 100s 后）天空停掉**，只能靠咖啡机。
- 撑过三波 + 终局一大波全家桶即胜利；任何敌人碰到左侧的主机即失败。
- 铲子是 **git revert**：移除自己的单位并**返还一半咖啡**（比原版铲子良心）。

### 代码方 · 7 张卡

| 卡 | 成本 | 作用 |
|---|---|---|
| 咖啡机 | 50 | 每 20s 产一杯咖啡（25） |
| console.log | 100 | 发射 `{}` 日志子弹 |
| 机械键盘 | 175 | 双倍射速，发射键帽 |
| 防火墙 | 150 | 过滤包，命中减速 |
| 橡胶鸭 | 50 | 高血肉墙，被咬会嘎 |
| 断点 | 25 | 8s 武装，敌人踩中即炸 |
| rm -rf | 150 | 1s 引信，3×3 范围清空 |

### 微软方 · 6 种敌人

| 敌人 | 特点 |
|---|---|
| Clippy | 基础款，回形针还记得你 |
| IE 浏览器 | 极慢，还会原地"加载中" |
| Edge 弹窗 | 弹得飞快 |
| Windows 更新 | 坦克，周期**强制重启**你行内一个单位（瘫痪 4s） |
| 蓝屏 BSOD | 超坦，死亡时**整行蓝屏**瘫痪你的单位 3s |
| 强制更新.exe | 终局巨型 Boss，扛着 setup.exe 碾过来 |

## 操作

点卡片（或数字键 1-7）→ 点格子种植；点咖啡收集；`X` 或点铲子后点单位移除；
`ESC` 暂停。触屏可直接点按。

## 实现

单文件 `game.js`：主循环 / 实体 / 波次脚本 / 矢量美术 / WebAudio 合成音效，
内部逻辑分辨率 1280×720，按视口等比缩放并叠加 devicePixelRatio。
`window.__mvc` 暴露调试钩子（`give` / `spawn` / `tap` / `to`），便于测试。
