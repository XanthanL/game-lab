# 微软大战代码 · Microsoft vs. Code

梗图改编的恶搞塔防，内核致敬《植物大战僵尸》——但场景全部换成程序员的真实世界：
你的电脑是战场，微软全家桶大军要进来强制安装，你用代码单位守住编辑器。
零依赖、零构建，美术全部矢量绘制，音效由 Web Audio 合成。

## 运行方式

双击 `index.html` 即可，或任意静态服务器（`python -m http.server`）。

## 章节战役（一章一个场景，每章 2 小关，共 10 关）

| 章 | 场景 | 机制 |
|---|---|---|
| 第一章 本地环境 `localhost:3000` | 白天编辑器 | 公网咖啡随便掉（1-1 开机自启 / 1-2 热重载） |
| 第二章 离线机房 `offline.mode` | 断网内网 | 天上不掉咖啡，全靠咖啡机；Windows 更新与蓝屏登场（2-1 / 2-2） |
| 第三章 冲突水道 `merge --abort` | 分支仓库 | 中间两行是 merge 冲突水道，先铺「分支莲叶」（3-1 / 3-2） |
| 第四章 祖传迷雾 `legacy.wasm` | 遗留系统 | 右半场浓雾看不见僵尸；.NET 4.0 会复活（4-1 / 4-2） |
| 第五章 跨域高墙 `CORS:403` | 同源策略 | 左半深渊禁种、直线弹被弹开，只能甩 BUG 报告；终章双 Boss（5-1 / 5-2） |

进度、★、商店、花园、每关卡组全部存 localStorage。

## 核心循环（PvZ 元游戏转世）

- **咖啡**（战斗资源）：每杯 30，点击收集；加班/离线场景无空投。
- **★ Star**（跨关货币）：击杀僵尸掉落（Clippy 1★、BSOD 8★、Boss 40★），全战役共 145 只。
- **npm 商店**：店主是那只橡胶鸭（~quack~ 要装点什么？）。9 个永久包：
  `bug-report@latest`（新卡）、`undo@2.0.0`（每行第二枚 Ctrl+Z）、`ram@16gb`、`ssd@nvme`（冷却 -25%）、
  `coffee-machine-xl`、`duck-debugger-pro`、`monitor-calibration`、`star-vacuum-daemon`（★自动吸取）、`extra-seed-slot`。
- **副业花园**：`npm init` 播种（side project ★10 / 开源框架 ★30），每 20s 一次 `git commit` 浇灌（真实时间，关页面也长），`Release` 收 ★。
- **选卡出击**：每关从卡池里挑 N 张携带（槽位随进度解锁，商店可 +1），PVZ 种子选择器同款。
- **Ctrl+Z**：每行一次自动撤销救援（对标除草机），商店升级变两枚。
- **git revert 铲子**：移除单位返还一半咖啡。

## 操作

选关 → 选卡（可自动配卡）→ 点格子种植；点咖啡/★收集；数字键 1-0 选卡；
`X` 铲子；`ESC` 暂停。悬停卡片看单位说明。
**手机端**：自动切换为底部大卡片 dock（图标 + 价格 + 冷却遮罩），横屏竖屏均可玩。

## 实现

`js/config.js`（布局/阵营/章节战役/商店/花园）、`js/art.js`（全矢量美术）、
`js/main.js`（引擎 + 选卡/商店/花园界面 + 存档 v2）。
逻辑分辨率 1280×720 等比缩放叠加 devicePixelRatio。
`window.__mvc` 调试钩子：`pick(n, deck)` / `buy(pkg)` / `setStars(n)` / `unlockAll()` 等，供自动化测试。
