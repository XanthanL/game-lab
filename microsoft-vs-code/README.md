# 微软大战代码 · Microsoft vs. Code

梗图改编的恶搞塔防，内核致敬《植物大战僵尸》——但场景全部换成程序员的真实世界：
你的电脑是战场，微软全家桶大军要进来强制安装，你用代码单位守住编辑器。
零依赖、零构建，美术全部矢量绘制，音效由 Web Audio 合成。

## 运行方式

双击 `index.html` 即可，或任意静态服务器（`python -m http.server`）。

| 章 | 场景 | 外观 | 机制 |
|---|---|---|---|

## 三档外观：浅色 / 深色 / 午夜

PvZ 的白天与黑夜在这里换成编辑器主题：**浅色模式**是白天写代码，**深色模式**是加班，
**午夜模式**是那个线上炸了的凌晨。每关自带一档（跟随章节推进），标题栏的「外观」按钮可在
`自动 / 浅色 / 深色 / 午夜` 之间循环手动锁定，写进存档。三档各自是一整套调色板：
画布里的草坪、UI 条、迷雾与暗角，以及 DOM 层的面板、卡片、按钮全部跟着换（`body[data-mode]`）。
午夜那档自带一层冷蓝 mood 叠色，夜关的暗幕（veil）也在这档最重——难度和氛围是同一件事。

## 核心循环（PvZ 元游戏转世）

- **咖啡**（战斗资源）：每杯 30，点击收集；离线机房无空投。
- **★ Star**（跨关货币）：击杀僵尸掉落（Clippy 1★、BSOD 8★、Boss 40★），全战役剧本共 157 只（召唤物另计）。
- **npm 商店**：店主是那只橡胶鸭（~quack~ 要装点什么？）。11 个永久包，★ 直接扣：
  新卡三包 `bug-report@latest` ★45（BUG 报告投掷器，跨域高墙刚需）、`rebase-spike@1.2.0` ★55（不可啃咬的地板伤害）、`cors-anywhere` ★95（万能头，本行直线弹豁免 CORS 高墙）；
  能力包 `undo@2.0.0` ★60（每行第二枚 Ctrl+Z）、`ram@16gb` ★50（开局咖啡 +100）、`ssd@nvme` ★80（全卡冷却 -25%）、
  `coffee-machine-xl` ★70（咖啡机产出 30 → 40）、`duck-debugger-pro` ★40（橡胶鸭血量 +60%）、`monitor-calibration` ★90（4K 显示器伤害 120 → 180）、
  `star-vacuum-daemon` ★55（★ 自动飞进账户）、`extra-seed-slot` ★100（每关可携带单位 +1）。
- **副业花园**：`npm init` 播种（side project ★10 / 开源框架 ★30），每 20s 一次 `git commit` 浇灌（真实时间，关页面也长），`Release` 收 ★。
- **选卡出击**：每关从卡池里挑 N 张携带（槽位随章节 4→8，商店可 +1），PVZ 种子选择器同款。
  同一张卡可以带重复包（各自的冷却独立），自动配组就会给你重复的咖啡机、SSH 隧道与 BUG 报告。
- **Ctrl+Z**：每行一次自动撤销救援（对标除草机），商店升级变两枚。
- **git revert 铲子**：移除单位返还一半咖啡。

## 操作

选关 → 选卡（可自动配卡）→ **长按卡牌拖到草坪松手**种下，一松手只落一个，拖到空地松手则取消手持。
点咖啡/★收集；数字键 1-0 选中该卡再点格子；`X` 铲子；`ESC` 暂停。悬停卡片看单位说明。
**图鉴**分「代码方 · 你 / 微软方 · 敌」两栏独立切换，点任意单位进档案页看数值、功能与背景故事；没遭遇过的是一格剪影。
**手机端**：自动切换为底部大卡片 dock（图标 + 价格 + 冷却遮罩），同样长按拖放，横屏竖屏均可玩。

## 实现

`js/config.js`（布局/阵营/章节战役/商店/花园）、`js/art.js`（全矢量美术）、
`js/main.js`（引擎 + 选卡/商店/花园界面 + 三档调色板 + 存档 v2）。
逻辑分辨率 1280×720 等比缩放叠加 devicePixelRatio。
`window.__mvc` 调试钩子：`pick(n, deck)` / `buy(id)` / `setStars(n)` / `unlockAll()` / `state()` 等，供自动化测试。
