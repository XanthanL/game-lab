# 欧陆风云 · 1444

浏览器里的大战略原型。手绘欧洲、北非、安纳托利亚海岸线，用抖动网格 Voronoi 生成约 1300 个陆地省与 750 个海域，82 个国家按 1444 年开局分布。纯静态，无构建。

## 技术

- 原生 ES Module，直接打开 `index.html` 运行
- 所有地图生成与模拟逻辑在 `js/` 下，可被 Node 复用
- Canvas 2D 渲染，支持缩放 / 平移 / 7 种地图模式

## 系统

- 经济：税收、生产、贸易、陆军 / 海军 / 要塞维护费、账目明细（含补贴收支）、建筑、核心化、发展度、破坏度
- 金融：贷款、利息（受低息特权 / 国家银行修正）、铸币与通胀、战争税、对外补贴、国家银行、破产清算
- 军事：募兵（步骑炮编成）、将领（军事传统决定质量）、移动、地形战斗、围城、补给损耗、撤军、叛乱
- 攻防：纪律 / 士气 / 战斗力修正、要塞等级与要塞防御、围城能力、封锁断援、军事通行权、首都陷落代价
- 海军：三舰种编队、海战、封锁、运兵登陆、轻舰贸易力
- 外交：宣称、宿敌（体量相当才可设，附权力投射收益）、同盟（进攻战需忠诚盟友跟随）、王婚、保障、通行权、
  多类战争借口宣战、和约谈判、侵略扩张、包围网、禁运、友好度系统（±200，含同盟/联姻/边境摩擦/AE/礼物/使节等来源分解）
- 贸易：22 个贸易节点、贸易实力份额、商人转移 / 收取、封锁、禁运、轻舰挂靠、节点主导者 / 垄断收集加成
- 理念：12 个理念组（每组 7 条 + 完成奖励）、组间政策（每 2 组解锁 1 槽）
- 阶级：贵族 / 教士 / 市民 / 平民，影响力与忠诚、王权领地、12 条特权、夺地 / 开议会 / 卖头衔、忠诚崩坏叛乱
- 首都：城防 2 级、贸易力 +25%、本土贸易节点所在、占领改写战争分数、陷落迁都与威望重挫、可付点迁都
- 模拟：君主点数、科技、稳定度、威望、正统性、厌战、通胀、破坏度、叛乱、历史事件、12+ 种按国势触发的随机事件
- AI：结盟示好、宿敌挑选、断绝恶盟、造宣称、多类借口开战、募兵、围城、媾和、平叛、科技、理念、政策、特权、夺地、禁运、补贴、设银行

## 本地运行

```bash
# 直接用浏览器打开
index.html

# 或起一个静态服务器
python -m http.server 8000
```

## 开发校验

```bash
# 地图预览
node tools/map-preview.js --political

# 10 年冒烟测试
node tools/smoke.js 120

# UI 自检（DOM 桩渲染全部面板 + 遍历全部动作）
node tools/ui-check.js

# 一键全套检查（导入 + UI + 冒烟）
npm run check
```
