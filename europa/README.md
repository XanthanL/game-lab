# 欧陆风云 · 1444

浏览器里的大战略原型。手绘欧洲、北非、安纳托利亚海岸线，用抖动网格 Voronoi 生成约 1300 个陆地省与 750 个海域，82 个国家按 1444 年开局分布。纯静态，无构建。

## 技术

- 原生 ES Module，直接打开 `index.html` 运行
- 所有地图生成与模拟逻辑在 `js/` 下，可被 Node 复用
- Canvas 2D 渲染，支持缩放 / 平移 / 6 种地图模式

## 系统

- 经济：税收、生产、贸易、陆军 / 海军维护费、要塞维护费
- 军事：募兵、移动、战斗、围城、撤退
- 外交：宣称、宿敌、同盟、王婚、宣战、停战、侵略扩张、包围网
- 模拟：君主点数、科技、稳定度、威望、正统性、厌战、叛乱、历史事件
- AI：造宣称、开战、结盟、募兵、围城、媾和、平叛、科技投入

## 本地运行

```bash
# 直接用浏览器打开
index.html

# 或起一个静态服务器
python -m http.server 8000
```
