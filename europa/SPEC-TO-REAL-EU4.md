# Europa Universalis 4 复刻项目差异说明 (SPEC - Real EU4)

## 📊 概述

本项目 `europa` 是一个简化版的欧陆风云 4 浏览器实现，实现了核心机制的 70-80%。本文档详细列出未实现或简化程度较高的系统。

---

## 🎯 核心缺失系统

### 1. **宗教系统** 🔴 重大缺失

#### 当前实现
- 仅有基础宗教定义（天主教/东正教/逊尼派/什叶派等）
- 宗教对国家属性是固定的

#### 真实 EU4
```
缺失功能:
- ✗ 传教士系统 (Missionaries)
- ✗ 宗教改革机制
- ✗ 教派转换 (如天主教→新教各派系)
- ✗ 宗教联盟机制
- ✗ 异端审判特权
- ✗ 圣战机制
- ✗ 宗教氛围对稳定度的影响
```

**实现难度**: ⭐⭐⭐⭐  
**优先级**: 高（影响游戏主题）

## 💰 数值简化情况

### 1. **战斗系统简化**
- ✓ 已实现：兵种比例、纪律、将领属性、地形修正
- ✗ 缺失：侧翼包抄加成、伏击机制、夜袭加成

### 2. **经济系统简化**
- ✓ 已实现：税收、生产、贸易三层收入
- ✗ 缺失：
  - 通货膨胀深度模型（现仅简单加减）
  - 地区物价差异 (price level by region)
  - 商品短缺事件 (commodity shortage)

### 3. **人力恢复简化**
- ✓ 已实现：maxManpower * 0.04/month
- ✗ 缺失：
  - 人力税 (manpower tax) 加速恢复
  - 征兵法案 (conscription) 政策
  - 殖民地人力提取限制

### 4. **发展度提升简化**
- ✓ 已实现：花费点数提升 baseTax/baseProd/baseManpower
- ✗ 缺失：
  - 自动发展速度 (auto dev growth)
  - 发展度衰减 (devastation 后需多年修复)
  - 省份潜力上限 (province development cap)

## 🎮 设计哲学建议

### 保持简化的领域
- ✗ 不建议实现：政府改革、殖民系统
  - **理由**: 复杂度呈指数增长，但玩家体验收益递减

### 值得投入的领域
- ✅ 推荐实现：外交细节、贸易深度
  - **理由**: 符合 EU4 "慢战略" 核心，且代码结构清晰

### 避免过度模拟
- ❌ 不要追求 100% 还原
- ✅ 重点抓 "关键时刻" 的决策压力
- ✅ 保留"手停口停"的紧迫感

## 📝 总结

`europa` 项目已经是一个相当完整的 EU4 精简实现，覆盖了：
- ✅ 核心的经济与财政系统
- ✅ 深度的军事与战斗机制
- ✅ 复杂的贸易网络
- ✅ 完整的理念与政策系统
- ✅ 阶级的政治斗争

**最值得继续开发的领域**:
1. **外交细节** - 使节、条约、继承危机
2. **贸易深化** - 走私、海盗、垄断
3. **历史事件** - 关键历史节点的剧情化

**建议放弃的领域**:
- ❌ 殖民与海外扩张 (地图规模爆炸)
- ❌ 政府改革树 (维护成本过高)
- ❌ 完整事件库 (需要数十万字文案)

**最终定位**: 作为一个 "EU4 风格的历史策略模拟器",而非 100% 复刻，这个项目已经达到了很高的完成度。**真正的乐趣在于做出那些"小而深刻"的决策**,而不是被无限的选择淹没。
