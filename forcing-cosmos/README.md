# 强渡宇宙 · FORCING COSMOS

像素风卡牌构筑 Roguelike（杀戮尖塔式玩法）。纯 HTML5 Canvas + WebAudio，**零依赖、零构建、零外部美术资源** —— 所有画面由调色板字符串在运行时烘焙，所有声音由振荡器合成。

> 公元 2099 年，地球已死。五十亿人挤在火星轨道的殖民站「温床」里。
> 你完成了第一次强渡，杀死了火星地下的星体寄生虫。
> 但探针在它的残骸里读到一段共振——它只是一个网络的节点。
> 共振梯度笔直指向外侧：穿过小行星带，指向一个坐标无解的地方。
> 计划代号：**强渡宇宙**。

## 玩法

杀戮尖塔式回合制卡牌构筑：抽牌 → 花电量出牌 → 结束回合 → 敌人行动。

| 操作 | 键位 |
|---|---|
| 出牌 | 点击卡牌；或把卡拖到敌人身上（拖到空白处取消） |
| 结束回合 | 空格 / Enter / 右下按钮 |
| 用药水 | 点击左下药水槽（仅我方回合） |
| 查看牌组 | 右下「牌组」 |
| 暂停 / 静音 | Esc·P / M |

**手机 / 平板**：点选卡牌，再点敌人确认（拖拽也行）；左上角是暂停，右下角是「结束回合」。
竖屏会自动把画面转 90° 铺满屏幕，**横屏体验更好** —— 转一下手机即可。

- **电量**：每回合回满，出牌消耗；**护盾**在我方回合开始时清零（「下回合不清零」的卡除外）
- **状态**：力量（攻击 +N，永久）· 易伤（受伤 ×1.5）· 虚弱（造成伤害 ×0.75）· 灼烧（每回合扣层数血后 -1）· 中毒（每回合扣层数血，不衰减）· 反伤
- **三幕推进**：火星 → 小行星带 → 深空奇点。每幕一张分支地图，走 6 个节点（战斗 / 精英 / 异象 / 休整 / 补给站），尽头是幕末 BOSS
- **构筑**：战后三选一（卡牌 / 升级 / 金币 / 药水）、遗物、药水、商店买卡与删卡
- **结局**：4 种（虚空 / 净化 / 牺牲 / 平衡），由你一路上的选择决定

## 乘员

| 乘员 | 生命 | 电量 | 被动 |
|---|---|---|---|
| 宇航员 | 80 | 3 | 回合开始 10% 概率 +1 护盾 |
| 工程兵 | 70 | 4 | 打出护盾牌额外 +2 护盾 |
| 异变者 | 75 | 3 | 打出施加状态的牌，层数翻倍 |
| 突击兵 | 65 | 3 | 打出攻击牌 15% 概率 +1 电量 |

## 本地运行

```bash
python -m http.server 8000    # 然后打开 http://localhost:8000/
```

## 调试参数

`?noanim=1` 冻结 CSS 动画 · `?auto=1` 直接进战斗 · `&act=N` 指定幕 · `&boss=1` / `&elite=1` 指定节点 · `&map=1` 直接看地图
