# 强渡宇宙 · FORCING COSMOS

像素风卡牌构筑 Roguelike（杀戮尖塔式玩法）。纯 HTML5 Canvas + WebAudio，**零依赖、零构建、零外部美术资源** —— 所有画面由调色板字符串在运行时烘焙，所有声音由振荡器合成。

> 公元 2099 年，地球已死。五十亿人挤在火星轨道的殖民站「温床」里。
> 你完成了第一次强渡，杀死了火星地下的星体寄生虫。
> 但探针在它的残骸里读到一段共振——它只是一个网络的节点。
> 共振梯度笔直指向外侧：穿过小行星带，指向一个坐标无解的地方。
> 计划代号：**强渡宇宙**。

## 玩法

杀戮尖塔式回合制卡牌构筑：抽牌 → 花电量出牌 → 结束回合 → 敌人行动。

| 操作 | 键位 |
|---|---|
| 出牌 | 点击卡牌；或把卡拖到敌人身上（拖到空白处取消） |
| 结束回合 | 空格 / Enter / 右下按钮 |
| 用药水 | 点击左下药水槽（仅我方回合） |
| 查看牌组 | 右下「牌组」 |
| 查看抽/弃/消耗堆 | 左下「抽 N / 弃 N / 耗 N」（点开可看内容；**抽牌堆顺序已打乱**，不公开下一张） |
| 暂停 / 静音 | Esc·P / M |

**手机 / 平板**：点选卡牌，再点敌人确认（拖拽也行）；左上角是暂停，右下角是「结束回合」。
竖屏会自动把画面转 90° 铺满屏幕，**横屏体验更好** —— 转一下手机即可。

- **出牌演出**：卡牌会从手牌**飞向目标**（攻击牌飞向敌人、护盾/增益/治疗飞向自己），落地才结算并炸开；多重打击牌**逐击**演出
- **伤害预测**：鼠标悬停（或拖动）攻击牌时，敌人血条下方直接显示这一下会打多少（已算进力量 / 虚弱 / 易伤 / 敌人护盾）
- **手牌上限 10**：手牌满时抽到的牌直接进弃牌堆并提示
- **电量**：每回合回满，出牌消耗；**护盾**在我方回合开始时清零（「下回合不清零」的卡除外）
- **状态**：力量（攻击 +N，永久）· 易伤（受伤 ×1.5）· 虚弱（造成伤害 ×0.75）· 灼烧（每回合扣层数血后 -1）· 中毒（每回合扣层数血，不衰减）· 反伤
- **三幕推进**：火星 → 小行星带 → 深空奇点。每幕一张分支地图，走 6 个节点（战斗 / 精英 / 异象 / 休整 / 补给站），尽头是幕末 BOSS
- **构筑**：战后三选一（卡牌 / 升级 / 金币 / 药水）、遗物、药水、商店买卡与删卡
- **结局**：4 种（虚空 / 净化 / 牺牲 / 平衡），由你一路上的选择决定
- **梯度等级**：选人页可选 Lv.0–10 的难度阶梯。每级叠一条独立修正（敌人 +10% 生命 / +10% 伤害 / 开局多带 1 张诅咒 / 精英 +20% / 商店 +25% / 休整 -30% / BOSS +25% 生命 / 每战开局 -3 生命 / 起始金币 -20 / 再 -3 生命）。**通关 Lv.N 才解锁 Lv.N+1**
- **航行日志**：标题页可看累计强渡次数 / 通关 / 击坠 / 走过的节点 / 最高梯度，以及最近 12 局的明细（职业 · 梯度 · 结局 · 节点 · 胜场 · 牌数 · 用时）。局外进度存在本地，可一键清空

## 乘员

| 乘员 | 生命 | 电量 | 被动 | 卡面主色 | 基础牌（10 张） |
|---|---|---|---|---|---|
| 宇航员 | 80 | 3 | 回合开始 10% 概率 +1 护盾 | 蓝 | 气动射击 ×4 · 气动护壁 ×4 · 漂移推进 · 轨道扫描 |
| 工程兵 | 70 | 4 | 打出护盾牌额外 +2 护盾 | 绿 | 铆钉射流 ×3 · 隔舱壁 ×5 · 荆棘镀层 · 盾击 |
| 异变者 | 75 | 3 | 打出施加状态的牌，层数翻倍 | 紫 | 孢子箭 ×3 · 几丁质层 ×4 · 诱变剂 ×2 · 诱变云 |
| 突击兵 | 65 | 3 | 打出攻击牌 15% 概率 +1 电量 | 红 | 点射 ×4 · 速防 ×3 · 破片榴弹 ×2 · 连击终结 |

每个乘员有**专属的基础牌与卡面主色**：基础牌只在本职业的奖励池里出现，卡面外框用职业色（底部类型条仍是类型色）。

## 内容量

52 张可选卡（36 通用 + 16 职业专属，全部可升级）+ 3 张诅咒 · **24 件遗物** · 18 种敌人 ·
3 座 BOSS · 10 个事件 · 6 种状态 · 6 种药水 · 10 级难度阶梯。

遗物分六类：战斗开始（护盾/力量/反伤/易伤/首回合电量）、战斗结算（金币/回血）、
出牌时（护盾牌加成/攻击牌给盾/首张攻击加伤）、条件加伤（低血加伤/每张诅咒加伤）、
防御（无盾减伤/消耗回血）、经济（商店打折/休整加成）。

## 本地运行

```bash
python -m http.server 8000    # 然后打开 http://localhost:8000/
```

## 调试参数

`?noanim=1` 冻结 CSS 动画 · `?auto=1` 直接进战斗 · `&act=N` 指定幕 · `&boss=1` / `&elite=1` 指定节点 · `&map=1` 直接看地图
