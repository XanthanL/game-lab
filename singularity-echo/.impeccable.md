# Design Context — 奇点回响 · Singularity Echo

> 本文件是 `impeccable` 的设计上下文来源（Phase 0.1 产出）。
> 任何视觉改动前先读这里；改方向时改这里，不要在绘制代码里各改各的。

## Users

- **主受众**：独立游戏玩家（roguelite / 双摇杆射击 / Nova Drift 类玩家）。
- **使用情境**：桌面浏览器键鼠为主，移动端为次要入口；单局 10–30 分钟。
- **要完成的事**：在惯性漂移中构筑一套 build，撑过 30 波，击败奇点回响。
- **次要受众**：GAME LAB 作品集访客 —— 点开看 60 秒，据此判断"作者会不会做东西"。
  这一层决定了**首屏 10 秒的视觉密度必须极高**，但不能靠堆元素，要靠构图的确定性。

## Brand Personality

- **三个词：孤独、壮阔、精确。**
- **语气**：冷静、克制、不解释。像一份观测日志，不像游戏宣传语。
- **情绪目标**：让人感到自己在一张巨大的星图上缓慢滑行 —— 周围是空的、冷的、真实的，
  而你是其中唯一在动的东西。

## Aesthetic Direction

**方向：星图测绘 / 天文台（Celestial Cartography）**

视觉语言取自**古代航海图与星图**，而不是现代科幻霓虹：

- 深墨底 + 暖白细线 + 单一朱砂强调色
- 刻度环、坐标网格、发丝分隔线、方位标记
- 六种船体使用**天然矿物颜料色板**（石青 / 朱砂 / 赭石 / 石绿 / 铅白 / 紫），
  都是带灰度的低饱和色 —— 既统一，又能区分
- 主题：**暗色为唯一主场**（太空不存在 light 模式），不做明暗双主题
- 尺度表达：极小的玩家 vs 极大的背景参照物（行星弧、恒星、巨构剪影）

**反参考（明确不要）**

| ❌ 不要 | 原因 |
|---|---|
| 常见"太空霓虹"：青紫渐变 + 到处发光 + 玻璃拟态 | 这正是当前的问题 —— 一眼 AI 味，且与市面同类无法区分 |
| 手游休闲风：圆角糖果色、大按钮、奖励爆炸 | 与"孤独壮阔"直接冲突 |
| 像素复古 8-bit | 另一条赛道，会稀释方向 |
| 赛博朋克式高饱和黄青对撞 | 太吵，破坏"安静是默认" |

**要避免的反模式**

- **用"更亮 / 更多光晕"表达力量。** 力量靠"画面先安静下来，然后一次爆发"。
  常态发光 = 没有重点 = 廉价。
- **用更多元素表达丰富。** 曾连续六版给背景叠加图层，换来一句"不符合质感要求"。
  丰富来自层次与节奏，不来自元素数量。

## Design Principles

1. **安静是默认，爆发是事件** —— 90% 的时间画面应当低饱和、低亮度；
   高饱和只留给奇点、Boss 登场、濒死三种时刻。
2. **线条优先于光晕** —— 质感来自线的精度（对齐、粗细阶梯、端点收束），
   不来自 blur 叠加。blur 越大越糊越廉价。
3. **尺度靠参照物** —— 壮阔来自"极小的玩家 vs 极大的背景"，
   不来自把背景本身画得更大更满。
4. **每个颜色都要有出处** —— 颜色只能来自设计系统的 token；
   绘制代码里不允许出现新的十六进制色值。
5. **动效必须有理由** —— 每次动效先回答它是"反馈 / 空间 / 状态 / 氛围"中的哪一个，
   答不出来就不做。键盘触发的高频操作不做动效。
