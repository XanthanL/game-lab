# Suno 提示词 · 扩展曲库（两套互斥人格）

> **基准不变**：Le Metroid《Black Hole》式 chillsynth / space lofi —— 空灵暖 analog pad + 长混响，全 instrumental。
> **新增变量**：两套"音乐人格"叠加在基准上，**一局只生效一套**（互斥，不混用）：
> - **A · 迷航 drift** = Blood Cultures 系 —— 迷幻、慵懒、失重、拼贴式 lo-fi
> - **B · 机械 machine** = Daft Punk 系 —— French house 律动、滤波扫频、机械推进
>
> **命名规范**：`「中文 / English」`，磁盘文件名 `___` 代替 ` / `（例：`「潮汐梦游___Tidewalk」.mp3`）。
> **时长**：目标 3:30–4:30，不够用 Extend 接长。生成时勾 **Instrumental**。
> **挑版**：Suno 偶发"结构性结尾"（突然收尾），循环用要挑结尾能自然接回开头的版本。

## 接入方式（改 index.html 的 BGMManager）

两套人格互斥 = 换 url 数组。最小改动：

```js
/* 音乐人格：drift（Blood Cultures 系）/ machine（Daft Punk 系），一局只生效一套 */
const BGM_PERSONA = (()=>{ try{ return localStorage.getItem('se_bgm_persona')||'drift'; }catch(e){ return 'drift'; } })();

const BGM_BASE = {   // 现有基准曲库，人格只覆盖下面四个阶段
  menu:   {urls:['bgms/「凝醒___Cryo_Wake」.mp3'],loop:true},
  combat: {urls:['bgms/「陨雨___Asteroid_Rain」.mp3'],loop:true},
  evolve: {urls:['bgms/「镀金裂变___Goldbreak」.mp3'],loop:true},
  end:    {urls:['bgms/「余晖___Afterglow」.mp3'],loop:true}
};
const BGM_PERSONAS = {
  drift: {   // A 组
    cruise: {urls:['bgms/「潮汐梦游___Tidewalk」.mp3'],loop:true},
    boss:   {urls:['bgms/「静默圣像___Still_Idol」.mp3'],loop:true},
    endless:{urls:['bgms/「余烬摇篮___Ember_Cradle」.mp3'],loop:true}
  },
  machine:{  // B 组
    cruise: {urls:['bgms/「霓虹轨道___Neon_Orbit」.mp3'],loop:true},
    boss:   {urls:['bgms/「机械神殿___Machine_Temple」.mp3'],loop:true},
    endless:{urls:['bgms/「超光速___Superluminal」.mp3'],loop:true}
  }
};
/* combat 在两套里各有一首，按人格覆盖；base 里的作为兜底 */
```

构造时合并：

```js
this.groups = Object.assign({}, BGM_BASE, BGM_PERSONAS[BGM_PERSONA] || BGM_PERSONAS.drift);
```

**注意**：cruise / endless 原本是**双轨轮换**（`loop:false` + 严格交替）。A/B 组各只有 1 首，想保持轮换就把它们和原有的 part1/part2 拼进同一组 urls（三轨轮换），例如：

```js
cruise:{urls:['bgms/「彗尾___Comet_Trail」1.mp3','bgms/「彗尾___Comet_Trail」2.mp3','bgms/「潮汐梦游___Tidewalk」.mp3'],loop:false}
```

⚠️ 但**同组内混入不同人格会风格跳变**——要三轨轮换就整套换（cruise 三轨全用 drift，或全用 machine），别半套。

**体积**：新增 8 首 × ~5MB ≈ 40MB。别一次性预热，`warm()` 只下每组第一首（现有逻辑已如此），轮换组第二首由播放时就地预取。
