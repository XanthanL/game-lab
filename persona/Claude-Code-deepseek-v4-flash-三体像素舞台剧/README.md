# 三体 · 像素舞台剧（NDS 双屏）

刘慈欣《三体》改编的 **NDS 风格双屏像素动画舞台剧**。从剧本到演出，全部由纯前端实现 ——
单文件 HTML，零依赖，双击即可开演。

**制作：Claude Code × deepseek-v4-flash**

## 运行方式

直接双击 `Claude-Code-deepseek-v4-flash-三体像素舞台剧.html`（推荐 Chrome / Edge）。
无需服务器、无需联网、无需任何构建步骤。

## 操作

| 输入 | 作用 |
|---|---|
| 触屏 / 鼠标点按（上屏或下屏） | 推进剧情（打字中＝立刻打完） |
| 空格 / 回车 | 同点按 |
| P | 暂停 / 继续 |
| M | 菜单 |
| S | 当前幕剧本 |
| 1 – 5 | 直接跳幕 |
| R | 从头开演 |
| Esc | 关闭覆盖层 |

演出**全程自动**：台词自动打出、特效自动触发、自动转幕；点按只是加速。
下屏是「剧本与触控」屏 —— 可随时翻看当前幕的完整剧本（点任意一行即可跳转演出），
或通过菜单进入「幕次选择」「全剧剧本」。

## 剧目结构（约 7 分钟）

1. **第一幕 · 红岸基地** —— 叶文洁借太阳发出啼鸣；四年后，"不要回答！不要回答！！不要回答！！！"跨越四光年而来
2. **第二幕 · 三体游戏** —— 汪淼进入 VR 游戏：乱纪元脱水、恒纪元浸泡（天空即三体问题的实时 N 体数值模拟）
3. **第三幕 · 古筝行动** —— 纳米飞刃将审判日号切成五十厘米厚的薄片
4. **第四幕 · 水滴** —— 两千艘战舰的舰队，被一枚探测器如穿纸般击穿；自然选择号，前进四
5. **第五幕 · 黑暗森林** —— 罗辑的墓前宣言；"你们是虫子！""虫子……从来没有被真正战胜过。"；人类的落日
6. **谢幕** —— 制作名单

## 实现说明（前端引擎）

```
剧本（JS 数据：幕 / 指令 / 台词）
   → 舞台管理器（状态机：打字、特效、转幕、跳转）
   → 渲染器（上屏 256×192 舞台 / 下屏 256×192 剧本与触控，3× 点阵放大）
```

- **像素美术**：手绘点阵精灵（调色板字符串 → Canvas）+ 程序生成（星空、山脉、粒子、切片船体）
- **三体问题**：三质点引力 N 体数值模拟实时驱动「三体世界」的天空，太阳远近直接决定乱纪元/恒纪元的画面色调
- **音乐**：WebAudio 芯片音序器，7 支循环曲目按场景切换；全套 8-bit 音效
- **双屏 NDS 外壳**：纯 CSS 机身、十字键、电源灯、CRT 扫描线
- **零依赖**：HTML + CSS + 原生 JS，单文件 ~200KB
