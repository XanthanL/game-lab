# 银河邮差 · 像素舞台剧

> 从剧本到演出，全部由前端实现 —— 一个用 HTML / CSS / JavaScript 打造的
> **像素风动画舞台剧**。零依赖、零构建，双击即演。

**作者**：Codex · GPT-5　**形式**：像素动画 · 舞台剧

---

## 剧情

夜深了，小城睡着了，只有巷口邮局的灯还亮着。

邮差**小满**接到一封信，信封上歪歪扭扭写着：「寄给最亮的那颗星」。
他把信折成一只纸船，顺着河水流进银河，替一个孩子把想念送到了星星那里——
星星读完后，回赠了一点暖暖的光。

| 幕 | 名称 | 内容 |
| --- | --- | --- |
| 序幕 | 夜班邮局 | 小满在深夜里整理最后一封要寄到天上的信 |
| 第一幕 | 寄信的孩子 | 孩子请小满把信寄给住在星星上的人 |
| 第二幕 | 纸船启航 | 信被折成纸船，河水载着它流向银河 |
| 第三幕 | 银河之上 | 小满沿星光铺成的河驶向银河深处 |
| 第四幕 | 星星的回信 | 最亮的星星读完信，落下一点温暖的光 |
| 终幕 | 黎明归来 | 天亮了，孩子收到星星的回信：想念会变成光 |

## 运行方式

直接双击 `index.html` 即可开演（或任意静态服务器）：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

## 操作

| 操作 | 效果 |
| --- | --- |
| 点击舞台 / 回车 | 推进台词（打字机立即打满 → 下一句） |
| 空格 / ⏸ 按钮 | 暂停 / 继续 |
| ← / → 方向键 | 上一幕 / 下一幕 |
| ☰ 按钮 / Esc | 返回节目单 |
| ♪ 按钮 / M 键 | 声音开关 |
| 完整剧本 / S 键 | 浏览剧本全文 |
| 节目单点击任意一幕 | 直接跳演该幕 |

> 也支持深链直达，例如 `index.html?start=1&act=3&cue=1` 直接跳到「银河之上」幕。

## 技术实现

- **舞台（上屏）**：单张 `<canvas>` 逻辑分辨率 256×192，CSS 放大并启用
  `image-rendering: pixelated`，所有图形按 1px 整数坐标程序化绘制
  （圆形 / 圆环 / Bresenham 直线 / 像素精灵 / 逐行渐变）。
- **戏台外壳**：红绒幕布 + 金色木框戏台 + 脚灯，下方是「节目单 / 台词 / 剧本」
  三块可切换面板，整体呈现一座微缩剧院。
- **剧本即数据**：`js/script.js` 是完整舞台剧本（幕、角色、台词、舞台指示、音效点），
  演出引擎直接读取驱动整场演出 —— 改剧本即改演出。
- **音效**：Web Audio API 用方波 / 正弦 / 三角波 / 噪声合成的温暖音效
  （划火柴、铃声、风、流星、星星、黎明）与循环音乐盒配乐，零音频资源。
- **确定性随机**：星空、城市窗户用种子随机数生成，每次演出画面一致。
