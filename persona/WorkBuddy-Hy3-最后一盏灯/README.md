# 最后一盏灯 · 像素舞台剧

> 从剧本到演出，全部由前端实现 —— 一个用 HTML / CSS / JavaScript 打造的
> **像素风动画舞台剧**。零依赖、零构建，双击即演。

**作者**：WorkBuddy (Hy3)　**形式**：像素动画 · 舞台剧

---

## 剧情

夜。一座小城。所有的路灯都熄了，像合上的眼。

唯一的**点灯人**提着一盏玻璃提灯，走过死寂的街道，点亮城里最后一盏灯。
一个躲在暗处的孩子，循着那圈温暖的光，悄悄跟了上来——
于是关于火、记忆与传承的故事，在灯下一句一句地讲了起来。

| 幕 | 名称 | 内容 |
| --- | --- | --- |
| 序幕 | 熄灭的城市 | 点灯人走进熄了灯的小城，走向最后那根灯杆 |
| 第一幕 | 点灯人 | 划亮火柴，灯亮了；暗处，孩子的眼睛亮了一下 |
| 第二幕 | 跟随 | 点灯人提灯前行，孩子不远不近地跟着 |
| 第三幕 | 灯下 | 灯下闲坐，点灯人讲起父亲——第一位点灯人 |
| 第四幕 | 风 | 狂风想吹灭灯，孩子张开手臂，替它挡了一会儿 |
| 终幕 | 黎明 | 灯被轻轻旋灭，孩子接过小提灯；光，传了下去 |

## 运行方式

直接双击 `index.html` 即可开演（或任意静态服务器）：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

## 操作

| 操作 | 效果 |
| --- | --- |
| 点击舞台 / 空格 / 回车 | 推进台词（打字机立即打满 → 跳下一句） |
| ← / → 方向键 | 切换上一幕 / 下一幕 |
| ☰ 按钮 / Esc | 返回节目单 |
| ⏸ / 空格（演出中）| 暂停 / 继续 |
| ♪ / M 键 | 声音开关 |
| 完整剧本 / S 键 | 浏览剧本全文 |
| 节目单点击任意一幕 | 直接跳演该幕 |

> 也支持深链直达，例如 `index.html?act=4&t=8` 直接跳到「风」幕第 8 秒。

## 技术实现

- **舞台（上屏）**：单张 `<canvas>` 逻辑分辨率 256×192，CSS 放大并启用
  `image-rendering: pixelated`，所有图形按 1px 整数坐标程序化绘制
  （字符画精灵 + Bresenham 直线 + 逐行圆盘 / 椭圆 / 圆环）。
- **戏台外壳**：红绒幕布 + 木质金边戏台 + 脚灯，下方是「节目单 / 台词 / 剧本」
  三块可切换的触控面板，整体呈现一座微缩剧院。
- **剧本即数据**：`js/script.js` 是完整的舞台剧本（角色、台词、舞台指示、音效点、
  上屏大字），演出引擎直接读取驱动整场演出 —— 改剧本即改演出。
- **音效**：Web Audio API 用方波 / 正弦 / 三角波 / 噪声合成的温暖音效
  （火柴、点灯、风声、雨声、音乐盒音阶、黎明），零音频资源。
- **确定性随机**：星空、房屋窗户用种子随机数生成，每次演出画面一致。
