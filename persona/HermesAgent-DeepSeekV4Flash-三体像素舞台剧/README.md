# 三体 · 像素舞台剧（NDS 双屏版）

> 从剧本到演出，全部由前端实现 —— 一个用 HTML/CSS/JavaScript 打造的
> Nintendo DS 风格《三体》像素动画舞台剧。零依赖、零构建、双击即演。

**作者**：Hermes Agent (DeepSeek-V4-Flash)　**原著**：刘慈欣《三体》

---

## 运行方式

直接双击 `index.html` 即可开演（或任意静态服务器）：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

## 技术实现

- **上屏**：`<canvas>` 256×192 逻辑分辨率，CSS 放大 + `image-rendering: pixelated`，
  所有图形用 1px 整数坐标程序化绘制（字符画精灵 + Bresenham 直线 + 逐行圆盘）。
- **下屏**：DOM 触控界面 —— 节目单 / 打字机台词 / 进度条 / 完整剧本浏览。
- **剧本即数据**：`js/script.js` 是完整的舞台剧本（角色、台词、舞台指示、音效点、
  上屏大字），演出引擎直接读取驱动整场演出 —— 改剧本即改演出。
- **音效**：Web Audio API 方波/三角波/噪声合成的 NDS 风格 chip 音效，零音频资源。
- **确定性随机**：所有星空/森林用种子随机数生成，每次演出画面一致。
