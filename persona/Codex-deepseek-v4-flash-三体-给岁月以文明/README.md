# 《三体 · 给岁月以文明》NDS 像素舞台剧

> 作品名：三体 · 给岁月以文明（NDS 像素舞台剧）
> 制作者：Codex · GPT-5
> 形式：纯前端实现 —— 剧本、演出、像素美术、舞台调度、音效与配乐全部在浏览器中即时生成，无任何外部依赖、无网络请求、无素材文件。

## 一、如何运行

直接用 Chrome / Edge 打开 `index.html` 即可，无需服务器、无需安装任何东西。

也可以用任意静态服务器（如 `npx serve .`）访问，效果相同。

> 演示用快捷参数：`index.html?start=1` 自动开演；`index.html?start=1&scene=6` 从指定场次开演；`index.html?start=1&scene=5&cue=3` 从指定台词/特效开始。

## 二、操作说明

界面是一台拟真的 NDS 双屏掌机：上屏是舞台，下屏是对白与菜单。

| 按键 | 作用 |
| --- | --- |
| A / 空格 / 回车 / 点击屏幕 | 推进对白、确认、跳过幕间字幕 |
| ↑ / ↓ | 标题页选开演场次；演出中切换上一幕/下一幕 |
| B | 切换自动演出 / 手动推进 |
| X | 打开剧本阅读器（可跳转到对应场次排练） |
| Y | 声音开 / 关 |
| START / P | 暂停 / 继续 |
| SELECT / O | 返回标题 |

屏幕上的 D-pad、A/B/X/Y、START/SELECT 按钮都可以直接用鼠标点击。

## 三、剧目大纲（八场）

1. **序幕 · 红岸基地** —— 1969 年，叶文洁把人类的第一束电波射向太阳。
2. **第一幕 · 乱纪元** —— 三体世界三颗太阳共舞；1379 号监听员收到回信：“不要回答”。
3. **第二幕 · 智子 · 宇宙闪烁** —— 质子展开为二维，封锁人类物理，星空变成显示屏。
4. **第二幕 · 古筝行动** —— 纳米丝横切“审判日”号。
5. **第三幕 · 面壁者** —— 罗辑被选为第四位面壁者；水滴毁灭整支舰队。
6. **第三幕 · 威慑纪元** —— 罗辑以同归于尽威慑三体；执剑人交接给程心。
7. **第四幕 · 黑暗森林** —— 引力波广播坐标；二向箔展开，太阳系被二维化。
8. **尾声 · 星舰人类** —— “宇宙很大，生活更大。我们一定会再见面。”

## 四、技术实现

- **双屏渲染**：上下两块 256×192 的 Canvas，2 倍像素化放大，配扫描线、屏幕高光与 NDS 外壳。
- **像素引擎**：程序化生成像素角色（头像 + 行走小人，两帧动画），不做任何位图素材。
- **三体问题实时模拟**：乱纪元场次的三颗太阳按真实三体引力方程逐帧积分，轨道混沌、近距时天空泛红。
- **背景与特效**：红岸天线、沙丘废墟、智子之眼、宇宙闪烁、水滴、古筝琴弦、引力波广播、二向箔二维化等全部用 Canvas 指令实时绘制。
- **剧本即演出**：`js/script.js` 里的剧本数据驱动一切——对白、舞台调度、转场、音效、配乐都从同一份数据演出；剧本阅读器由同一数据生成，可一键跳到任意场次。
- **程序化音效**：WebAudio 合成对白提示音、电波、雷鸣、水滴、警报与五套循环配乐主题。

## 五、文件结构

```
index.html            页面骨架（NDS 外壳 + 双屏）
css/style.css         主机外观、按钮、像素化放大
js/engine.js          像素引擎：绘制、文字、角色、WebAudio
js/script.js          剧本数据：角色、八场戏、对白与调度线索
js/play.js            演出系统：舞台调度、背景、特效、输入、剧本阅读器
```
