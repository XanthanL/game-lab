# NOVA DRIFT · 新星漂移

一款单文件太空 roguelike 弹幕射击游戏。驾驶 customizable 战机穿越 30 波星区，击碎巨像、装配模块、构筑流派，最终肃清星域 —— 或者进入无尽漂移，看看自己能走多远。

- **纯前端**：打开 `index.html` 即玩（建议通过本地 HTTP 服务器访问，详见下文）

- **零依赖**：全部逻辑、渲染、程序化 BGM/SFX 均为原生 Canvas + Web Audio

- **跨端**：键鼠 + 触屏双操作方案，进度自动缓存于 localStorage，关页可续

## 基本操作

| 操作             | 键鼠                  | 触屏        |
| -------------- | ------------------- | --------- |
| 推进 / 转向        | WASD / 方向键          | 左半屏拖动     |
| 瞄准 / 射击        | 鼠标瞄准，空格或按住左键开火      | 右下 FIRE 键 |
| 暂停             | P / ESC             | —         |
| 静音             | M                   | —         |
| 设置（BGM/SFX 音量） | O                   | —         |
| 升级选卡           | 1 / 2 / 3 点选，R 刷新一次 | 点按        |

游戏目标：清空每波敌人与岩石，每 5 波迎战一场巨像 Boss，第 30 波肃清星域通关。通关后可进入无尽模式继续挑战。

## 升级系统

击坠敌人掉落经验碎片（不同敌人掉落不同颜色），拾取升级后三选一。每次升级可**刷新一次**卡池。

**两类模块都最多装配 6 种**：拿满后该类不再出现新模块，只刷已拥有且未满级的。**精英岩必掉 1 个应急修复**；**Boss 必掉 2 个数据注入**（直升两级）；精英巨像额外必掉回血。

## 星区与无尽模式

- **外环碎屑带**（1–10 波）→ **中子星云**（11–20 波）→ **深空奇点**（21–30 波），敌型与配色逐区升级

- 第 30 波肃清后可选择**无尽漂移**：波次无上限，每 5 波仍有巨像轮换，看你能撑多久

## 音频

- 7 首程序化 BGM 按阶段自动切换：主菜单 / 发育期巡航 / 战斗 / 巨像战 / 无尽 / 结算，模块升 MAX 时切入 26 秒「镀金裂变」插曲

- 设置面板（O 键）可分别调节 BGM 与音效音量，即时生效并持久化

## 本地运行

```powershell
cd nova-drift
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

或使用 VS Code 的 Live Server 扩展。直接以 file:// 打开时部分浏览器会拦截音频加载。
