# 奇点旅途 · SINGULARITY VOYAGE

像素风太空弹幕射击（纯 HTML5 Canvas + WebAudio，零依赖，零构建）。

> 驾驶你的船穿过十二段航程。外环碎屑带、中子星云、深空奇点——
> 每一段都有不同的编队在等你，每四段有一座巨像挡路。
> 打通十二段只是开始：航程不会结束，直接转入**无尽深渊**。

## 玩法

| 操作 | 键鼠 | 触屏 |
|---|---|---|
| 转向 | **A / D**（或 ←/→）—— 不按键就保持当前朝向 | 左半屏摇杆：推满=满舵，微推=慢转 |
| 推进 | **W**（或 ↑）沿当前机首方向加速（有惯性，松手会漂移） | 左半屏摇杆推出死区 |
| 制动 | **S**（或 ↓）—— 速度指数衰减 | 左半屏按住不动（在死区里） |
| 朝向 | 鼠标一动 → 机头朝光标缓慢转向；按 A/D → 立刻切回键盘朝向 | 同左半屏摇杆 |
| 瞄准 | 鼠标位置画一枚**像素准星** | 右半屏拖动（瞄准点有括线标记） |
| 开火 | 按住左键 / 空格 | 右半屏按住（自动开火） |
| 助推冲刺（短无敌） | Shift / 右键 | 右下「冲」 |
| 超载爆发 | E | 右下「燃」 |
| 暂停 / 静音 | Esc·P / M | 左上「II」 |
| 全屏 | — | 右上「全」（开局自动尝试一次） |

**手机**：请横屏玩 —— 竖屏时会有一张「请把手机横过来」的提示。
布局会避开刘海与手势条（`env(safe-area-inset-*)`），并把底部按钮放大到约 40 游戏像素。

击坠敌人掉落**星尘**，拾取累积经验；经验满 → 三选一**模块**，装配后永久生效（可重抽一次）。
击坠和**擦弹**积攒能量，满格释放超载：清屏冲击波 + 火力翻倍 + 螺旋弹幕。

弹幕辨识：**青白细针**是你的炮弹，**红/粉/紫描边圆弹**是敌弹，务必躲开。

- **船体**（5 台，后两台需解锁）
  - 游隼（均衡）/ 轻剑（玻璃炮）/ 堡垒（重装）
  - **玄鸦**（刺客）— 累计击坠 300 解锁：船体 62，速度 128%，自带 10% 暴击、暴击 3 倍
  - **蜂群**（编队）— 航程抵达第 10 段解锁：出击自带 2 架僚机，拾取范围 +30%
- **模块**（29 张，每张有满级质变）
  - 数值：装甲板 · 推进器 · 自动装填 · 重型弹头 · 暴击电容 · 磁力线圈 · 纳米修复 · 相位外壳 ·
    **口径校准**（弹丸更粗、飞得更远）· **过载超频**（射速伤害换最大船体）
  - 弹体：多联机炮 · 穿甲弹 · 高爆弹 · **跳弹**（弹丸撞屏边反弹）· **制导弹药**（弹丸自己咬住最近敌人）·
    **散射喷嘴**（齐射多喷一圈扇形弹）· **裂变弹芯**（炮弹首次命中炸成一圈弹片）
  - 装置：战斗无人机 · 能量护盾 · 电弧线圈 · 脉冲核心 · 静止场 · **尾炮**（齐射同时朝船尾开火）·
    **冲角装甲**（贴上去就造成伤害，撞击自伤大减，代价是射速）· **死亡尾流**（高速拖出灼热带，灼伤敌人并**消解敌弹**）·
    **噬能回收**（每次击坠回一点血）· **轨道长枪**（冷却就绪时下一发变成贯穿光矛）·
    **相位折跃**（重击袭来时自动脱险，该次伤害作废）· **磁暴雷**（定时布设磁雷，磁引靠近的敌人再触爆）
  - 升到满级会触发一次**质变**（数值跃升 + 外观变金）；成对装配还会点亮**协同**（26 组，卡面会预告）
- **敌型**（16 种）
  - 追猎者 · 蝌蚪 · 飞镖 · 炮手 · 分裂体 · 掠夺者 · 重甲炮台 · 相位闪现者 · 潜行者 · 浮游雷 · 环轨炮 · 吸附虫
  - **织网者**（撒减速蛛网，压缩你的走位）· **牧者**（给周围敌人回血加速，必须优先点掉）
  - **新星**（死亡炸出一圈弹幕，别在弹幕缝里杀它）· **铁壁**（正面装甲吃 75% 伤害，绕后打）
- **巨像**：第 4 段 母岩 / 第 8 段 环带狱卒 / 第 12 段 奇点之门
- **无尽深渊**：打通第 12 段不是终点，第 13 段起航程不再结束，直接转入无尽深渊：
  - **深渊档位** —— 每 5 段抬一档（13 段 = 1 档，18 段 = 2 档……）。档位只放大**敌人**：
    血量 `1.14^档` 指数增长（**不封顶**），伤害 `1.08^档`、移动速度 `1.03^档`（速度封顶 1.5 倍）、
    每档多刷 1 只杂兵（封顶 +10）。**主线线性成长在第 12 段封顶**，线性和指数不会叠乘失控。
  - **巨像轮换** —— 无尽里每 4 段来一只巨像，三只用**轮换袋**洗牌，一轮里各来一次才重洗，不连出同一只。
  - **星区循环** —— 背景星区在 0/1/2 之间循环，越往后越像「深空奇点」。
  - HUD 段数：主线「第 N/12 段」，无尽「第 N 段 · 深渊 K 档」。
- **图鉴**：记录你遭遇过的一切 —— **敌型 16 / 巨像 3 / 船体 5 / 模块 29** 四个页签。
  没遇到过的只显示「？？？」和一枚暗剪影，遭遇过才解锁名字和那一行「怎么对付它」。
  收录进度**跨局累计**（存在存档里，不会因为重开浏览器归零）。
- **续档**：每段航程开始时自动存档；暂停里可以**保存并退出**，标题页就会出现
  「继续航程 · 第 N 段（船体）」，接着上次的船体、模块、分数继续打。
  一份存档只保留一局（roguelike 一局就是一次性的），船毁会自动清掉它。

> 尾炮 / 跳弹 / 制导 / 冲角 / 尾流 / 口径 / 散射 / 裂变 / 过载 / 噬能 / 长枪 / 折跃 / 磁雷
> 这十三张的**玩法行为**来自《奇点回响》，但数值、上限、视觉都是按本作重定的 ——
> 搬的是机制，不是模型。5 台船体的轮廓也对着回响的矢量机型重描过（`.workbuddy/gen_hull.py`）。

## 打击感

命中与击杀会插入 **20–160 毫秒的凝滞帧**（暴击顿挫、精英和巨像更重），配合屏幕震动、受击暗角、
低血量心跳声。这是像素弹幕手感的主要来源 —— 不是靠加粒子。

进度存在浏览器 `localStorage`（`sv_save_v1`）：最佳分数、累计击坠、最远航段、通关次数、已解锁船体。

## 本地运行

```powershell
cd singularity-voyage
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

`file://` 直接打开会被同源策略拦掉资源加载，请走本地 HTTP 服务。
