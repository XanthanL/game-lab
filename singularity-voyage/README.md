# 奇点旅途 · SINGULARITY VOYAGE

像素风太空弹幕射击（纯 HTML5 Canvas + WebAudio，零依赖，零构建）。

> 驾驶你的船穿过十二段航程。外环碎屑带、中子星云、深空奇点——
> 每一段都有不同的编队在等你，每四段有一座巨像挡路。

## 玩法

| 操作 | 键鼠 | 触屏 |
|---|---|---|
| 推进 | WASD / 方向键（有惯性，松手会漂移） | 左半屏拖动（屏幕上有摇杆底座） |
| 瞄准 | 鼠标，机头跟随；屏幕上有一枚**像素准星** | 右半屏拖动（瞄准点有括线标记） |
| 开火 | 按住左键 / 空格 | 右半屏按住（自动开火） |
| 助推冲刺（短无敌） | Shift / 右键 | 右下「冲」 |
| 超载爆发 | E | 右下「燃」 |
| 暂停 / 静音 | Esc·P / M | 左上「II」 |
| 全屏 | — | 右上「全」（开局自动尝试一次） |

**手机**：请横屏玩 —— 竖屏时会有一张「请把手机横过来」的提示。
布局会避开刘海与手势条（`env(safe-area-inset-*)`），并把底部按钮放大到约 40 游戏像素。

击坠敌人掉落**星尘**，拾取累积经验；经验满 → 三选一**模块**，装配后永久生效（可重抽一次）。
击坠和**擦弹**积攒能量，满格释放超载：清屏冲击波 + 火力翻倍 + 螺旋弹幕。

弹幕辨识：**青白细针**是你的炮弹，**红/粉/紫描边圆弹**是敌弹，务必躲开。

- **船体**（5 台，后两台需解锁）
  - 游隼（均衡）/ 轻剑（玻璃炮）/ 堡垒（重装）
  - **玄鸦**（刺客）— 累计击坠 300 解锁：船体 62，速度 128%，自带 10% 暴击、暴击 3 倍
  - **蜂群**（编队）— 航程抵达第 10 段解锁：出击自带 2 架僚机，拾取范围 +30%
- **模块**（16 张，每张有满级质变）
  - 数值：装甲板 · 推进器 · 自动装填 · 重型弹头 · 暴击电容 · 磁力线圈 · 纳米修复 · 相位外壳
  - 弹体：多联机炮 · 穿甲弹 · 高爆弹
  - 装置：战斗无人机 · 能量护盾 · 电弧线圈 · 脉冲核心 · 静止场
  - 升到满级会触发一次**质变**（数值跃升 + 外观变金）；成对装配还会点亮**协同**（8 组，卡面会预告）
- **敌型**（16 种）
  - 追猎者 · 蝌蚪 · 飞镖 · 炮手 · 分裂体 · 掠夺者 · 重甲炮台 · 相位闪现者 · 潜行者 · 浮游雷 · 环轨炮 · 吸附虫
  - **织网者**（撒减速蛛网，压缩你的走位）· **牧者**（给周围敌人回血加速，必须优先点掉）
  - **新星**（死亡炸出一圈弹幕，别在弹幕缝里杀它）· **铁壁**（正面装甲吃 75% 伤害，绕后打）
- **巨像**：第 4 段 母岩 / 第 8 段 环带狱卒 / 第 12 段 奇点之门

## 打击感

命中与击杀会插入 **20–160 毫秒的凝滞帧**（暴击顿挫、精英和巨像更重），配合屏幕震动、受击暗角、
低血量心跳声。这是像素弹幕手感的主要来源 —— 不是靠加粒子。

进度存在浏览器 `localStorage`（`sv_save_v1`）：最佳分数、累计击坠、最远航段、通关次数、已解锁船体。

## 本地运行

```powershell
cd singularity-voyage
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

`file://` 直接打开会被同源策略拦掉资源加载，请走本地 HTTP 服务。
