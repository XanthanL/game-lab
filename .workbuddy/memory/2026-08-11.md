## PVZ（E:\Code\game\PVZ）— 纯前端 Canvas 游戏
技术栈：vanilla JS + Canvas 2D，零依赖、零构建。脚本经 `js/` 下按序 `require` 注入 `PVZ` 全局（config/anim/art/draw/art/sprites/systems/*/entities/*/game）。

### 已修复 bug（根因）
- 割草机不起作用：`onZombieReachHouse` 触发后未击杀破门僵尸（每帧重复触发→误判负）；碾压判定只覆盖正前方。修复：`zombie.takeDamage(9999)` 直接击杀 + `Lawnmower` 碾压判定改为 `z.x <= this.x + this.w*0.6`。
- 铲子不起作用：`onPointerDown` 只画了铲子按钮、从没处理点击。修复：新增 `shovelMode` 切换，点草坪格 `removePlant()` 移除植物，保持模式可连续铲；再次点/右键取消。
- Boss 关渲染崩溃 `c is not defined`：`render()` 全屏闪光叠加块引用未定义 `c`。修复：改用 `PVZ.config.canvasWidth/Height`。

### 美术与动画升级（轻量、零依赖、版权安全）
- `js/anim.js` 轻量动画系统（缓动 + 对象池），主循环驱动。
- `js/art/draw.js` 软阴影、LRU 渐变缓存、阳光光晕脉动、爆炸冲击波、豌豆拖尾辉光。
- `js/art/sprites.js` 可选 CC0 精灵图层（默认不启用，失败回退程序化绘制）。
- 植物弹性入场、爆炸全屏闪光、割草机旋转轮+排气烟；植物/僵尸按 `cellWidth/80` 缩放，两布局视觉一致、不溢出。

### 竖屏原生支持（本次新做）
- `config.js`：所有布局字段改为按 `_mode`（`'landscape'`/`'portrait'`）分支的 getter。landscape 1020×600（cell 80×100），portrait 720×1280（cell 72×238，草坪占满纵向，seedPanelWidth=0）。
- `main.js`：`fitCanvas()` 按设备朝向(或 `?mode=`)设 `_mode`；坐标映射用动态 `cfg.canvasWidth/Height`（修复竖屏点击错位）；移除"请横屏"遮罩；模式翻转且游戏中则重开当前关。
- `game.js`：触控 dock 模式（`useDomDock`，仅 isTouch 时 true）隐藏画布内种子栏/铲子/暂停按钮/提示，避免顶栏拥挤与重复命中。
