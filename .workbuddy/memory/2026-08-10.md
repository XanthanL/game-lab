## cursed-house SVG 精灵只显示四分之一（已修）
- 现象：纸人偶/钥匙等 SVG 精灵在手机上只画出左上一角。
- 根因：9 个精灵 SVG 只写了 `viewBox`、没有 `width`/`height` → SVG 无内在尺寸。
  浏览器在 DPR=2 的手机上按 2 倍光栅化（如 doll 32×56 → 64×112 位图），
  但 `img.width/height` 仍报告 CSS 尺寸 32×56；渲染代码
  `drawImage(img, srcL, 0, srcR-srcL, img.height, ...)` 用它算源矩形，
  于是只采样到位图左上 1/4。DPR/浏览器不同，症状从"缺一角"到"变小走形"不等。
- 修复：新增 `svgSprite(w,h,body,fb)`（index.html ~412 行）——
  ① 生成 SVG 时显式写入 `width`/`height` 并与 viewBox 对齐；
  ② onload 后把 SVG **烘焙到固定尺寸的离屏 canvas**（超采样 ss=clamp(round(320/max(w,h)),1,10)），
     返回 canvas 而非 Image。canvas 的 width/height 即真实位图像素，彻底消除 CSS 像素/设备像素歧义，
     引用稳定（无需 onload 换变量），且避免每帧重复光栅化 SVG。
  ③ 有 fallback 的（doll/key/stairs）先把 fallback 拉伸铺上，加载完再覆盖。
- 已转换：doll/key/well/altar/lantern/tree/skeleton/grass/stairs 共 9 个，宽高比全部与原 viewBox 一致。
- 教训：**canvas 游戏里凡是要参与 drawImage 源矩形裁剪的 SVG，必须先烘焙成 canvas**，
  不要直接把 `<img>`(SVG) 当雪碧图采样。

## cursed-house 手机端无法转视角（已修）
- 现象：手机上能移动，但视角完全转不动，屏幕按钮也点不动。两个独立 bug 叠加：
  1. **灵敏度双重缩放**：touchmove 里 `mouseDX+=(x-tc.lx)*0.004`，而 `move()` 又 `rot=mouseDX*0.0022`
     → 8.8e-6 rad/px，拖 100px 只转 **0.05°**，肉眼等同没反应。
  2. **pointer-events 继承**：`#touch{pointer-events:none}`，`.tbtn` 未声明 `auto`；
     pointer-events 是**继承属性**，所以 互动E/静音M/暂停 三个按钮全部点不动。
     教训：全屏透明 HUD 容器设 none 后，**每个可交互子元素必须显式 `pointer-events:auto`**。
- 修复与新增（index.html）：
  - 触控拖拽改 `mouseDX+=dx*TOUCH_LOOK*lookSens`，`TOUCH_LOOK=2.4` → 满屏宽拖动约 121°。
  - `.tbtn` 加 `pointer-events:auto`，z-index 6→7（仍低于 .overlay 的 10，暂停时不误触）。
  - 新增 `#btnL/#btnR`（◀ ▶，右下 bottom 22px，60px 圆钮）长按持续转向：
    `turnDir` + `move()` 里 `rot+=turnDir*BTN_TURN*lookSens*dt`，`BTN_TURN=2.0` rad/s ≈115°/s；
    `bindTurnButton()` 同时绑 pointer/touch 事件，全局 pointerup + blur 兜底复位。
  - 新增 `#lookHint` 右半屏首次提示（5 秒或首次拖动后淡出）、标题页操作说明按 isTouch 切换文案。
  - 暂停面板加 `#setting` 灵敏度滑块（0.3–3.0，localStorage `ch_sens`），该区域拦截
    click/pointer/touch 冒泡以免误触"点击继续"；桌面 mousemove 也乘 lookSens。
  - touchstart/touchmove 对非按钮触点 `preventDefault()`（仅 cancelable 时）。
- 校验：Node+vm DOM 桩 **30 项断言全通过**（含拖拽转角线性度、方向、左半屏不转视角、
  长按转向速率、松手停止、暂停时失效、滑块 2.0 档恰为两倍、按钮不重叠、z-index 层级）。
